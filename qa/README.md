# QA — 무엇이 무엇을 보는가

검사는 **목적별**로 나눠 둔다. 기능별이 아니다. 기능은 `screen/` 안에서 묶는다.

```
qa/run.sh                바뀐 파일을 보고 필요한 것만 돌린다
qa/run.sh --all          전부
qa/run.sh data screen    골라서
qa/run.sh --list         무엇이 있는지
```

| 폴더 | 보는 것 | 언제 도나 |
|---|---|---|
| `data/` | DB 값·불변식 26가지 | 마이그레이션·파이프라인·빌더가 바뀌면 |
| `screen/` | **화면이 DB 값을 맞게 읽는가** | 프론트·백엔드·DB가 바뀌면 |
| `mirror/` | 한 사실이 여러 표에서 같은가 | 거울 동사가 바뀌면 |
| `app/` | 업무 규칙(권한·단계·집계) | 손으로 |
| `build/` | 빌드 산출물이 맞는가 | 빌더가 바뀌면 |
| `ui/` | UI 규칙(네모버튼·설명글씨) | 프론트가 바뀌면 |
| `external/` | 바깥 정본(토지이음)과 같은가 | **손으로만.** 공공 사이트에 요청을 보낸다 |

## 왜 `screen/` 이 따로 있나

`data/` 는 **DB 안까지만** 본다. 데이터가 맞아도 읽는 코드가 틀리면 안 걸린다.
2026-09-02 에 그게 드러났다 — `legal_bcr = [50,60]` 은 완벽히 맞는 데이터였고 버그는
전부 읽는 쪽에 있었는데, `qa_data` 는 그 내내 26개 다 통과였다. 그날 나온 버그 넷 중
파이프라인이 잡은 것은 0개다.

```
데이터가 맞나                data/      있었다
코드가 그 데이터를 맞게 읽나   screen/    없었다 → 그래서 만들었다
```

## `screen/` 은 두 겹이다

문자 찾기만으로는 절반만 잡힌다. `max()` 가 245 대신 50 을 고른 것은 화면 어디도
망가져 보이지 않는다 — 50% 는 법정용적률로 아주 그럴듯한 값이다.

```
① 흔적 찾기   %% · NaN · undefined · [object Object] · null
             + 라벨 뒤 값 줄의 모양       → 시끄러운 고장을 넓게
② 정답 박기   반드시 떠야 할 글자          → 조용히 틀린 값을
```

묶음 이름 앞에 성격을 적는다. **섞여 있는 것 자체는 괜찮지만 구분을 안 적으면 다음에
아무 검사나 붙는다.**

```
[정합]  DB 값을 화면이 맞게 읽는가 — 이 도구의 본래 목적
[동작]  값 대조가 아니라 죽지 않는가 — 대조할 DB 값이 없는 화면
```

## 새 기능을 만들면 매번 QA를 추가해야 하나

아니다. 두 겹의 비용이 다르다.

| 새 화면이 생기면 | 무엇을 하나 |
|---|---|
| 일단 | **경로 한 줄만** 넣는다. 흔적 찾기가 공짜로 붙는다 |
| 그 값이 문서로 나가면 | 기대값을 박는다 (확인설명서·계약서·보고서) |
| 틀려도 그럴듯해 보이면 | 기대값을 박는다 |
| 순수 UI면 | 안 넣는다 (모달 열림·닫힘) |

2026-09-02 에 잡은 넷 중 **셋은 경로만 있었어도 잡혔다.** 기대값이 필요했던 건
`max()` 하나뿐이다.

## 기대값은 화면에서 베끼지 않는다

베끼면 지금 틀린 값도 정답으로 굳는다. 대장·원장에서 확인하고 근거를 그 줄에 적는다.

```
대장 land_area 926.4㎡ ÷ 3.305785 = 280.2평   →  화면에 "280.2평" 이 떠야 한다
```

## 건너뛴 것은 통과가 아니다

`screen/` 은 프론트(5173)·API(8000)가, 나머지는 DB(55432)가 떠 있어야 한다.
안 떠 있으면 **건너뛰되 그렇게 말한다.** 조용히 통과시키면 검사가 있으나 마나다.

## 화면 점검 계정

로컬 전용 계정을 스스로 만들어 쓴다. 사용자 계정은 안 쓴다.

```
curl -sX POST localhost:8000/auth/signup -H 'Content-Type: application/json' \
  -d '{"email":"qa-screen@qa.example.com","password":"qascreen12345",
       "name":"화면점검","terms_agreed":true,"privacy_agreed":true}'
```

다른 환경이면 `qa/screen/.qa_screen.env`(gitignore)로 덮는다.
