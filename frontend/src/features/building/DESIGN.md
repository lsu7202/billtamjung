# S02 리포트/전체 — 디자인 가이드라인 (작업 기준)

> 목적: "데이터는 많은데 한눈에 안 들어온다"를 해결. 우리 데이터를 **어떻게 잘 보여주고
> 유저를 중독시키냐**가 승부. 매 결정마다 "이게 진짜 유저가 원하는 UI/UX인가?"를 반문한다.

## 0. 원칙
1. **데이터 → 인사이트.** 숫자 나열이 아니라 "그래서 뭔데?"에 답한다. (예: 공시지가 7,869만 → "5년 +38%, 상권 상위 10%")
2. **한 화면 = 한 질문.** 카드 하나가 유저의 질문 하나에 답한다.
3. **리포트=요약(한눈), 전체=상세(파고듦).** 같은 데이터, 다른 밀도. 리포트는 **매물분석보고서의 세미버전** — 이 매물의 핵심 가치를 한눈에.
4. **일관성.** 금액=`shared/format.won`, 차트=`TrendChart`, 지표타일=`StatTile`. 새 표현법 만들지 말고 재사용.
5. **AI티 벗기.** 와이어프레임 기본 틀에 갇히지 말 것. 색·여백·위계로 "읽고 싶게".
6. **설명 글씨를 붙이지 않는다.** ★ (2026-08-09 규칙화)
   차트·표가 스스로 말하게 두고, 그 옆에 조건·건수·요약을 글로 덧붙이지 않는다.
   글이 붙으면 그래프가 읽히기 전에 글부터 읽히고, 화면은 잡담이 된다.

   ```
   ✗  주변 실거래 평단가   500m · 최근 5년 · 57건 · 이상치 3건 제외
      ─ 주변 중앙 3,796만/평   본매물 3,614만/평 (추정가 기준)
      [차트]
      1  종로2가 71-5   7m   54억   4,408만
      2  관철동 6-4    37m   53억   3,848만

   ✓  주변 실거래 평단가                              만원/평
      [차트]                    ← 축 라벨이 거리, 본매물은 색으로 구분
   ```

   - **남기는 것**: 제목 · 단위 · 축 라벨 · 값 라벨. 없으면 못 읽는 것만.
   - **빼는 것**: 조회 조건(반경·기간·건수) · 계산 근거 · 요약 문장 · 보조 목록 ·
     "…기준", "…제외" 같은 단서.
   - 조건을 **바꿀 수 있으면** 컨트롤로 놓는다(글로 적지 말고). 못 바꾸면 안 적는다.
   - 정말 필요하면 툴팁·hover로. 상시 노출은 안 된다.
   - 같은 이유로 빈 상태 플레이스홀더·안내 문구도 최소로.

## 1. 리포트 vs 전체
| | 리포트 | 전체 |
|---|---|---|
| 목적 | 핵심가치 한눈에 | 항목별 상세·편집 |
| 밀도 | 요약(점수·대표숫자·미니차트) | 원자료(표·풀차트·입력) |
| 그래프 | **합쳐서 비교 OK**(가격 3종 한 막대 등) | **분리**(공시/실거래/임대 각 카드) |
| 편집 | 없음(읽기) | 있음(오버레이 입력) |

## 2. 유저가 우리 데이터로 알고싶은 것 (관점 리스트)
브로커/투자자가 상업용 매물에서 던지는 질문 = 우리가 답할 카드. 우선순위 순.

| # | 질문 | 우리 데이터 | 리포트 | 전체 | 차별성 |
|---|---|---|---|---|---|
| P1 | **얼마짜리?** (가치) | 추정가(F-17)·공시·실거래·매도희망 | 가격비교 막대 + PER배수 | 각 값·시계열 | ★추정가 |
| P2 | **얼마 버나?** (수익) | 임대료(총·평당)·수익률(만실/공실제외) | 수익률 + 임대 대표숫자 | 층별임대표·주변시세 | ★임대추정 |
| P3 | **좋은 자리?** (입지가치) | F-16 8축(역세권·대로변·상권·유동인구…) | 가치 레이더 + 매력도점수 | 항목별 점수·근거 | ★★심화 가치평가 |
| P4 | **주변 대비?** (상대) | 상권 시세·주변 comps | 임대 프리미엄 "+21%" | 주변시세 리스트/지도 | ★상권 시계열 |
| P5 | **오르나?** (추세) | 공시지가·임대·실거래 시계열 | 상승률 요약(5·10년) | 각 추세 풀차트 | ★임대 시계열 |
| P6 | **뭘 할 수 있나?** (활용) | 용도지역·용적률여유·규제 | 투자적합도(임대/리모델/신축) | 토지·규제 상세 | — |
| P7 | **리스크?** (권리·물리) | 노후도·권리·명도·대수선 | 리스크 뱃지 | 위키·힌트 탭 | — |

**반문 체크(매 카드):** ① 유저가 실제로 이걸 물어보나? ② 3초 안에 답이 보이나? ③ 우리만의 값인가(차별)? ④ 다른 카드와 안 겹치나?

## 3. 리포트 레이아웃 (P1~P7 매핑)
```
┌ 헤더: 매력도 82/100(P3) · [추정가 2,164억](P1) · 한줄 AI평 ─────────────┐
├──────────────────────────────────┬──────────────────────────────────────┤
│ P1 가격비교 (막대: 적정·공시·실거래·희망) │ P3 가치 레이더 (8축)                  │
│    + PER 배수                      │    + 상권 내 위치                      │
├──────────────────────────────────┼──────────────────────────────────────┤
│ P2 수익 (수익률·총임대) + P4 프리미엄 +21% │ P5 추세 (공시 5·10년 / 임대 상승률)     │
├──────────────────────────────────┴──────────────────────────────────────┤
│ P6 투자적합도: 임대 A · 리모델링 가능 · 신축 부적합    P7 리스크 뱃지        │
└──────────────────────────────────────────────────────────────────────────┘
```
- 장점: 핵심 7질문이 한 화면. 빌딩샵 REPORT보다 P3(가치)·P4(상권)·P5(임대추세)가 우리 강점.
- 단점/주의: 정보과밀 위험 → 카드당 대표숫자 1개 + 보조 1개로 제한. 추정가·가치점수 미산출 매물은 "분석 필요" 상태 노출(실시간 근사 or CTA).

## 4. 전체 레이아웃 (상세)
- 헤더지표 → 사진 → 금액(P1) → 투자분석(P2) → 층별임대(P2) → 상세정보 → 건물 → 토지+공시지가추이(P5) → 거래시세[실거래·광고](P5) → 주변시세(P4) → 사이드바(P7).
- 그래프 **분리 원칙** 유지. 공시지가는 토지 섹션에 값+추이 통합(완료).

## 5. 컴포넌트 재사용 (일관성)
- `shared/format.ts` — won/wonShort/perPyMan/manPerM2. **금액은 무조건 여기.**
- `TrendChart` — 모든 시계열. (공시·실거래·임대·리포트 추세)
- `StatTile`(신규) — 라벨+대표값+보조+델타. 헤더지표·리포트 지표 공용.
- `ScoreRadar`(신규) — F-16 8축. 리포트·S02b 공용.
- `CompareBar`(신규) — 가격 3종 비교 막대. 리포트 전용이나 재사용 가능.
- 색: 공시 #1E5AF0 · 실거래 var(--c-real) · 광고 var(--c-ad) · 임대 var(--green) · accent var(--signal). **의미색 고정.**

## 6. 작업 순서
1. ✅ 포매터 통합 + 만/억 버그
2. ✅ 공시/실거래/광고 카드 분리, 공시추이 토지통합, TrendChart
3. StatTile·ScoreRadar·CompareBar 재사용 컴포넌트
4. 리포트 탭(세그먼트 + P1~P7 카드)
5. 매매가(F-17) 마스터 채우기 → P1 데이터 완성
6. 최종 버그 스윕
