# 빌탐정 디자인 시스템 — "플랫 정밀" (Flat & Precise)

> 방향 확정 2026-07. Linear/Compass류 = 데이터 밀도 높으면서 깔끔.
> **모든 카드·기능은 이 규칙을 따른다.** 새 컴포넌트 만들기 전 여기부터 읽는다.
> 정본 토큰: `tokens.css` · 공용 컴포넌트: `components.css`, `ReportPrimitives.tsx`

## 1. 원칙 (한 줄)
**그림자 없이 hairline으로, 색은 1개로, 숫자는 크고 라벨은 작게.**

## 2. 색 (규율 = 강조 1 + 의미색 + 데이터 아이덴티티. 그 외 전부 모노톤)
- **강조 1색**: `--signal` 블루 `#1E5AF0`. 대표값·활성 상태·링크에만.
- **의미색**: 상승 `--up`(빨강) · 하락 `--down`(파랑) · 양호 `--green` · 경고 `--vacant`. **수치 판단에만**, 장식 금지.
- **데이터 아이덴티티**(계열 구분 전용): 실거래 `--c-real` · 공시 `--c-gongsi` · 임대 `--c-rent` · 광고 `--c-ad`. 차트/범례에서만.
- **⚠️ 동일 대상 = 지도·차트 같은 색**(엔티티 색 고정): 본매물=`--ink` · 실거래=`--c-real` · 임대=`--c-rent` · 공시지가=`--c-gongsi` · 광고/매도희망=`--c-ad`. 지도 마커·범례·컬럼·라인 전부 이 매핑을 따른다(하드코딩 hex 금지, 토큰만).
- **그 외 모든 것은 모노톤**: 잉크 `--ink`/`--ink-2`/`--muted`, 배경 `--bg`/`--panel`/`--surface-2`, 경계 `--line`/`--line-2`.
- ❌ 금지: 장식용 그라디언트, 의미 없는 컬러, 한 화면 4색 이상 동시.

## 3. 카드 (플랫)
- `.panel` = 흰 배경 + **hairline 경계(`--line`) + radius 8px, 그림자 없음.** (그림자는 지도 위 떠있는 오버레이에만)
- 카드 안 구획은 **hairline(`border-bottom:1px var(--line)`)** 으로. 카드를 또 카드로 감싸지 않는다.
- 헤더 = `.sec-head` (제목 좌 + 액션/메타 우). 액센트 바 없음(제거됨).
- 내부 패딩 리듬: 헤더 `13px 16px`, 본문 `14px 16px`, KV행 `9px`.

## 4. 타이포 (대비를 만든다)
| 역할 | 스펙 |
|---|---|
| 페이지 히어로 숫자 | 24~26px, 800, `--signal`(대표) 또는 `--ink` |
| 카드 대표 숫자(StatTile) | 18~21px, 800, mono, tabular-nums |
| 카드 제목(sec-head) | 14px, 800 |
| 본문/값 | 13~14px |
| **라벨**(숫자 위/옆) | **11~12px, `--muted`.** 항상 값보다 작고 조용하게 |
- **모든 숫자는 mono + `tabular-nums`** (`.num` 클래스). 이게 우리 "데이터 랩" 시그니처.
- 금액 표기는 `shared/format`만 사용(`won`/`wonShort`). 헤더 히어로·리포트 대표값 = 반올림(`wonShort`), 편집 필드 = 정밀(`won`).

## 5. 컴포넌트 표준 (재사용 = 일관성)
- **금액 입력** = KV `money`(원 입력 + 억 환산 + ↺). 자체 입력창 만들지 말 것.
- **% 입력** = KV `unit="%"`.
- **대표 지표** = `StatTile`(라벨+큰 숫자). **단, 헤더에 이미 있는 값은 카드에서 중복 금지.**
- **라벨/값 리스트** = `.kv-grid`(2열, hairline).
- **차트** = `TrendChart`(폭 `maxW`로 제한, 높이 실제 px). 그래프↔표 토글 제공(실거래·공시지가 패턴).
- **길이 제한**: 표/목록 5행 초과 시 `더보기 (N)`/`접기` (단어 통일).

## 6. 배치
- 넓은 컬럼(≥900px)은 **2단**으로: 작은 카드 나란히, 넓은 카드(지도·표·차트)만 풀폭.
- 관련 카드는 인접(층별임대 ↔ 주변임대시세).
- radius: 카드 8 · 컨트롤 6.

## 7. AI 티 회피 체크리스트 (PR 전 확인)
- [ ] 그림자로 띄운 카드 없나 → hairline인가
- [ ] 강조색이 2개 이상인가 → 1개로
- [ ] radius가 제각각인가 → 8/6
- [ ] 라벨이 값보다 크거나 진한가 → 작고 muted로
- [ ] 같은 값이 3곳 이상 반복되나 → 글랜스 1 + 편집 1로
- [ ] 이모지 섹션 마커 있나 → 제거(지하철🚇 등 실용 아이콘은 예외)

## 8. 차트 명세 (전부 SVG · 라이브러리 없음 · 폭 실측해 1:1 렌더)
공통: 컨테이너 폭을 `ResizeObserver`로 측정 → `viewBox` 폭=측정 px(텍스트·도형 왜곡 없음). 높이는 실제 px. 계열색은 §2 데이터 아이덴티티만.

| 차트 | 용도 | 스펙 |
|---|---|---|
| **TrendChart** | 시계열(공시지가·실거래) | 높이 실제 px(110~150) · 넓은 컬럼은 `maxW` 제한(≤560, 납작 방지) · **영역 그라디언트**(색 0.20→0) · 라인 2.25px · **엔드포인트 값 라벨** · **호버 세로 가이드+툴팁**(navy bg·#fff) · 그리드 점선 2선 · x라벨 시작/중간/끝만 |
| **CompareBar**(비교 컬럼) | 가격·임대료 비교 | **세로 막대** · 그라디언트 은은하게(색 1→0.82, 심하면 흐릿) · colW ≤56 · 높이 178 · **값 라벨 위**(mono 12·강조 800) · 카테고리 아래(강조=ink·그외 muted) · 베이스라인 1px · **호버=해당 막대 강조·나머지 dim(0.5)** · 대표(strong)는 상단 3px 캡 |
| **ScoreRadar** | F-16 8축 | N각형 격자 4단계 · 폴리곤 fillOpacity .2 · 색=등급색(S보라·A signal·B green) · 축 라벨 10.5px muted |
| **표 토글** | 차트↔표 | 차트 있는 카드는 헤더 우측 `그래프`/`표` 세그먼트(공시지가·실거래 패턴). 표는 `.wf`, 최신 위. |
- ❌ 금지: 평면 단색 막대(그라디언트·호버 필수) · 가로 막대(세로로) · 폭 풀폭 납작 차트.

## 9. 카드 명세 (플랫 정밀 완성형)
카드 = `.panel`(flat). 헤더 `.sec-head`(14/800) + 본문. 본문 유형 3가지:

**(a) 지표 스택** — 차트 옆 대표 수치(공시지가 카드 정본). 
- 라벨 `11px · muted · letter-spacing .03em · mb 4` / 값 `23px · 800 · mono · line-height 1` / 단위 `13px · muted`
- 항목 사이 `border-top 1px --line` + `padding 12px 0`. 색: 계열값만 계열색, 나머지 ink.

**(b) StatTile** — 그리드형 지표(수익·추세). 라벨 12 muted / 값 21 800 mono. 헤더에 이미 있는 값은 중복 금지.

**(c) KV 리스트** — 편집형 라벨/값(금액·건물·토지). `.kv-grid` 2열 · `.kv` hairline · 라벨 muted · 값 700 mono · 금액=KV `money`, %=KV `unit`.

공통 상태: 미지정=muted 흐리게 · 이상치=`.tag.stale` 배지 · 편집됨=`--signal-ink` · 5행 초과=`더보기 (N)`/`접기`.
배치: 넓은 컬럼 2단(작은 카드 나란히·넓은 카드 풀폭) · 관련 카드 인접.
