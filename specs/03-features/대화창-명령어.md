# 대화창 명령어 사전 (2026-08-14)

> 하단 대화창(TradeBar)이 알아듣는 것 전부. **전부 규칙이고 LLM 은 없다.**
> 원리: 즉시성(로컬 파서) · 되묻기(모를 때만, 최대 두 번) · 자동 채움(화면 맥락 주입).

## 화면 맥락 — 조건은 화면이 이미 알고 있다

| 보고 있는 화면 | 주입되는 대상 | 바의 점선 칩 |
|---|---|---|
| 매수 › 사람 › 매물 탭 | 그 제안(buyer × 매물) | `강태윤 · 118-25` |
| 매수 › 사람 › 전체 | 그 사람 | `강태윤` |
| 매도 › 사람 › 매물 탭 | 그 매물(owner × 매물) | `윤미경 · 49-9` |
| 매도 › 사람 › 전체 | 그 사람 | `윤미경` |
| 매물 › 매물 선택 | 그 매물(매도 축) | `김영순 · 118-25` |
| 캘린더 › 날짜 선택 | 기본 날짜 | (칩 없음 — 날짜만) |
| 대시보드 | 없음(전역) | — |

- 점선 = 화면에서 온 것(직접 고른 칩은 실선). × 로 끄면 전역, 화면을 옮기면 되살아난다.
- **명시가 추적을 이긴다** — 문장에 딴 이름을 쓰면 그 이름이 대상이다.
- 이 주입 덕에 **장부의 커밋칸을 걷어냈다**(입력은 바 하나, 장부는 읽기 레일).
- **이름 + 화면 매물 = 합쳐진다** — 매물을 보면서 「하늘부동산 제안」이라 치면 그 사람
  메모가 아니라 **이 매물에 대한 제안**이다. 그 매물에 제안이 없으면 **담으면서** 적는다
  (영수증 「담고 · 제안」 · 되돌리면 담기까지 걷는다). 매칭이 시작되면 이게 일상 동선이다.

## 기록 (파서가 문장에서 읽는다 — 회귀 122문장)

| 치는 것 | 되는 일 |
|---|---|
| 「155억에 내놓기로 하심」 | 매물 장부 + 단계 제안 + 매매가 오버레이 |
| 「148억이면 판다심」 | 매도희망가 |
| 「160억으로 재제안 돌렸음」 | 제안 장부 + 제시가 |
| 「120억이면 하겠다심」 | 매수희망가 |
| 「86억에 계약 합의」 | 계약 + 거래가 + 거울 전파 + 캘린더 사건 |
| 「수익률 안 나온다고 패스」 | 거절 + 사유 roi (사유 없으면 칩으로 한 번 묻는다) |
| 「내일 2시에 사무실에서 브리핑」 | 확정 창 → 캘린더(참석자·장소·담당) |
| 「일정」·「약속」·「미팅」 | 확정 창(캘린더를 보고 있으면 그 날짜 기본) |
| 「브리핑 다음주로 미룸」·「3시로 미뤄」·「잘 마쳤습니다」 | 있던 약속 이동(날짜·시각)·완료 |

## 명령 (기록보다 먼저 본다)

| 명령 | 되는 일 | 안전장치 |
|---|---|---|
| 「오늘 일정 전부 완료」 | 오늘 예정인 **내** 약속 일괄 완료 | 팀원 것 제외 + 건수 영수증 + 되돌리기 |
| 「전부 내일로」 | 일괄 미룸 | 위와 같음 |
| 「방금 거 취소」 | 마지막 기록·일괄의 되돌리기 | |
| 「캘린더」·「매물」·「매도」·「매수」·「대시보드」 | 탭 이동 | |
| 「내일 캘린더」·「다음주 캘린더」 | 그 날짜를 짚고 이동 | |
| 「내일 뭐 있지」 | 답 한 줄(3건 + 캘린더로) | 읽기 전용 |
| 「윤미경 번호」 | 전화 + 복사 | **마스킹 규칙 그대로**(목록 API 경유) |
| 「BT-1112 상세」 | 매물상세 열기 | |
| 「49-9 맞는 매수자」 | 조건 매칭 N명 답 줄 | 읽기 전용 |
| 「49-9 왜 안 나가」 | 제안·거절·사유 요약 답 줄 | 읽기 전용 |
| 「윤미경」(이름만) | 그 사람 화면으로 이동 | |

## 안 만든 것 (이유와 함께)

- **일괄 삭제** — 파괴적. 필요해지면 확인 질문 한 번을 필수로.
- **자동 재배치**(Motion류) — 약속은 상대가 있는 일. 앱이 옮겨도 상대는 모른다.
- **판단 명령**(「중요한 것만」) — 우리가 못 지키는 약속.
- **전역 토글**(내 담당/팀 전체) — 화면마다 자기 토글이 있고 뜻이 갈린다.
