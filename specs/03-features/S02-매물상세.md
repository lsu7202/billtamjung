## 1. 목적/역할
- 한 건물(대표지번)의 **모든 데이터를 한 화면**에 — 조회·업무관리·집단지성·산출물(보고서)의 허브.
- [[S01-매물통합검색]]에서 진입하는 실무의 중심 화면.

### 1.1 ★ 데이터 계층 (S02 전체를 관통하는 원칙)
> 상세·확정 규칙은 메모 `data-edit-architecture` 참조.

| 계층 | 소유 | 내용 | 원칙 |
|---|---|---|---|
| **① 공공 마스터** | 시스템 · read-only | 건물·토지·규제·공시지가·교통 원천 | **불변.** 유저 수정 절대 반영 안 됨 |
| **② 유저 오버레이** | 계정(+팀 공유) | 마스터 위에 개인이 **덮는 값**(정정·입력) | 화면값 = 마스터 + **내 오버레이**. 남에게 영향 없음, 팀은 공유범위 따름 |
| **③ 커뮤니티(전체 공유)** | 전 유저 | **위키**(특이사항)·**광고가**(시세 점) | 마스터 정정 아님, **새 글/시세 추가**·동의(👍)·신고 |
| ※ 시스템 추정 | 시스템 · read-only | **매각사례**(추정 매칭) | "추정" 고지. 유저 오버레이 없음 |

- [규칙] **핵심: 마스터는 절대 안 바뀐다.** 유저가 고친 건 자기(+팀) 오버레이일 뿐. 다수결·전체반영 없음.
- [규칙] **관리 단위 = 대표지번**(부속 필지 자동 포함, [[S01-매물통합검색]] §3.0). 필지별 값은 관련필지에서 열람(§3.6).

### 1.2 ★ 수정 3-모드 (필드별 — `04-data/data-overview.md`에 명시)
| 모드 | 필드 | 규칙 |
|---|---|---|
| **🔒 잠금** | 공시지가·용도지역·규제7종·**법정치**·지목·토지면적·PNU·좌표 | 팩트·식별자·조례계산 → 수정 불가 |
| **✏️ 직접입력** | 대장현황(엘베·주차·층수·면적·승인일·용도) + 사적(업무·상세·임대·매매가·메모) | 유저 입력 → 오버레이(②) |
| **🔀 계산 or 입력** | 수익률·자기자본·공실제외수익률·총보증금/임대료/관리비·평단가·여유분·총공시지가 | 자동계산 기본, **직접입력도 허용**(강제 계산 X). 직접입력값 있으면 우선. **자동/수동 배지 없음** |

## 2. 진입 · 이탈
- **진입**: [[S01-매물통합검색]] 행/핀 → 이 화면(건물 PK/PNU). 부속지번 검색도 대표 건물로 귀결.
- **이탈**:
  - `매물 분석하기` → **매물분석보고서**(PPT, 크레딧 소모) → [[R-보고서]].
  - `브리핑 자료` → **브리핑 PPT**(크레딧 소모) → [[R-보고서]].
  - `주변시세 계산기` → 주변임대시세 모달([[S03-주변시세]]).
  - 하단 `←` 뒤로 → [[S01-매물통합검색]](결과·스크롤 복원).
- [규칙] **상세 조회 자체는 무크레딧.** 크레딧은 산출물(보고서·브리핑)에만.

## 3. 화면 요소별 동작 — 좌측 본문

### 3.1 헤더 (대표지표)
| 요소 | 동작 |
|---|---|
| 주소 + ★ | [규칙] 대표지번 주소. ★=즐겨찾기 토글(계정 귀속). |
| 매물번호·접수일·담당 | [데이터] 사적 레이어(업무). |
| 대표지표 | [데이터] 매매가 · **수익률(만실/현재)** · 평단가(대지) · 면적(대지/연면적/건축, 평) · 층수(B_F/_F). 본문 값의 요약. |

### 3.2 매물사진
- [규칙] 인덱스 토글: **로드뷰 / 지도 / 업로드 사진**. 썸네일·이전/다음·카운트.
- [MVP] 지도·업로드 사진. [정식] 로드뷰 임베드(지도 API 연동).

### 3.3 표시 범위 토글
- [규칙] **전체 / 매물 / 건물·토지** — 본문 블록을 그룹(`deal`/`land`)으로 필터해 노출. (매물=금액·임대·상세·매각·광고·주변시세 / 건물·토지=건물·토지·규제·공시지가·입지)

### 3.4 금액정보 [사적+파생]
| 요소 | 동작 |
|---|---|
| 매매가·총보증금·총임대료·총관리비·총공실 | [데이터] 매매가=수기. 총보증금/임대료/관리비·총공실 = **층별 임대정보 집계**(§3.5, 🔀 직접입력도 가능). |
| 수익률(만실/현재)·순임대수익(월)·평단가(대지/연면적) | [규칙] 파생(🔀). 식은 `data-overview` F-07/08/10/14(일부 TBD). |
| **자기자본·대출 이자(월)** | [규칙] 수기 입력(사적). → **자기자본수익률**(순임대수익÷자기자본, F-11) 자동 산출. |
- [규칙] **별도 계산기 없음** — 층별 임대정보(§3.5)가 단일 진실, 총집계·수익률은 여기서 자동 파생. what-if는 층별 임대정보 직접 편집(오버레이)+하단 undo/↺(§5)로.

### 3.5 층별 임대정보 [사적, 프리필+수기]
- [규칙] 표: 층·호실·전용면적·**계약면적**·보증금·임대료·관리비·**상태(공실 토글)**. `＋ 호실 추가`로 행 추가.
- [데이터] **층·용도·전용면적 = 층별개요 프리필**, 호실·**계약면적**·금액·공실 = 수기. 층구분 7값·공실 3값(`data-overview` G4).
- [규칙] **평당 시세의 "평" = 계약면적 기준**(전용 아님) — [[S03-주변시세]] 평당 보증금/임대료와 정합.
- [규칙] 합산값이 §3.4 총보증금/임대료/관리비·총공실·수익률에 반영.

### 3.6 건물정보 · 토지정보 · 규제·특례 [공공]
| 블록 | 내용 |
|---|---|
| 건물정보 | 대지/연/건축면적·층수·용적산정연면적·주차·엘리베이터·사용승인일·대수선·기타용도 · **건폐율/용적률(실 / 법정 / 잔여여유분)** 병기. |
| 토지정보 | 토지면적·지목·**용도지역(걸침 병기)**·이용상황·주용도·지형형상·도로접면·지세 · **관련 필지**. |
| 관련 필지 | [규칙] 부속지번 있으면 클릭 → **관련필지 모달**(대표+부속 표, **각 필지 독립값**·합산 안 함). 없으면 "단일 필지". |
| 규제·특례 | [데이터] 지구단위·정비·고도·경관·방화·문화재·개발제한 = 해당구역명/해당없음. (강남 산출, 전서울 확장 예정) |
- [규칙] 공공 데이터는 **원칙 불변** — 오류는 §4.2 수정이력으로 집단지성 정정.

### 3.7 시계열 블록 (공시지가 · 매각사례 · 광고)
| 블록 | 동작 |
|---|---|
| 공시지가 [🔒 공공·시계열] | [규칙] 표/그래프 토글. 총공시지가·공시지가기준(×2) = 파생. (11개년 2016~2026) |
| 매각사례 [시스템 추정·시계열] | [규칙] 표/그래프. **"추정" 배지 필수**(RTMS 지번 마스킹→추정매칭). **read-only**(유저 오버레이 없음 — 정확값은 등기 확인). |
| 광고 [③ 커뮤니티·시계열] | [규칙] 표/그래프 + `광고 정보 입력` → 광고가 입력 모달(광고가·확인일·**내 광고** 체크). **전체 공유**, 확인 N건·내 기여 표시. |
- [규칙] 등락 색상: +빨강 / −파랑. 변동 시에만 새 점(시계열).

### 3.8 입지정보 [공공+수기]
- [규칙] 지도 + 🚇주변 지하철(역명·호선·거리·도보) + 🚌주변 버스정류소(거리·도보, 노선 결측). 유동인구(NICE 수기).

### 3.9 주변임대시세 [파생·조회]
- [규칙] 매트릭스 표(층·매물면적·평당 보증금/임대료·추정보증금/임대료). `주변시세 계산기` → [[S03-주변시세]] 모달(반경 기반 평균 산출→등록).

## 4. 화면 요소별 동작 — 우측 고정 사이드바 (스크롤 고정)
탭: **업무 · 위키 · 수정이력 · 메모**

### 4.1 업무 [사적, 팀 공유]
- [규칙] 진행상태(준비중/진행중/가격제시/매각/철회) · **내 광고**(내가 낸 광고가 배지) · 담당자·긴급도·소유자타입/내용/명·관계·협조도·친절도·매수의향서·전화번호.
- [데이터] 전부 사적 레이어(계정 소유, 팀 공유범위 따름 — [[S0M-마이페이지]] §3.5). enums=`data-overview` G8~G9.

### 4.2 위키 [집단지성]
- [규칙] 특이사항 미리보기(카테고리·본문·작성자·👍) → `전체보기` 모달.
- **모달**: 카테고리 필터(권리·명도/임차인/개발·도로/건물상태/소유자/기타) · 정렬(**신뢰도순**/최신순) · 작성폼(카테고리·출처·본문) · 엔트리(👍 동의·댓글·**신고**·출처·대댓글).
- [규칙] **신뢰도 = 동의(👍) 수** 기준 정렬. 부정확 시 **신고로 정정**. [MVP] 작성·동의. [정식] 댓글·신고 워크플로.

### 4.3 수정이력 [내/팀 오버레이 내역]
- [규칙] **내(+팀)가 마스터와 다르게 바꾼 필드 목록** — 필드별 `원본값 → 내 값` + **되돌리기**(마스터로 복원).
- [규칙] 마스터는 안 바뀌므로 다수결·전체반영·크라우드 통계 **없음**(§1.1). 순수 내 오버레이 추적·복원 장치.
- [열림] 기존 hi-fi 목업(`S02.html`)의 "다수결 분포" UI는 이 모델로 realign 필요.

### 4.4 메모 [사적, 팀 공유]
- [규칙] 팀 공유 메모(대표+팀원 내부만). [정식] 팀 기능 의존([[S0M-마이페이지]] §3.5) — 개인 메모는 [MVP].

## 5. 하단 고정 툴바
| 요소 | 동작 |
|---|---|
| ← → ↺ | [규칙] 데이터 수정 **undo/redo/초기화**(내 수정 세션 대상). |
| 평/㎡ 토글 | [규칙] 면적 표시단위 전환(저장은 ㎡). |
| `브리핑 자료` | [규칙] 기초 PPT 생성 → [[R-보고서]]. **크레딧 소모.** |
| `매물 분석하기` | [규칙] 심화 매물분석보고서 PPT → [[R-보고서]]. **크레딧 소모.** |

## 6. 상태 · 규칙
- [규칙] 파생값(🔀 모드)은 원천 수정 시 자동 재계산 — **단 직접입력값이 있으면 그 값 우선**(§1.2).
- [규칙] 유저 수정 = 마스터 불변, **오버레이만**(팀 공유범위). 커뮤니티(위키·광고가)는 전체 공유·동의(👍)·신고. 매각=시스템 추정 read-only.
- [규칙] 크레딧: 조회·수정·계산기 무료. **보고서·브리핑만 소모**([[S0M-마이페이지]] §3.2).

## 7. 예외
- 데이터 결측 필드 → `—`/"확인중". 추정값 → "추정" 배지.
- 부속지번 없는 건물 → 관련필지 "단일 필지".
- 크레딧 부족 + 보고서 시도 → 충전/업그레이드 유도([[S0M-마이페이지]]).
