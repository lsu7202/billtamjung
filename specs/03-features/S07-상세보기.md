# S07 상세보기 — 건물 사양서 (2026-10-01)

이 건물의 사실을 자세히 보는 화면. 고객 · 중개사가 같은 화면을 본다. 고치는 곳은 없다.
개별 중개사의 광고(글 · 중개사 · 문의)는 사이드바(매물 찾기)가 맡고, 팀 값은 매물관리 모달이 맡는다.
**매매가는 건물의 중요한 사실이라 싣는다** — 머리 줄에 「매매 N억」. 여러 중개사가 올렸으면 공개 매매가 중 **가장 싼 것**, 없으면 회색 추정가. 어느 광고인지는 싣지 않는다.

## 1. 여는 길

| 어디서 | 어떻게 |
|---|---|
| 매물 찾기 · 구해요 사이드바 「상세보기」 | 레일 오른쪽을 다 덮는 판. 주소에 `?b=건물번호`. 뒤로가기 · Esc · ← 로 닫으면 보던 자리 그대로 |
| ⌘ · Ctrl 클릭 · 가운데 클릭 · 판 머리 ↗ | 새 탭 `/buildings/건물번호` — 같은 화면을 페이지로 |
| 주변 유사거래 줄 | 그 건물 사양서로 바뀐다 |

## 2. 화면 (위에서 아래로, 사이드바와 같은 부품)

```
[사진 · 거리뷰 · 지도]
가격 카드 — 용도 · 용도지역 태그 / 빌탐정 추정가 / 최근 실거래 / 주소 · 도로명 / 관심
① 건물  ② 토지  ③ 토지이용계획  ④ 공시지가  ⑤ 층별 현황  ⑥ 입주 이력
⑦ 상권 임대료  ⑧ 실거래  ⑨ 입지
```

묶음은 사이드바의 접기(Fold)와 같다. ① · ⑧ 은 펼친 채로 연다.

## 3. 칸 명세

성격: **공공** = 공공 자료 · 그것의 정해진 계산 / **크롤링** = 카카오 장소 / **추정** = 우리 모델 값.

### 미디어
| 칸 | API · 출처 | 성격 |
|---|---|---|
| 사진 | `GET /buildings/{pk}/ads` 의 photo_ids (노출 중 광고 먼저). 광고 글 · 가격은 안 싣는다 | 광고 사진 |
| 거리뷰 | 네이버 파노라마(좌표) | 공공 |
| 지도 | 네이버 지도 + 필지 경계(`parcel_geom`) | 공공 |

### 가격 카드
| 칸 | API · 출처 | 성격 |
|---|---|---|
| 주소 · 도로명 | `GET /buildings/{pk}` addr · road_addr | 공공 |
| 용도 · 용도지역 태그 | main_use_name(줄임) · use_zone | 공공 |
| 빌탐정 추정가 | sale_est (master.building_sale_est) | 추정 — 상세보기의 추정은 이것 하나 |
| 최근 실거래 | last_sale_price · last_sale_ym | 공공 |
| 관심 | `GET /interest` 저장 수 · 오늘 본 사람 | 서비스 |

### ① 건물 — `GET /buildings/{pk}` · 건축물대장 · 공공
대지면적 · 연면적 · 건축면적 · 용적산정 연면적 · 지상 / 지하 층수 · 높이 · 건폐율 · 용적률 · 사용승인일(경과 연수) ·
대수선 및 리모델링 · 주용도 · 기타용도 · 구조 · 주차 · 승강기(옆에 「승강기공단 N대」 — `_ref.elevator_ext`).

- 건폐율 · 용적률은 **대장값만**. 대장이 비면 「—」. 계산값 참조(`_ref.bcr_calc` · `far_calc`)는 상세보기에 안 싣는다(중개사용, 매물관리).
- 면적은 앱 전체 단위(평 · ㎡)를 따른다.

### ② 토지 — `GET /buildings/{pk}/parcels` · 공공
필지 칩(필지가 둘 이상일 때 지번, 고르면 아래 값이 그 필지로) · 토지면적 · 지목 · 용도지역(걸치면 비중순 병기, `use_zone_mix`) ·
토지이용상황 · 지형/형상 · 지세 · 도로접면 · 실측 도로폭 전 · 측 · 후(`road`) · 법정 건폐율 · 법정 용적률(토지이음 산식) ·
**법정 대비 건폐율 · 용적률** = 대장 − 법정(넘으면 +, 남으면 −. 법정이 하나일 때만).

### ③ 토지이용계획 — parcels[].reg_all · 국토부 원문 · 공공
포함 · 저촉 · 접함으로 나눠 이름을 늘어놓는다(필지가 여럿이면 합치고 겹침은 하나로).

### ④ 공시지가 — gongsi_series · gongsi_latest · gongsi_total · 공공
㎡(평)당 · 총액 · 1990~ 추이 그래프 · 5년 전 대비 · 10년 전 대비.

### ⑤ 층별 현황 — `GET /buildings/{pk}/floors`
| 칸 | 출처 | 성격 |
|---|---|---|
| 층 · 대장 용도 · 바닥면적 | master.floor_outline | 공공 |
| 전유부(전용 · 공용면적) | master.building_unit — 집합건물만, 「전유부 N개」로 접어 둔다 | 공공 |
| 지금 업체 · 업종 | master.biz(카카오), 없으면 인허가 원장 | 크롤링 |
| 층 미상 N곳 | 위와 같음 | 크롤링 |

### ⑥ 입주 이력 — `GET /buildings/{pk}/floors/history` · 지방행정 인허가 · 공공
층별로 업체명 · 업종 · 영업 기간(개업 ~ 폐업) · 상태. 끝에 통신판매업 N곳.

### ⑦ 상권 임대료 — 빼 둔다(10-01)
임대료는 아직 고도화가 필요하다. 나중에 ⑤ 층별 현황에 「예상 임대료 확인하기」를 두고, 누르면 모달에서
결과와 근거(상권 임대동향 원값 · 층 · 면적 …)를 같이 보여 주는 방식으로 다시 넣는다.
`GET /buildings/{pk}/sanggwon-rent`(임대동향 원값)는 그때 쓰려고 남겨 둔다.

### ⑧ 실거래 — 공공
- **이 건물 거래 이력**: `seriesApi.get` (거래 시점 · 실거래가 · 연면적 평당 · 등락). **지금 중개사 전용 → 누구나로 푼다.**
- **주변 유사거래**: `POST /market/nearby` + 유사 기준(`use_like` · `use_zone` · `jimok`). 500m · 5년.
  기준 태그(#용도 #용도지역 #지목 #500m #5년)를 누르면 끄고 켠다(보는 사람 화면에서만). 최근순 · 가까운순, 단가 연면적 · 대지.
  맨 위 줄 = 이 건물. 줄을 누르면 그 건물 사양서.

### ⑨ 입지
| 칸 | 출처 | 성격 |
|---|---|---|
| 교통 — 지하철 호선별 최단역 · 버스 정류장(이름 · 거리) | `GET /buildings/{pk}` transit | 공공 |
| 주변 소식 — 갈래 · 제목 · 날짜 · 출처 링크 | area_event · urban_notice | 공공 |

유동인구 · 상권 구성은 뺐다(10-01). 건물이 아니라 동네 값이다. 자료 · API 는 남긴다(모델 검색 · 적정가 보정이 쓴다).

## 4. 상세보기에 넣지 않는 것

- 추정: 추정 수익률 · 추정 임대료/보증금 · 추정 평단가 · 공시 비율 · 매도가능성 점수 · 임대 시세 추이(역산)
- 팀: 매매가 · 매도희망가 · 팀 수익률 · 층별 임대 내역 · 업무 칸(명도 · 용도변경 …) · 위키 · 수정 이력 · 팀 사진 · 대장값 덮어쓰기
- 중개사용: 건폐 · 용적 계산값 참조 · 시장 호가(크롤링)
- 입체 지적도
- 유동인구 · 상권 구성(10-01)
