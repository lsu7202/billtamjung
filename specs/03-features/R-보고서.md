## 1. 목적/역할
- 매물의 **산출물(PPT) 2종**을 자동 생성 — 매수자 설득 자료. **S02에서 관리한 매물 데이터 기반 자동 산출.**
  | 종류 | 성격 | 크레딧 |
  |---|---|---|
  | **브리핑 자료** | 매물 소개 **기초자료** — 정보 나열, 분석 없음 | 10 |
  | **매물분석보고서**(=가치분석) | **심화 분석** — 가치점수·적정매매가·주변시세·수익률 | 30 |
- [규칙] 서식은 **빌탐정 통일 스타일**(R_example 기준). 두 보고서 동일 디자인.
- [규칙] **★ 무료/유료 경계**: 앱(S02)은 **raw 데이터 + 유저 curation**(주변시세 조회·다듬기 포함)까지 무료. **분석 synthesis(가치점수·적정매매가·협의금액·예상수익률)는 보고서 전용**(앱에 안 뜸). 보고서 = 배포용 브랜디드 PPT 산출물(유료 가치).

## 2. 진입 · 이탈 · 생성 플로우
- **진입**: [[S02-매물상세]] 하단 `브리핑 자료`(10) / `매물 분석하기`(30) 버튼 → **생성 모달**.
- **생성 모달 (동작)**:
  1. **옵션 확인** — 크레딧(소모/잔액) · **상권**(S02에서 지정한 반경, 매물분석만) · **주변임대시세 포함/제외 토글**(매물분석만) · 선행 안내(가치점수 결측=0점, 결측이어도 생성됨).
  2. `생성하기` → 생성 중(로딩).
  3. **미리보기** — 슬라이드 썸네일(분석 8 / 브리핑 7).
  4. 액션: `PPT 다운로드` · `내 산출물 저장`(계정) · `재생성`.
- [규칙] **크레딧 소모 = 생성 성공 시점**(옵션 확인·미리보기 전까지 무료). 베타=그림자 계량(실차감 없음).
- [규칙] 선행조건: 가치점수 9항목 결측 = **0점**(게이팅 없음). 생성은 항상 가능, 값 채울수록 정확.

## 3. 상권 (S03 인라인 · R 공유)
- [규칙] 적정매매가·주변임대시세는 **[[S02-매물상세]] 주변시세 블록에서 유저가 지정한 상권**(중심+반경, 사용자 지정)을 스코프로 사용. **상권 중심 ≠ 본매물**(복합 요소로 결정).
- [규칙] 상권은 S02 인라인 지도에서 설정(모달 아님). R은 그 상권값을 그대로 받음.
- [예외] 상권 내 매각사례 0건 → 상권 넓혀 해결(매각은 추정 매각이력 기반이라 콜드스타트 아님). 최대 반경도 희소하면 적정매매가 "산정 불가/저신뢰"([정식] 폴백 TBD).

## 4. 브리핑 자료 [기초 · 분석 없음]
- [규칙] `브리핑자료.pptx` 구조 그대로, 서식만 빌탐정. **가치점수·적정매매가·주변시세·수익률 전혀 없음.**
- 구성: ①표지(브랜딩·담당자) ②매물 기본정보(소재지·토지·건물·금융 표+사진) ③위치/지도 ④로드뷰/사진 ⑤임대 내역(층별 표) ⑥추가 사진 ⑦마무리.
- [데이터] 전부 **S02 데이터 그대로 나열**(계산 없음). 임대 내역 = 층별 임대정보(임대차기간 등 별도 필드 없음 — S02 필드에 맞춤).

## 5. 매물분석보고서 [심화 · 4 STEP]
> 8슬라이드. 표지 요약 → 기본정보 → 분석흐름 → STEP1~4 → 최종요약.

### 5.1 표지 · 핵심 요약
- [데이터] 6지표: **가치점수(등급)** · 매도희망가 · **적정매매가** · 협의 필요금액(매도희망가−적정매매가) · 주변임대시세 적용 총임대료 · **예상수익률**.

### 5.2 STEP1 — 가치점수
- [규칙] 9항목(도로접면15·역거리15·유동인구15·용도지역15·지형형상13·사용승인일11·엘베7·대수선7·경사도2%) 가중합 = **최대 100점**. 항목 점수표·산식 = `formulas.md`.
- [데이터] 레이더 차트 + 9항목 평가표 + 총점/**등급**(S 90+ / A 75~89 / B 60~74 / C <60).
- [규칙] 결측 항목 = 0점(게이팅 없음). 값은 S02 오버레이(유저 수정) 반영.

### 5.3 STEP2 — 매매사례 → 적정매매가
- [규칙] **입력 = [[S03-주변시세]]에서 유저가 curate한 매각 comps**(공용 반경·최근 5년·이상치 제거됨). 앱에서 다듬은 raw를 보고서가 받음.
- [규칙] 산정(상세 `formulas.md`): 사례별 **연면적 평단가** → **시점보정**(연도별 표) → **가치점수 유사도 가중**(`max(0.3, 1−|Δ점수|/20)`) → **가중평균 평단가 × 본매물 연면적** = 적정매매가. **이 synthesis가 보고서의 유료 핵심**(앱엔 없음).
- [데이터] 유사사례 표(주소·거리·거래일·매각가·연면적·평단가·가치점수차·시점보정) + 차트 + 협의금액. **사례 주소 클릭 → 그 매물 S02**(앱에서 볼 때, [[S02-매물상세]] §2).
- [규칙] **각 매각사례도 가치점수 계산**(가중치용). "추정 매각" 고지.

### 5.4 STEP3 — 주변임대시세
- [규칙] = [[S03-주변시세]] 결과(공용 반경 층별 평균). 층별 현재/주변시세/차이 표.
- [규칙] **토글로 제외 가능**(불완전한 집단지성 데이터라). 제외 시 §5.5 폴백.

### 5.5 STEP4 — 예상수익률
- [규칙] **예상수익률 = 적용 총임대료 × 12 ÷ 적정매매가** (R_example 확정).
- [규칙] 적용 총임대료 = 주변임대시세 적용 총임대료(STEP3). **STEP3 토글 제외 시 → 현재 임대료로 폴백**(§5.4 의존성).
- [데이터] 예상보증금·예상 임대료(월)·예상 연임대수익·예상수익률 + 호가 대비 비교표.

### 5.6 최종 요약
- [데이터] 매도희망가→적정매매가→협의금액 + 결론·매수검토 포인트 + 핵심수치 재정리.

## 6. 상태 · 규칙
- [규칙] 보고서 = **S02 데이터의 스냅샷 산출**. 유저 오버레이(수정값) 반영 → 각자/팀 값으로 생성.
- [규칙] 크레딧: 브리핑 10 · 분석 30. 잔액 부족 시 충전/업그레이드 유도([[S0M-마이페이지]]).
- [규칙] 산식 파라미터(시점보정표·가중치·등급컷)는 `formulas.md` 단일 출처. 표 갱신은 거기서.

## 6a. 구현 방식 (PPT 생성)
- [규칙] **서버사이드 템플릿 기반 생성.** 빌탐정 **PPT 템플릿**(.pptx 마스터/레이아웃, 통일 서식) + **데이터 바인딩**(placeholder 치환·표/차트 주입). 라이브러리 = python-pptx 등.
- [데이터] 바인딩 소스:
  - 매물 데이터 = **S02 값(마스터 + 유저 오버레이)** — 생성 시점 스냅샷.
  - comps = **[[S03-주변시세]]에서 curated 매각/임대** (상권 반경 적용).
  - 산출값 = 가치점수(F-16)·적정매매가(F-17)·예상수익률(F-18) — `formulas.md`.
- [규칙] **차트**: 레이더(가치점수 9항목)·막대(매매사례·주변임대시세)·시계열(공시지가 등) → PPT 네이티브 차트 or 이미지 렌더.
- [규칙] **미리보기** = 생성된 슬라이드 이미지 썸네일. **다운로드** = .pptx 파일.
- [규칙] **저장**: `내 산출물`(계정 귀속)에 보관 → 재다운로드. **재생성**: 데이터 변동 시 다시 생성(재생성 크레딧 정책 TBD).
- [규칙] 서식 = **분석보고서·브리핑 동일 빌탐정 스타일**(R_example 기준). 브리핑=7슬라이드(분석 없음)·분석=8슬라이드.
- [열림] 생성 = 동기 대기 vs 비동기(완료 알림) · 차트 렌더 방식(네이티브/이미지) · 재생성 크레딧.

## 7. 예외
- 가치점수 항목 다수 결측 → 점수 낮게 산출(0점 누적), 생성은 됨.
- 반경 내 매각사례 0건 → 반경 확대 유도, 그래도 없으면 적정매매가 산정 불가 표기.
- 주변임대시세 제외 → STEP3 생략 + STEP4 현재 임대료 기준.
- 크레딧 부족 → 생성 차단(베타=기록만).
