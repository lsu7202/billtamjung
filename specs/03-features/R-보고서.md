## 2. 진입 · 이탈 · 생성 플로우
- **진입**: [[S02-매물상세]] 하단 `브리핑 자료`(10) / `매물 분석하기`(30) 버튼 → **생성 모달**.
- **생성 모달 (동작)**:
  1. **옵션 확인** — 크레딧(소모/잔액) · **상권**(S02에서 지정한 반경, 매물분석만) · **주변임대시세 포함/제외 토글**(매물분석만) · 선행 안내(가치점수 결측=0점, 결측이어도 생성됨).
  2. `생성하기` → 생성 중(로딩).
  3. **미리보기** — 슬라이드 썸네일(분석 8 / 브리핑 7).
  4. 액션: `PPT 다운로드` · **`내 산출물`에 자동 보관**(생성 완료 시 자동, 별도 저장 버튼 없음 — §2a). **재생성은 여기 미리보기가 아니라 `내 산출물`의 `데이터 변경됨` 행에서**([[S0M-마이페이지]] §3.2a) — 방금 생성한 것을 즉시 재생성하는 건 무의미.
- [규칙] **크레딧 소모 = 생성 성공 시점**(옵션 확인·미리보기 전까지 무료). 베타=그림자 계량(실차감 없음).

### 2a. 생성 = 비동기 잡 *(확정 2026-07-19)*
**백엔드는 잡 큐, 프론트는 대기 화면.** 둘은 별개다 — 사용자는 화면에서 기다리므로 **알림 시스템이 필요 없다.**

| 상태 | 화면 | 비고 |
|---|---|---|
| `대기` / `생성중` | 모달에 **로딩 표시** | 진행률은 단계 표기 수준(데이터 수집 → 차트 → 파일) |
| `완료` | **자동 다운로드** + 미리보기 | 크레딧 차감은 이 시점 |
| `실패` | 사유 표시 + `다시 시도` | **크레딧 미차감** |

- [규칙] **화면을 벗어나도 잡은 계속 돈다.** 완료된 산출물은 `내 산출물`(S0M §3.2a)에 남으므로 알림 없이도 찾을 수 있다.
- [규칙] **동시 생성 상한**을 둔다(계정당 N건). 초과 시 "생성 중인 보고서가 있습니다" 안내.
- [규칙] 자동 다운로드가 **브라우저 팝업 차단에 막힐 수 있다** → 막히면 `다운로드` 버튼으로 폴백.
- [규칙] 크레딧은 **성공 시 차감**이므로, 비동기에서도 **잡 완료 트랜잭션 안에서** 원장에 기록한다(예약·홀드 불필요).
- [데이터] 잡 상태는 별도 테이블 없이 **`reports.status`**로 관리(`04-data/schema-app.md` §7).
- [규칙] 선행조건: 가치점수 **8항목** 결측 = **0점**(게이팅 없음). 생성은 항상 가능, 값 채울수록 정확.
  - 8항목은 전부 건축물대장·토지 데이터라 **서울 전 건물에 값이 있어** 실제로는 결측이 거의 없다(유동인구 제외 효과, `formulas.md` F-16).

## 5. 매물분석보고서 [심화 · 4 STEP]
> 8슬라이드. 표지 요약 → 기본정보 → 분석흐름 → STEP1~4 → 최종요약.

### 5.1 표지 · 핵심 요약
- [데이터] 6지표: **가치점수(등급)** · 매도희망가 · **적정매매가** · 협의 필요금액(매도희망가−적정매매가) · 주변임대시세 적용 총임대료 · **예상수익률**.

### 5.2 STEP1 — 가치점수 [미래가치 트랙]
> **역할(2026-07-29):** 매력도 지표 = **미래가치 트랙**. 적정가(STEP2)와 독립. 그 실효 용도 = **임대 상향여력(F-19)의 입력** — "이 매력도면 주변보다 임대료를 더 받을 수 있나".
- [규칙] **9항목**(도로접면·역거리·용도지역 각15.3·**유동인구15**·지형형상12.75·사용승인일11.05·엘베·대수선 각6.8·경사도1.7%) 가중합 = **최대 100점**. 항목 점수표·산식 = `formulas.md`.
  - **유동인구 재편입 route B(2026-07-26)** — proxy(도로·역 기반) 초기화로 comp에도 값 존재. 정확도 이득은 없으나 제품 완결성으로 채택. 상세 = `formulas.md` F-16.
- [데이터] 레이더 차트(**9축**, 웹 `ScoreRadar` SVG — 축 수 동적) + **9항목** 평가표 + 총점/**등급**(S 90+ / A 75~89 / B 60~74 / C <60).
- [규칙] 결측 항목 = 0점(게이팅 없음). 값은 S02 오버레이(유저 수정) 반영.

### 5.3 STEP2 — 매매사례 → 적정매매가 [현재가치 트랙]
- [규칙] **입력 = [[S03-주변시세]]에서 유저가 curate한 실거래 comps**(공용 반경·**최근 5년**·**성격(이용상황 섹터) 필터**·이상치 제거됨). 앱에서 다듬은 raw를 보고서가 받음. 성격 필터·인접 감점 = `formulas.md` F-17.
- [규칙] 산정(상세 `formulas.md` F-17 v2): comp별 **시점보정 → 거리가중 `1/(거리+50)` → 공시배율·대지단가·연면적단가 3지표 → geomean-IQR → 공시:대지 0.6 블렌드 → α연면적법 → 수익환원 β0.2**. **★ 가치점수(F-16)는 쓰지 않는다**(옛 유사도가중 폐기, 이중계산 방지). **이 synthesis가 보고서의 유료 핵심**(앱엔 없음).
- [데이터] 유사사례 표(주소·**거리**·거래일·실거래가·연면적·평단가·시점보정·거리가중) + 차트 + 협의금액. comp가 적정가에 주는 경로 = **거리·시점·성격·포함여부뿐**. **사례 주소 클릭 → 그 매물 S02**([[S02-매물상세]] §2).
- [규칙] "추정 실거래" 고지. (comp 가치점수는 적정가에 무관하므로 표에 노출 안 함.)

### 5.4 STEP3 — 주변임대시세 (+ 임대 상향여력)
- [규칙] = [[S03-주변시세]] 결과(공용 반경 층별 평균). 층별 현재/주변시세/차이 표.
- [규칙] **토글로 제외 가능**(불완전한 집단지성 데이터라). 제외 시 §5.5 폴백.
- [규칙] **임대 상향여력(F-19) [미래가치 트랙, 신규·미구현]** — 주변임대 + 가치점수로 "이 매력도면 기대되는 임대료 vs 현재 임대료"의 갭 산출. +면 저평가(업사이드). 현재가치(적정가)와 독립. 산식 = `formulas.md` F-19.

### 5.5 STEP4 — 예상수익률
- [규칙] **예상수익률 = 적용 총임대료 × 12 ÷ 적정매매가** (R_example 확정).
- [규칙] 적용 총임대료 = 주변임대시세 적용 총임대료(STEP3). **STEP3 토글 제외 시 → 현재 임대료로 폴백**(§5.4 의존성).
- [데이터] 예상보증금·예상 임대료(월)·예상 연임대수익·예상수익률 + 호가 대비 비교표.

### 5.6 최종 요약

## 6a. 구현 방식 (웹 렌더 1차 · PPT export 2차)  *(전환 2026-07-29)*
- [규칙] **1차 = 웹 렌더.** 보고서는 우리 웹에서 **인터랙티브 컴포넌트로 렌더**(2트랙 뷰·차트·표). 서버는 synthesis 값(F-16/17/18/19)만 계산해 내려주고, 렌더는 프론트. 재사용 = `ReportView.tsx`·`ReportPrimitives.tsx`(CompareBar·ScoreRadar·MetricStack)·`TrendChart`. 차트는 SVG라 9축 등 동적 반영(정적 PPT 템플릿의 "8축 고정" 제약 없음).
- [규칙] **2차 = PPT export (후속).** 완성된 웹 보고서를 .pptx로 내보내기. 서버사이드 템플릿(python-pptx) 또는 웹 캡처 기반 — 방식 [정식] TBD. **웹이 정본, PPT는 배포 포맷.**
- [데이터] 바인딩 소스:
  - 매물 데이터 = **S02 값(마스터 + 유저 오버레이)** — 생성 시점 스냅샷.
  - comps = **[[S03-주변시세]]에서 curated 실거래/임대** (상권 반경 적용).
  - 산출값 = 가치점수(F-16)·적정매매가(F-17)·예상수익률(F-18)·임대여력(F-19) — `formulas.md`.
- [규칙] **차트**: 레이더(가치점수 **9축**)·막대(매매사례·주변임대시세·본매물vs주변)·시계열(공시지가). 웹 SVG 렌더.
