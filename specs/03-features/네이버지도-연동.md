## 1. API 스택 (네이버 클라우드 플랫폼)
- **Maps — Web Dynamic Map (JS API v3)**: 동적 지도·마커·클러스터·팬/줌.
- **Panorama (거리뷰/로드뷰)**: 좌표 기준 파노라마.
- (필요 시) **Geocoding**: 주소→좌표. 우리는 자체 좌표 보유라 보조용.
- [데이터] **좌표 원천 = 우리 필지 centroid(WGS84)** (`data-overview` 좌표 x/y, `build_gangnam` 산출). 지오코딩 의존 최소.
- [규칙] 인증 = clientId(ncpKeyId). 요금·키 발급 = **사업화 시**(베타는 개발키).

## 2. 마커 색상 규칙 (전 화면 통일)
- **광고 = green(#34a853) · 내 매물 = blue(#1a73e8) · 일반 = purple(#7b3fe4)** — [[S01-매물통합검색]] 리스트 3열 색상과 **동일**.
- 마커 라벨 = 매매가(억). 본매물 = 검정 마커(참조).

## 3. 사용처별 동작

### 3.1 S01 지도 뷰
- [규칙] 검색 결과 매물을 **색상 마커**로(§2). 지도 영역 = 좌 대형, 우 **동기 리스트**(영역 내 매물, 태그 색상).
- [규칙] **마커 클릭 → 요약 팝오버**(주소·매매가·수익률·연면적) → `상세보기` [[S02-매물상세]]. 리스트 행 클릭도 동일.
- [규칙] **클러스터링**: 밀집 시 숫자 버블 → 클릭 시 줌인/펼침. (임계=화면밀도, [정식] 튜닝)
- [규칙] **`↻ 이 지역 재검색`**: 팬/줌 후 현재 지도 bounds로 재조회 — **수동 버튼**(자동 재조회 아님, 과호출 방지).
- [규칙] 검색바 필터·`★ 즐겨찾기` 필터가 지도 결과에도 동일 적용.
- [예외] 결과 0건 → 빈 지도 + 안내. 좌표 없는 매물 → 리스트에만(핀 없음) 표기.

### 3.2 S02 매물사진 — 지도 탭
- [규칙] 본매물 **단일 마커** 지도. 기본 줌(건물 식별 수준). 팬/줌 자유.

### 3.3 S02 매물사진 — 로드뷰 탭
- [규칙] **Panorama** — 본매물 좌표 **최근접 파노라마** 로드. 회전·이동(파노라마 이동) 지원.
- [예외] 좌표 인근 파노라마 없음(골목 등) → "로드뷰 없음" 안내 + 지도 탭 유도.

### 3.4 S02 입지정보 지도
- [규칙] 본매물 + **주변 지하철·버스 마커**(교통 데이터). 역/정류소 라벨·거리.

### 3.5 S02 주변시세 — 상권 지도 (인라인)
- [규칙] **상권 원(중심+반경) 직접 지정** — **★ 중심 ≠ 본매물**(복합 요소). 본매물은 참조 마커.
  - **중심 이동** = 원 드래그. **반경 조절** = 원 테두리 핸들 드래그 or 반경 슬라이더(양방향 동기).
- [규칙] 원 내부 매물이 조회 대상(임대·매각 comps). 원 밖 본매물도 허용.
- [규칙] 이 상권(중심 좌표+반경)을 [[R-보고서]]가 그대로 사용.

## 4. 공통 규칙
- [규칙] 지도 로딩 중 스켈레톤/스피너. 타일 로드 실패 → 재시도.
- [규칙] 반응형: 지도 컨테이너 리사이즈 대응.
- [규칙] 마커 과다(수백+) → 클러스터 필수(성능).
