## 1. API 스택 (네이버 클라우드 플랫폼)  *(문서 정독 반영 2026-07-21)*

> ⚠️ **상품 전환 주의**: 구 `AI NAVER API > Maps`는 **2025-07-01 무료한도 종료·신규 차단**. 반드시 **신 상품 `Application Services > Maps`** 로 발급하고, 옛 튜토리얼(구 예제) 코드를 쓰지 말 것.

- **Web Dynamic Map (JS v3)**: 동적 지도·마커·팬/줌.
  - **지도 유형**(`setMapTypeId`): 일반 `NORMAL` / 위성 `SATELLITE` / 하이브리드 `HYBRID` / 지형 `TERRAIN` → 레이어 툴바(§3.1)에 매핑.
  - **네이버 제공 오버레이 레이어**: **`CadastralLayer`(지적편집도)** · `TrafficLayer` · `StreetLayer`(거리뷰 가능 도로) 등 — `layer.setMap(map)` 한 줄로 부착.
  - **커스텀 오버레이**: `Marker`·`Polygon`·`Circle` + **`Data`(GeoJSON 로드)** — 우리 지적 폴리곤을 얹는 표준 경로.
  - **클러스터링**: `MarkerClustering` 유틸 제공(대량 빌딩 마커).
- **Panorama (거리뷰/로드뷰)**: `naver.maps.Panorama` (submodule=panorama). **좌표 지정 시 반경 300m 최근접 파노라마 자동 매칭.** POV(회전·이동) 지원.
- **★ Static Map API (REST)**: 정적 지도 이미지 반환 → **보고서(PPT) 삽입용 지도 캡처를 이걸로 처리**(서버 REST). `R-보고서.md` PPT 지도 문제 해결.
- **Geocoding / Reverse Geocoding (REST)**: 주소↔좌표. Reverse는 `orders=legalcode,admcode,addr,roadaddr`. 우리는 자체 좌표 보유라 보조용.
- [데이터] **좌표 원천 = 우리 필지 centroid(WGS84)** (`data-overview` 좌표 x/y, `build_gangnam` 산출). 지오코딩 의존 최소.
- [규칙] **인증**: JS는 콘솔 Application 등록 → **`ncpKeyId`**(구 `ncpClientId` 폐기) + **Web 서비스 URL 도메인 등록 필수**. REST는 헤더 `x-ncp-apigw-api-key-id`/`-api-key`(서버측, 도메인 무관).
- [규칙] 요금·키 발급 = **사업화 시**(베타는 개발키). 신 Maps 상품 구간 단가는 공식 문서 미노출 → **콘솔 요금계산기로 확인**(베타 종료 시 처리, `네이버지도-연동` §쿼터).

### 1.1 ★ 지적도 = 이중 구조 *(핵심 결정 2026-07-21)*
| 목적 | 방법 |
|---|---|
| **지적선을 보이게만** | 네이버 **`CadastralLayer`** ON — 경계선 타일. 우리 폴리곤 불필요 |
| **필지 클릭·색칠·데이터 매핑** | **우리 PostGIS 지적 폴리곤을 GeoJSON(`Data`)으로 오버레이** — `CadastralLayer`는 그림 타일이라 클릭·데이터가 안 됨 |

- [규칙] 두 개를 **병행**한다: 네이버 지적선(배경) + 우리 폴리곤(투명, 클릭 히트영역).
- **★ 차별점**: 필지 클릭 → 그 필지의 **공시지가·용도지역·규제**(우리가 이미 필지 단위로 보유, `build_gangnam` 필지별 적재) 팝오버. 경쟁사(부동산플래닛·빌딩샵)는 지적선만 보여줄 뿐 필지 클릭·데이터 매핑이 없다.

### 1.2 영역 그리기 · 자석 스냅 ★★ *(신설 2026-07-21 — [[S01-매물통합검색]] §3.6c)*
> 지도에 임의 영역을 그려 그 안의 매물만 검색하는 고유 기능의 지도 측 구현.

- [규칙] **그리기 오버레이** = `naver.maps.Polygon`(또는 `Polyline`) + 지도 이벤트(`mousedown/mousemove/mouseup`)로 경로 수집. 그리는 동안 `draggable=false`로 팬 정지. 네이버 `drawing` 서브모듈이 있으면 활용, 없으면 커스텀.
- [규칙] **3모드**: 자유곡선(드래그 경로 그대로) · 다각형(클릭 정점 + 정점 마커 드래그 편집) · **자석 올가미**(아래).
- **★★ 자석 올가미 = 우리 지적 폴리곤 데이터로 구현**(경쟁사 불가):
  - [규칙] 스냅 소스 = **§1.1의 우리 지적 폴리곤 경계(GeoJSON)** + (있으면) 도로 경계. 이미 지적도 레이어용으로 로드된 데이터 재사용.
  - [규칙] **후처리 스냅(베타 가능)**: 대충 그린 올가미 → 그 영역과 **겹치는(중심 포함) 필지들의 합집합** 폴리곤으로 경계를 재정리(`ST_Union`). 건물을 반 자르지 않고 필지 단위로 딱 맞음.
  - [규칙] **실시간 스냅(정식)**: 드래그 중 커서 인근 임계 내 최근접 필지 경계 정점/간선으로 흡착(포토샵 자석 올가미 느낌). 난도 높아 정식.
  - **⚠️ 알고리즘 보류(2026-07-21)**: 실제 지도·지적 폴리곤이 붙기 전엔 스냅 알고리즘(최근접 경계 탐색·흡착 임계·경로 스무딩)을 확정하지 않는다. **UI 틀(모드 버튼·상태)만 목업에 두고**, 알고리즘은 **지도 연동 단계에서 실측 데이터로 실시간 설계**. 현 단계 판단은 무의미(그릴 지도가 없음).
- [규칙] **검색 전달** = 최종 폴리곤을 **GeoJSON**으로 API에 → PostGIS `ST_Within`([[S01-매물통합검색]] §3.6c). 자기교차 `ST_MakeValid`, 정점 과다 `ST_SimplifyPreserveTopology`.
- [규칙] 영역 표시 = 반투명 채움 + 경계선(시그널색). 영역 밖 마커는 흐리게/숨김.
- **단계**: 🟢 베타(자유·다각형 + 후처리 필지 스냅) · 🔵 정식(실시간 자석 스냅·복수 영역·원 도구).

## 2. 마커 색상 규칙 (전 화면 통일)
- **광고 = green(#0E9F6E) · 내 매물 = blue(#1E5AF0) · 일반 = purple(#6E56E8)** — 디자인 시스템(`wireframe.css`) 분류색과 **동일**(2026-07-21 정제).

## 3. 사용처별 동작

### 3.1 S01 지도 뷰
- [규칙] 검색 결과 매물을 **색상 마커**로(§2). 레이아웃 = **좌 사이드바(선택 요약 + 미니 리스트) · 우 대형 지도**(디스코·부동산플래닛 표준).
- [규칙] **마커 클릭 → 좌측 사이드바 요약 카드 갱신**([[S01-매물통합검색]] §3.6) → `상세보기` [[S02-매물상세]]. 리스트 행 클릭도 동일. ~~지도 위 요약 팝오버~~ 폐기(2026-07-21): 사이드바 중복.
  ※ 필지 클릭(§위 지적도)·클러스터 클릭 팝오버는 유지 — 마커(매물) 팝오버만 폐기.
- [규칙] **클러스터링**: 밀집 시 숫자 버블 → **클릭 시 그 위치 매물 목록 팝오버**(가까운 순, 상위 N + `확대해서 보기`). `확대해서 보기` = 그 클러스터로 줌인해 개별 핀으로 분해. (임계=화면밀도, [정식] 튜닝)
- [규칙] ~~`↻ 이 지역 재검색`~~ **폐기(2026-07-21)**: 범위는 명시적으로만(법정동/그린 영역). 지도 팬/줌은 보기 전용. 검색 범위는 폴리곤으로 시각화(법정동 실선·그린영역 점선, 동일 컴포넌트).
- [규칙] 검색바 필터·`★ 즐겨찾기` 필터가 지도 결과에도 동일 적용.
- [규칙] **레이어 툴바(2026-07-21)**: 일반 / 위성 / **지적도** / 로드뷰.
  - **일반↔위성** = 배타(네이버 base ↔ 위성 타일).
  - **지적도** = 독립 토글. **필지 경계 오버레이**(우리 PostGIS 지적 폴리곤, `master`). 다필지 필지 구분을 지도에서 확인.
  - **로드뷰** = 네이버 Panorama 전환 패널(§3.3과 동일 API). 선택 지점 최근접 파노라마.
- [예외] 결과 0건 → 빈 지도 + 안내. 좌표 없는 매물 → 리스트에만(핀 없음) 표기.

### 3.2 S02 매물사진 — 지도 탭
- [규칙] 본매물 **단일 마커** 지도. 기본 줌(건물 식별 수준). 팬/줌 자유.

### 3.3 S02 매물사진 — 로드뷰 탭
- [규칙] **Panorama** — 본매물 좌표 **최근접 파노라마** 로드. 회전·이동(파노라마 이동) 지원.
- [예외] 좌표 인근 파노라마 없음(골목 등) → "로드뷰 없음" 안내 + 지도 탭 유도.

### 3.4 S02 입지정보 지도
- [규칙] 본매물 + **주변 지하철·버스 마커**(교통 데이터). 역/정류소 라벨·거리.

### 3.5 S02 주변시세 — 상권 지도 (인라인)
- [규칙] **상권 원(중심+반경) 직접 지정** — **★ 중심 ≠ 본매물**(복합 요소). 본매물은 참조 마커.
  - **중심 이동** = 원 드래그. **반경 조절** = 원 테두리 핸들 드래그 or 반경 슬라이더(양방향 동기).
- [규칙] 원 내부 매물이 조회 대상(임대·실거래 comps). 원 밖 본매물도 허용.
- [규칙] 이 상권(중심 좌표+반경)을 [[R-보고서]]가 그대로 사용.

## 4. 공통 규칙
- [규칙] 지도 로딩 중 스켈레톤/스피너. 타일 로드 실패 → 재시도.
- [규칙] 반응형: 지도 컨테이너 리사이즈 대응.
- [규칙] 마커 과다(수백+) → 클러스터 필수(성능).

## 5. 예외 · 열린 항목
- **API 요금·쿼터 — 보류 확정(2026-07-19)**
  - **지금 산정하지 않는다.** 1인당 지도 호출 수를 모르는 상태에서 계산하면 숫자가 허구가 된다. 베타는 개발키로 충분(지인 대상, 트래픽 미미).
  - ⚠️ **베타 종료 시 반드시 처리**: 실측 호출량 기반 쿼터 산정 + **초과 시 폴백**(정적 지도 이미지 등). **미정으로 둔 채 정식 출시하면 안 된다.**
- 좌표 정확도(필지 centroid vs 건물 중심) — 대체로 충분, 오차 큰 케이스 보정 TBD.
- 클러스터 임계·마커 스타일 세부 = 디자인 확정 시.
- 로드뷰 파노라마 방향(건물 바라보게 초기 회전) 최적화 [정식].
