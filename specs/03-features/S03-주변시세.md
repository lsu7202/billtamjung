## 1. 목적/역할
- 본매물과 **비슷한 주변 매물들의 층별 평균 임대시세**를 산출 → [[S02-매물상세]] §3.9 주변임대시세 표에 등록.
- **데이터 원천 = 반경 내 건물들의 층별 임대정보(집단지성 공용, 유저 축적)**.
  - [규칙] 빌딩 임대 실거래는 **공공에 없음**(전월세 신고제=주택만) · 크롤링 폐기 → **집단지성이 유일 소스**. ⏳ 콜드스타트라 초안.
- [규칙] 매각 아님, **임대** 시세. 매매 시세는 별도(추정 매각이력).

## 2. 진입 · 이탈
- **진입**: [[S02-매물상세]] 주변임대시세 섹션의 `주변시세 계산기` 버튼. (금액 계산기 아님 — 그건 폐기됨)
- **이탈**:
  - `평균 → 주변임대시세 등록` → 산출 평균을 [[S02-매물상세]] §3.9 표에 반영(**단방향**) 후 닫힘.
  - `닫기`/배경 → 등록 없이 닫힘.
- [규칙] **무크레딧**(조회·분석 도구). 크레딧은 보고서에만.

## 3. 화면 요소별 동작 (워크플로우 순)

### 3.1 ① 상권 반경 (입력)
- [규칙] 지도에 **본매물 아이콘(중심)** + **반경(원) 직접 그림**. `04-data/field-inventory.md`의 **공용 반경 모달** 사용 — [[R-보고서]]와 **공유**.
  - [규칙] 반경은 **사람이 매번 직접 설정**(저장·재사용 안 함, 상권 객체는 나중). 슬라이더(예 200~1000m).
- [규칙] **조회 층 범위**: `지하 N ~ 지상 N층` 입력 — 이 범위 층만 조회.
- `분석하기` → 백엔드가 반경·층 범위 내 건물들의 **층별 임대정보 조회**.
- [열림] 반경 외 **조건필터**(용도지역·도로급·규모)로 유사도 좁히기 = TBD.

### 3.2 ② 조회 결과 · 노이즈 수정 (표·편집)
- [규칙] 표: 체크 · 층 · 계약면적 · 전용면적 · 보증금 · 임대료 · **평당보증금 · 평당임대료** · 관리비 · 주소 · 삭제(×).
- [규칙] **평당의 "평" = 계약면적 기준**([[S02-매물상세]] §3.5 정합).
- [규칙] **이상치 자동 표시**(통계 기반 `이상치` 배지) → 기본 **체크 해제**(평균 제외). 유저가 체크/해제로 반영 여부 조정, `×`로 삭제.
- [열림] 이상치 판정 기준(통계 방식·임계) = TBD.

### 3.3 ③ 층별 평균 (등록될 값)
- [규칙] 체크된 행만 **같은 층끼리 평균** → 층 · 평당보증금 · 평당임대료 · **추정보증금 · 추정임대료** · 건수.
- [규칙] **추정보증금/임대료 = 평당 평균 × 본매물 해당 층 계약면적** — "이 매물 각 층이 주변 시세로면 얼마"의 추정.
- [규칙] `평균 → 주변임대시세 등록` → 해당 층에 [[S02-매물상세]] §3.9 표로 반영.

## 4. 상태 · 규칙
- [규칙] 등록은 **단방향**(S03 → S02). S02 주변임대시세 표를 S03이 덮어쓰되, 역방향 없음.
- [규칙] 산출값은 **오버레이(사적)** — 본매물의 주변임대시세로 저장([[S02-매물상세]] 데이터 계층 ②).
- [규칙] 반경·층범위·체크상태는 모달 세션 동안만. 재분석 시 재조회.

## 5. 데이터 연결
- [데이터] 입력: 반경(중심=본매물 좌표·거리) · 조회 층범위.
- [데이터] 조회: 반경 내 건물들의 **층별 임대정보**(집단지성 공용, `data-overview` G4).
- [데이터] 산출: 층별 평당 평균(계약면적 기준) → 본매물 주변임대시세(오버레이 저장).

## 6. 예외
- 반경 내 데이터 **0건/희소**(콜드스타트) → "데이터 부족" 안내. 콜드스타트 보완책(상권 통계 기준선 등) = 베타 후 결정.
- 특정 층만 데이터 없음 → 그 층 추정 공란.
- 이상치만 남고 정상치 0 → 평균 산출 불가 안내.
