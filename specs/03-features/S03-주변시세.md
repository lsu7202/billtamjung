## 1. 목적/역할
- **공용 반경 한 번**으로 반경 내 **주변 임대시세 + 주변 매각 comps 둘 다** 조회하고, 유저가 **노이즈를 curate**하는 도구.
- **핵심 원칙**: 우리 주변 데이터는 불완전(매각=추정, 임대=집단지성)이라 **유저 curation 필수** → 앱(S02)에서 다듬고, 보고서는 그 결과로 계산.
  | 축 | 원천 | 산출 | 소비처 |
  |---|---|---|---|
  | **임대** | 반경 내 층별 임대정보(집단지성) | 층별 평균 임대시세 | [[S02-매물상세]] 매물에 등록 + 보고서 STEP3 |
  | **매각** | 반경 내 추정 매각이력(최근 5년) | curated 매각 comps | 보고서 STEP2 **적정매매가 재료**(가중평균 synthesis는 보고서) |
- [규칙] 여기선 **raw 조회 + curation까지**. 적정매매가(가치점수 가중평균)·가치점수 등 **synthesis는 보고서 전용**([[R-보고서]]).

## 2. 위치 · 동작
- **위치**: [[S02-매물상세]] **주변시세 블록**(인라인, 모달 아님). 다른 데이터처럼 S02 화면에서 바로 편집.
- [규칙] 상권 지정 → `재조회` → 임대·매각 comps 갱신. curation(체크 해제·× 삭제)·평균은 **인라인 즉시 반영**.
- [규칙] 층별 임대 평균 = 매물의 주변임대시세로 자동 반영(오버레이). curated 매각 comps = 보고서 적정매매가 재료로 저장.
- [규칙] **무크레딧**(조회·curation). 크레딧은 보고서에만.

## 3. 화면 요소별 동작

### 3.1 ① 상권 설정 (인라인 지도 · 중심+반경 사용자 지정)
- [규칙] **주변시세 블록 안 인라인 지도**에서 **상권 원(중심 + 반경) 직접 지정**. **★ 상권 중심 ≠ 본매물** — 상권은 여러 요소가 복합 작용해 정해지므로 중심을 자유롭게 옮김(본매물은 참조 마커). 별도 모달 아님(다른 데이터와 동일하게 S02 인라인 편집).
- [규칙] 상권 1번 지정 = **임대·매각 동시 스코프**. [[R-보고서]]가 이 상권을 그대로 사용.
- [규칙] 상권은 매번 직접 설정(저장·재사용 안 함, 상권 객체 저장은 나중).
- [규칙] **임대 조회 층 범위**(지하 N~지상 N) 입력. `분석하기` → 임대·매각 동시 조회.

### 3.2 ② 주변 임대시세 (조회·curate·등록)
- [규칙] 표: 체크·층·계약면적·전용면적·보증금·임대료·**평당보증금·평당임대료**·관리비·주소·삭제. **평당의 "평"=계약면적 기준**([[S02-매물상세]] §3.5).
- [규칙] **이상치 자동 표시** → 기본 체크 해제(평균 제외). 유저가 체크/해제·삭제로 curate.
- [규칙] 체크된 행만 **같은 층끼리 평균** → 층별 평당 평균 + **추정보증금/임대료**(= 평당평균 × 본매물 층 계약면적).
- [규칙] `임대 평균 → 매물 등록` → [[S02-매물상세]] 매물의 주변임대시세로 반영(단방향, 오버레이).

### 3.3 ③ 주변 매각 comps (조회·curate·저장)
- [규칙] 표: 체크·주소·거리·거래일·매각가·연면적(평)·**연면적 평단가**·삭제. (**최근 5년(2021~2026)** 추정 매각이력, 반경 내 전부)
- [규칙] **이상치 자동 표시** → 기본 체크 해제. 유저 curate(× 삭제 포함).
- [규칙] **"추정 매각" 고지**(RTMS 지번 마스킹).
- [규칙] `매각 comps 저장` → curated 세트를 보고서 STEP2 적정매매가 재료로. (여기선 가중평균·적정매매가 계산 안 함 — 보고서에서 가치점수 가중 synthesis)

## 4. 상태 · 규칙
- [규칙] 임대 등록·매각 comps 저장 = **오버레이(사적)**, 팀 공유범위 따름([[S02-매물상세]] §1.1 ②).
- [규칙] 상권(중심·반경)·층범위·체크상태는 매물 세션 유지. 재조회 시 갱신.
- [규칙] 적정매매가·가치점수·예상수익률은 **여기서 안 보여줌**(보고서 전용).

## 5. 데이터 연결
- [데이터] 입력: **상권(중심 좌표 + 반경, 사용자 지정)** · 임대 조회 층범위.
- [데이터] 임대 조회: 반경 내 **층별 임대정보**(집단지성, `data-overview` G4).
- [데이터] 매각 조회: 반경 내 **추정 매각이력**(최근 5년, `data-overview` G6~7).
- [데이터] 산출: 층별 임대 평균(오버레이) · curated 매각 comps(오버레이) → 보고서가 소비.

## 6. 예외
- 임대 데이터 0건/희소(콜드스타트) → "데이터 부족" 안내(보완책 베타 후).
- 매각 comps 0건 → **반경 넓혀 해결**(매각은 추정이력 8만동, 콜드스타트 아님). 최대 반경도 희소하면 적정매매가 산정 불가(보고서에서 표기).
- 이상치만 남고 정상치 0 → 평균/comps 없음 안내.
