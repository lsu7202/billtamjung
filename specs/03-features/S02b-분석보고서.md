## 1. 목적/역할
- [[S02-매물상세]] `[매물 분석하기]`(30크레딧)와 **보고서 생성 사이의 중간 검토 창**(모달). [[R-보고서]] §2 "생성 모달"의 확장.
- **왜 필요한가**: S02→보고서가 지금은 블랙박스(누르면 바로 생성). 그 사이에 **가치점수·적정매매가의 입력을 검토·조정**하는 자유도를 준다. 특히 **추정값(유동인구 등)** 을 유저가 확인·보정할 수 있게.
- **모토 유지 원칙**: 기본값은 전부 **시스템 자동**(마스터 + 시스템 추정)이라 **아무것도 안 만져도 생성된다.** 조정은 강요가 아니라 권한. → *"앱=raw+curation 무료, synthesis만 유료"*([[R-보고서]] §1) 철학 그대로.
- **브리핑(10크레딧)은 이 창을 거치지 않는다** — 분석 없음(가치점수·적정매매가 없음). 브리핑은 R §4대로 바로 생성 모달(옵션 확인만).

## 2. 진입 · 이탈
- **진입**: [[S02-매물상세]] `[매물 분석하기]`.
- **이탈**:
  - `[생성 확정]` → synthesis 잡(F-16/17/18/19 계산, R §2a) → **웹 보고서로 렌더**(리치 컴포넌트·2트랙, R §6a). **PPT 다운로드는 그 웹 보고서에서 export**(2차·후속). 크레딧은 **생성 성공 시** 차감.
  - `[취소]`/`×`/배경 → 조정값 폐기하고 S02로. (조정은 이 창에서만 임시 — 보고서 스냅샷에만 반영, S02 오버레이는 §4 참조)

## 3. 화면 요소별 동작

### 3.1 레이아웃 (모달, 위→아래)
1. **헤더**(네이비) — `분석 보고서 - 명세서` · 매물주소 · 닫기(×). **크레딧은 헤더에 안 넣음**(§3.6 명세로).
2. **상권 지도** — 반경 원 + **반경 내 매물 위치 오버레이**(중심=본매물, 실거래=보라·임대=초록 핀) + 범례. **읽기전용** — *반경 설정은 [[S02-매물상세]] 주변시세에서.* 캡션: 중심·반경·실거래 N건·임대 M건.
3. **주변 실거래사례** — comp 리스트(펼침 편집, §3.4)
4. **주변임대 포함/제외** — 토글(R §2·§5.4)
5. **우측: 실시간 산출 미리보기 + 크레딧 명세**(§3.6)
6. **하단 바** — `[취소]` · `[생성 확정 (크레딧 30)]`

> **본매물 값은 여기서 수정하지 않는다.** 본매물 가치점수 입력은 [[S02-매물상세]]에서 이미 편집 완료 → 우측 미리보기에 **참고 표시만**. 수정 대상 = **반경 내 주변매물(comp)뿐.**

### 3.2 ★ 통일 정보 컴포넌트 = ⓘ 아이콘 + 호버 툴팁 (`.info-i`)
- [규칙] 추정값·자동산출값 등 **부연 설명이 필요한 값 옆엔 통일된 ⓘ 아이콘**을 붙인다. 마우스 호버 시 설명 툴팁(부동산플래닛식). 임시 placeholder·span 금지. (v1 — 차차 개선)
- **유동인구 ⓘ 문구**: *"도로접면·역거리 기반 시스템 추정값입니다. 법적 효력이 없으니, 실제와 다르면 사용자 판단 하에 적절한 값으로 수정하세요."*
- [규칙] 남발 금지 — 추정값(유동인구) 등 **꼭 필요한 곳에만**. 점수·자동산출값은 화면에 노출하지 않으므로 ⓘ도 없음.
- [데이터] 정본 클래스 = `components.css .info-i`([[../07-architecture/02-유연성-설계원칙]] §4). [[S02-매물상세]] 등 추정값 표시에도 동일 재사용.

### 3.3 (삭제됨 — 본매물 입력은 S02 담당)
> 본매물 가치점수는 §3.1 참고표시로만. 편집은 [[S02-매물상세]] 상세정보·건물정보에서.

### 3.4 주변 실거래사례 검토 (핵심)  *(comp 가치점수 편집 제거 2026-07-29)*
- [규칙] 상권 반경 내 실거래 comps 리스트. 행 = `✓포함 · 주소 · 거리 · 거래일 · 실거래가 · 연면적 평단가 · 거리가중`. **가치점수는 표시하지 않는다** — F-17이 comp 가치점수를 쓰지 않기 때문(거리가중, `formulas.md` F-17 v2).
- [규칙] **★ comp가 적정매매가에 주는 경로 = 포함/제외 · 성격필터 · 시점(거래연월) · 거리뿐.** 유저의 검토 = **포함/제외 토글**(이상치 판단)이 전부. comp의 물적 속성(도로·역·용도 등) 편집 UI는 **없앤다** — 적정가에 영향이 없어 오도 소지.
  - *(이력)* v1은 "행 펼침 → comp 가치점수 입력 9종 편집 → 유사도 가중 갱신" 설계였으나, F-17이 유사도가중을 폐기(거리가중 전환)하면서 **근거 소멸 → 편집 기능 제거**. comp 가치점수 편집이 필요하면 그 comp의 [[S02-매물상세]]에서(별도 경로, 그 건물 오버레이).
- [규칙] **이상치 기본 제외**(체크 해제, `이상치` 뱃지) — [[S03-주변시세]] curation과 동일. 포함/제외 조정 시 적정매매가 재계산.
- [규칙] comp 주소 클릭 → 그 매물 [[S02-매물상세]](새 탭/이탈 경고).

### 3.5 주변임대 포함/제외 (③)
- [규칙] R §2·§5.4 토글. 포함 시 STEP3(주변임대시세)→STEP4(예상수익률) 반영, 제외 시 STEP3 생략·STEP4는 현재 임대료 폴백(R §5.5).

### 3.6 우측: 실시간 산출 미리보기 + 크레딧 명세
- [규칙] **미리보기 계기판 (현재/미래 2트랙, `formulas.md`)**:
  - **현재가치**: **매도희망가** · **적정매매가**(F-17) · **협의금액**(매도희망가−적정매매가) · **예상수익률**(F-18).
  - **미래가치**: **가치점수(등급)**(F-16) · **임대 상향여력**(F-19).
  - comp 포함/제외에 따라 즉시 갱신(무크레딧 — 생성 전 무료, R §2). 가치점수는 comp와 무관(본매물 값).
- [규칙] **크레딧 명세**(미리보기 아래): `현재 보유 크레딧` · `차감 예정(−30, 분석 보고서)` · **`예상 잔여 크레딧`**(강조). 헤더엔 크레딧 미표시.
- [예외] 상권 실거래 0건 → 적정매매가 "산정 불가" 표기, 반경은 [[S02-매물상세]]에서 넓히기 유도(R §7). 생성은 가능.

## 4. 상태 · 규칙
- [규칙] 이 창의 comp 조정(포함/제외·유동인구)은 **이 보고서 스냅샷에만 반영** — 기본은 일시. `[생성 확정]` 시 그 값으로 synthesis.
  - comp 유동인구 보정을 **그 매물 오버레이로 승격**(팀 공유·재사용)하려면 각 comp의 [[S02-매물상세]]에서 직접 수정(별도 경로). 이 창은 빠른 검토용.
- [규칙] 크레딧은 **생성 성공 시 차감**(R §2a). 검토·미리보기·취소는 무크레딧.
- [규칙] 상권(중심·반경)은 [[S02-매물상세]] 주변시세에서 설정한 값을 **읽기전용으로 표시**(지도 오버레이). 반경 변경은 S02에서(R §3).

## 5. 데이터 연결
- [데이터] 입력 = S02 값(master+overlay) + 시스템 추정(유동인구 proxy). comps = [[S03-주변시세]] 반경 실거래/임대.
- [데이터] 산출 = F-16(가치점수)·F-17(적정매매가)·F-18(예상수익률)·F-19(임대 상향여력), 파라미터 = `ref.formula_params`(버전).
- [데이터] 생성 확정 → `app.reports` 잡 + 스냅샷(조정값·상권·formula 버전).

## 6. 예외
- 상권 실거래 0건 → 적정매매가 산정 불가, 생성은 가능.
- 유동인구 등 추정 실패(도로·역 결측) → 해당 항목 0점, 안내.
- 크레딧 부족 → 생성 차단(베타=기록만).
