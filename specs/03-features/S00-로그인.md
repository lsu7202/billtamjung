## 1. 목적/역할
- 서비스 진입 게이트. **로그인 안 하면 어떤 화면도 못 봄**(전 화면 인증 전제).
- 가입 = 계정 생성 + **체험판(1개월) 자동 시작**(검색 무제한 + 크레딧 60).

## 2. 진입 · 이탈
- **진입**: 미인증 상태로 앱 접근 시 무조건 이 화면. (딥링크로 특정 매물 접근해도 로그인 후 그 매물로 복귀 — [정식])
- **이탈**: 로그인/가입 성공 → **S01 매물 목록**(기본 랜딩). 실패 시 화면 유지 + 오류 표시.

### 3.3.1 전화번호 인증 (어뷰징 방어의 핵심) **[정식]**

> **MVP 제외 결정 (2026-07-19).** MVP는 이메일 가입만으로 진입한다.
> **감수하는 리스크**: 이메일은 무한 생성 가능하므로, MVP 기간에는 다중계정으로 체험판(크레딧 60)을 반복 발급받는 어뷰징을 막을 수단이 없다.
> **완화**: 베타는 **무결제·그림자 계량**(크레딧 소비만 기록, 실제 차단 없음)이라 어뷰징의 금전적 실익이 없다. 크레딧이 실제로 돈이 되는 **정식 전환 시점에 본 절을 필수로 활성화**한다.
> → 정식 전환 전까지는 이 방어선이 없다는 점을 과금 설계(`05-business/credit-policy.md`)에서 전제할 것.

- [규칙] **왜 필요한가**: 이메일은 무한 생성 가능 → 다중계정으로 체험판(크레딧 60)을 무제한 재발급받는 어뷰징 차단 불가. **전화번호는 1인 1번호**라, 이게 실질 방어선.
- [규칙] **★ 1 전화번호 = 1 계정.** 이미 가입에 사용된 번호로는 **재가입 자체가 불가**([예외] "이미 가입된 번호입니다"). → 다중계정·체험판 재발급 어뷰징을 **원천 차단**. (계정 삭제 후 재가입 허용 여부·쿨다운 = 정책 TBD)
- [규칙] SMS 인증: 번호 입력 → 6자리 코드 발송 → 유효시간(예 3분)·재발송 제한(예 회당 대기)·시도 횟수 제한.
- [데이터] 전화번호(정규화·암호화)·인증완료 시각. **번호는 계정의 유일 식별자 중 하나**(이메일과 함께).
- [예외] 이미 가입된 번호 = 가입 차단. 코드 불일치/만료 = 재입력. 발송 실패 = 재시도. 가상번호(VoIP)·해외번호 차단 여부 = [정식] 정책 TBD.
- [정식] 소셜 가입도 최초 1회 전화번호 인증 요구(동일 방어).

### 3.4 소셜 로그인 [정식]
- 카카오·네이버 — 정식 출시. MVP엔 비활성(‘정식’ 뱃지).
- [규칙] **★ 전화번호 기준 자동 연동**: 소셜 로그인도 전화번호를 받아(소셜 제공 or 별도 인증), **그 번호가 기존 계정에 있으면 그 계정으로 자동 로그인**(새 계정 안 만듦). 없으면 신규 계정 생성 + 최초 1회 전화번호 인증.
  - → "1 전화번호 = 1 계정"이 이메일·소셜을 관통. 소셜로 우회한 다중계정·체험판 재발급 **원천 차단.**
  - → 한 사람이 이메일로 가입했다가 카카오로 로그인해도 **같은 계정**(계정 분열 없음).
- [예외] 소셜이 전화번호를 안 주면 → 별도 SMS 인증으로 번호 확보 후 연동.

## 4. 상태 · 규칙
- [규칙] **체험판 자동 시작**: 가입 즉시 체험판(1개월)·크레딧 60 부여. **단 전화번호당 1회만**(§3.3.1). 종료 후 상태는 `credit-policy.md` (TBD: 완전잠금 vs 읽기전용).
- [규칙] 검색은 구독 무제한, 크레딧은 보고서에만 소모 — 계정에 티어·크레딧 잔량 귀속.
- [규칙] 인증 세션 만료 시 재로그인 유도 → 로그인 후 **작업 중이던 화면으로 복귀**(베타 포함 기본 동작).

## 5. 데이터 연결
- [데이터] 계정: 이메일(id)·비밀번호(해시)·이름·중개사무소명(선택)·**전화번호(정규화·암호화)·인증시각**·가입일·티어·크레딧잔량·약관동의(시각).
- [데이터] **체험판 수령 이력(전화번호 기준)** — 어뷰징 방어용, 계정 삭제 후에도 유지.
- [데이터] 세션: 액세스/리프레시 토큰(로그인 유지 여부).
- ※ 계정은 **사적 레이어의 소유자** — 내 매물·CRM·크레딧이 이 계정에 귀속.

## 6. 예외
- 이메일 중복 가입 시도 → 오류.
- 로그인 실패 → 존재여부 노출 안 하는 통합 메시지.
- 네트워크 실패 → 재시도 안내.
- [규칙] 소셜 ↔ 이메일 계정 = **전화번호로 자동 연동**(§3.4) — 별도 병합 절차 없이 같은 번호면 같은 계정.
