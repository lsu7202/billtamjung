## 1. 목적/역할
- [[S01-매물통합검색]]의 `[필터]`로 뜨는 **조건 입력 모달**. 뒤로 S01 결과가 흐리게 비침.
- **결과 목록은 S01에만.** 모달 안엔 리스트도 건수도 없음. 건수는 **적용 후 S01 결과바**에서 확인.
  - ~~예상 건수 실시간 노출~~ **폐기(2026-07-19)** — 조건 변경마다 전수 COUNT는 DB 부하 대비 실익이 없다.
- 조건 지정 → `[적용]` → 모달 닫히고 S01 결과·칩에 반영.

## 2. 진입 · 이탈
- **진입**: S01 `[필터]`.
- **이탈**:
  - `[적용]` → 닫힘 + S01 재조회(§3.2 칩 동기화).
  - `[취소]`/`×`/배경 클릭 → 변경 폐기하고 닫힘.
- [규칙] 검색·건수 미리보기는 **무크레딧**([[S01-매물통합검색]] §3.1).

## 3. 화면 요소별 동작

### 3.1 레이아웃 (위→아래)
1. **헤더** — 제목 · **평/㎡ 토글** · `[불러오기]` `[조건저장]` · 닫기(×)
2. **지역 앵커**(항상 표시) — 시/도 · 시/군/구 · 법정동 3단 select (§3.4)
3. **적용된 조건 칩바** — 걸린 전체 조건을 칩으로, 각 `×` 개별 제거
4. **좌측 인덱스 + 우측 패널**(본체, §3.3)
5. **하단 바** — `[전체 초기화]` · 적용 조건 N개 · `[취소]` · `[적용]`

### 3.2 조건 칩 동기화
| 요소 | 동작 |
|---|---|
| 적용 조건 칩바 | [규칙] 지금 걸린 전 조건을 칩으로. `×`로 개별 제거. |
| 조건 개수 | [규칙] 하단 "적용 조건 N개" = 활성 조건 수. |
- [예외] 조건이 과도해 0건이어도 적용은 가능(S01에서 빈 상태). 과도 조건은 유저 판단.
- ~~예상 건수 실시간 재계산~~ **폐기(2026-07-19)**. 건수 확인은 적용 후 S01 결과바에서.

### 3.3 인덱스 + 패널 (핵심 구조)
- [규칙] **좌측 인덱스 탭 + 우측 패널**(아코디언 폐기 — 스크롤 과다 방지). 우측 패널 **내부 스크롤**(높이 고정).
- 인덱스 = `⭐ 자주 찾는 조건` + **7 카테고리**(= [[S02-매물상세]] 섹션명과 일치): 입지·건물·토지·금액·상세·공시지가/매각/광고·업무. 각 항목에 **적용 개수 뱃지**.
- [규칙] **전 필드 = 값칩 + 팝오버로 통일**. 컨트롤 실체는 한 곳(`#ctl-store`)에만 존재, **칩 클릭 → 팝오버로 이동해 편집**. 카테고리 탭은 `대표조건 칩` + `세부조건 칩` 두 묶음.

### 3.3.1a 필드 커버리지 (컬럼정의서 대조 · 2026-07-15)
- [규칙] **건폐율/용적률 여유분 추가**(건물정보): `법정−실제 = 증축여력`. 듀얼 슬라이더(%p, 이상). **증축 가능 매물 발굴**의 핵심 필터. (데이터는 법정치와 함께 강남만 산출 → 전서울 확장 예정)
- [규칙] **규제 7종(개발제한·고도·지구단위·정비·경관·방화·문화재)은 검색 필터에서 보류**. 근거: 대부분 "찾는 조건"이 아니라 "확인 정보"라 [[S02-매물상세]] 규제·특례 블록에 표시로 충분. 정비구역만 향후 후보(전서울 규제 확장 후).
- [규칙] **건물명 검색 없음**(불필요 확정). 주소는 S01 검색바 담당.

### 3.3.2 대표조건(⭐ 자주 찾는 조건 = 15개)
- 매매가 · 수익률 · 역과의거리 · 건물용도 · 매각일 · 광고가 · 대지면적 · 연면적 · 엘리베이터 · 주차장 · 건축면적 · 용도지역 · 진행상태 · 소유자타입 · 사용승인일
- [규칙] 값칩 균일 그리드(라벨 구분 없이 흐름).

### 3.4 지역 앵커 = 기본 select 3단(누적) + 영역 그리기
- [규칙] 시/도 → 시/군/구 → 법정동 **기본 select**(검색형 태그박스 폐기 — 무거움).
- [규칙] **캐스케이드**: 상위 선택 시 하위만 노출. 법정동(또는 "○○ 전체") 선택 → **조건에 누적 추가**(`지역 강남구 논현동` 칩). 여러 개 누적 = 다지역 검색.
- [규칙] 주소(지번/도로명) 직접 입력은 **S01 검색바 담당** — 세부검색에서 제외.
- [규칙] **★ 영역 그리기 연동**(2026-07-21, [[S01-매물통합검색]] §3.6c): 지역 앵커에 `🗺️ 지도에서 영역 그리기` 진입점. 누르면 지도로 전환해 영역을 그리고, 그린 폴리곤이 **범위**가 된다.
  - **범위는 검색바·필터 모달 공유 상태**: 법정동 앵커 ↔ 그린 영역은 **배타**(영역이 동 범위 대체). 그린 영역이 있으면 여기 지역 앵커도 `✏️ 그린 영역`(다시 그리기·지우기)로 표시되고 3단 select는 비활성.
  - 그린 영역도 **조건 저장/불러오기**(§3.7)에 폴리곤(GeoJSON)으로 포함.

### 3.5 토지이용상황 = 섹터 그룹 다중선택 + 디벨롭 프리셋
- [규칙] **6 섹터**(상업용빌딩·상가주택·주거·공업/산업·신축부지·특수/기타)로 묶되 개별 선택도 가능. 저장값 = 개별 코드 집합(섹터는 입력 편의 래퍼).
- [규칙] 섹터 체크=전체 / `▸`=개별 펼침 / 일부 선택=중간(–) 상태. 칩 요약 `상업용 빌딩 전체 외 2`.
- [규칙] **⚡디벨롭 프리셋**(섹터 위 빠른선택) = 배타 아닌 **크로스 태그**. 재개발·용도전환 유망 11값을 여러 섹터에서 한번에 토글. 정확히 그 세트면 칩 `디벨롭`.
- 상세 코드 매핑 = `S01b-plan.md` §6-2 / `codes-vworld.md`.

### 3.6 기타용도 = 텍스트(부분일치) + 프리셋 칩
- [규칙] 건축물대장 `etcPurps`(서술형·표준코드 없음) → 자유입력 부분일치. 소속=건물정보.
- 프리셋 칩: 근린생활시설·사무소·업무시설·단독주택·다가구주택·소매점·판매시설·상가(클릭 시 입력창 채움).

### 3.7 조건 저장 / 불러오기
| 요소 | 동작 |
|---|---|
| `[조건저장]` | [규칙] 현재 조건에 이름 붙여 저장(같은 이름 덮어쓰기, 빈 이름·0조건 경고). 전 필드 직렬화. |
| `[불러오기]` | [규칙] 저장 목록(이름·조건개수) → `[불러오기]`(상태 복원)/`[삭제]`. |
- [데이터] 저장 목록은 계정 귀속 — [[S0M-마이페이지]] §3.4 "저장한 검색 조건"과 동일 소스.

### 3.8 표시 단위
- [규칙] 화면 표시단위 ≠ 저장단위(저장=원/숫자/㎡/ISO). 헤더 **평/㎡ 토글**로 면적 표기 전환.
- [규칙] **공시지가 = 만원/㎡**(원 아님). 금액 눈금은 균등분할 아니라 **매물 몰리는 값**에 배치(실분포로 재확인 예정).

## 4. 상태 · 규칙
- [규칙] 모달 상태는 열려있는 동안만 임시 — `[적용]` 전엔 S01에 미반영. `[취소]`=폐기.
- [규칙] 조건은 **건물 단위**로 매칭([[S01-매물통합검색]] §3.0 — 부속지번 중복 없음). 걸침 값(용도지역 등)은 병기 저장분으로 건물 단위 매칭.
- [규칙] 슬라이더 끝 핸들=무한(이상/이하), 값칸 직접입력은 눈금 상한 무시 가능.

## 5. 데이터 연결
- [데이터] 필드 정의·검색타입·단위 = `04-data/data-overview.md`. 값 목록 = `04-data/enums.md`.
- [데이터] 적용 조건 → 직렬화 쿼리 → S01 조회 파라미터.
- [데이터] 저장 조건 = 계정별 필터 스냅샷(JSON).

## 6. 예외
- 0건 예상: 적용 허용(S01 빈 상태 안내).
- 지역 미선택 + 광범위 조건 → 전 서울(대량) — S01 페이징이 처리.
- 슬라이더 역전 입력(하한>상한) → 자동 정렬(min/max 스왑).
- 저장 이름 빈값/0조건 → 경고, 저장 차단.
