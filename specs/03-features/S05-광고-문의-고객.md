# S05 광고 · 문의 · 고객

> 2026-09-28 대표 결정으로 짠 명세. 근거 조사: [밸류맵-디스코-견주기](../06-review/밸류맵-디스코-견주기-2026-09-28.md).
> S01 매물통합검색의 탭 · 사이드 판 부분은 이 문서가 앞선다.

## 1. 화면은 하나, 차이는 권한 하나

중개사와 고객은 **같은 화면**을 본다. 다른 것은 **매물관리 시스템을 쓸 수 있는가** 하나다.
그 기준은 **계정 종류 `accounts.kind`(중개사 · 고객)** 다(대표 09-28). 팀 소속은 「데이터가 사는 곳」이라 따로다.

| | 누구나 | 중개사에게만 더 |
|---|---|---|
| 윗메뉴 | 건물 검색 · 어시스턴트 · 소식 · 마이페이지 | 매물관리 · 고객관리 · 일정 |
| 검색 탭 | 실거래 · 매매 · 전체 | 매매 탭의 「내 매물」 칩 · 파랑 핀 |
| 사이드 판 | 광고 카드 · 건물 요약 · 상세보기 | 크롤링 매물 참고 줄 |
| 건물 상세 | 대장 · 실거래 · **추정가** · 층별 정보 · 입주 이력 · 주변 소식 | 소유자 · 메모 · 매수자 · 크롤링 호가 · 「매물관리에서 보기」 |
| 광고 | 보기 · 저장 · 상담요청 · 신고 | 올리기 · 고치기 · 내리기 |
| 문의 | 보내기 · 내 문의 내역 | 받기(고객관리) |

- 막는 곳은 **API** 다. 기본 의존성(`current_user`)은 중개사가 아니면 403, 누구나 쓰는 라우트만 `any_user` 로 푼다
  (검색 · 건물 상세 · 실거래 · 소식 · 층별 정보 · 사전 · 광고 보기). 팀 칸은 team_id 가 없으면 SQL 에서 빠진다.
- 어시스턴트는 고객용 도구 묶음 전까지 중개사만.
- 내 매물이 없는 계정에는 「내 매물」 칩이 서지 않는다. 화면 모양은 같다.

## 2. 검색

### 탭

| 탭 | 무엇 | 핀 |
|---|---|---|
| 실거래 | 국토부 실거래. 건물마다 최근 거래 하나 | 회색 · 거래가 · 년월 |
| 매매 | 노출 중인 매매 광고. 중개사는 칩으로 「내 매물」(광고 안 한 것 포함)을 더 본다 | 광고 검정 · 내 매물 파랑 |
| 전체 | 전 건물 추정가 | 회색 · 「추정」 |

- 매매 탭 칩(팀 계정만): 전체 · 내 매물 · 광고만.
- 한 필지에 광고가 여럿이면 묶음 핀 하나. 숫자를 단다.
- 돈을 들인 광고가 위에 설 때는 카드에 「광고」 표시. 정렬 칩(가격 · 면적 · 최근)으로는 돈과 상관없이 찾을 수 있다.
- 결과가 없으면 「조건 남기기」(§5-3).

### 사이드 판

핀을 누르면 왼쪽 판이 열린다.

1. **광고** — 그 건물의 노출 중 광고 N건. 카드: 매매가 · 대지 · 연면적 · 규모 · 전속 · 중개사(사진 · 이름 · 사무소) · 상담요청 아이콘. 광고가 없으면 이 칸은 서지 않는다.
2. **건물 요약** — 대지 · 연면적 · 규모 · 용도지역 · 사용승인일 · 추정가 · 최근 실거래.
3. **크롤링 매물**(팀 계정만) — 이 건물에 시장에 나온 매매 · 임대 호가. 가격 · 층 · 면적 · 게시 사무소 · 마지막 확인일.
4. 「상세보기」 → 건물 상세.

## 3. 광고

### 올리기

- 자동으로 켜지지 않는다. 매물관리의 매물 모달에서 **광고 폼(모달)** 을 작성하고 「올리기」를 눌러야 노출된다.
- 소유자 미확보 매물도 올릴 수 있다.
- 폼은 매물과 대장 값으로 미리 채운다. 중개사가 고칠 수 있고, 고친 값은 광고에만 남는다(매물은 그대로).

| 칸 | 미리 채움 | 비고 |
|---|---|---|
| 거래유형 | 매매 | 지금은 매매 하나 |
| 중개유형 | 매물의 전속 칸 | 일반 · 전속 |
| 매매가 | 매물 매매가 | 필수 |
| 가격 공개 | 공개 | 비공개면 카드에 「가격 문의」(밸류맵 priceVisible) |
| 대지 · 연면적 · 규모 · 용도지역 · 사용승인일 | 대장 | |
| 사진 | 매물 사진 중 고름 | **3장 이상**(밸류맵 규정), 순서 |
| 위반건축물 | 대장 | 있으면 카드에 표시 |
| 제목 · 설명 | 없음 | 자유글은 이 두 칸뿐 |
| 연락처 | 담당 중개사 전화 | |
| 위치 공개 | 공개 | 비공개면 동까지만 |

### 상태

칸을 나눈다.

| 칸 | 값 |
|---|---|
| `state` | 노출 · 비노출 · 거래완료 · 삭제. 거래완료는 되돌리지 않는다 |
| `review` | 통과 · 검수중 · 반려(+사유). 첫 판은 통과로 시작, 신고가 들어오면 검수중 |
| `expires_on` | 무료 노출 기한(올린 날 + 30일). 매물관리에서 「확인」을 누르면 30일 연장. 지나면 「지난 광고」로 남긴다(지우지 않는다) |
| `address_open` | 위치 공개 여부 |

- 매물이 계약되면(계약 칸) 광고 state 를 거래완료로 돌리자고 묻는다.
- **거래완료 광고는 지도에 회색으로 남긴다**(밸류맵). 거래일 · 중개한 사무소가 보인다. 되돌리지 않는다(디스코).

### 노출 순위

- 광고 등록은 무료. 돈은 **노출 순위**로 받는다(대표 09-28).
- 첫 판은 칸만 둔다(`app.ad_boosts`). 순위 규칙 · 가격은 나중에 정한다.

## 4. 문의(상담요청)

- 광고 카드 또는 광고가 있는 건물 상세에서 「상담요청」. 로그인 필요.
- 폼(모달): 유형(**매수 문의 · 매도 문의 · 시세 문의**, 밸류맵) · 내용(200자) · 이름 · 전화 · 개인정보 동의. 이름 · 전화는 프로필에서 미리 채운다.
- 보내면 그 광고를 올린 **팀의 고객관리**에 「새 문의」로 선다.
- 상태: **미확인 · 상담중 · 고객등록 · 종료**(대표 09-28).
  - 미확인: 아무도 안 열어 봄. 중개사가 열면 상담중.
  - 고객등록: 고객관리 명단에 올림. 매수 문의는 매수자로, 매도 문의는 매물(소유자)로. 이후는 그쪽 흐름을 탄다.
  - 종료: 연결되지 않고 끝남.
- 광고의 연락처(전화)는 카드에 그대로 보인다. 채팅은 칸만 둔다.

## 5. 고객

### 5-1. 프로필

| 칸 | 값 |
|---|---|
| 의사 | 매수자 등급 사전 그대로(buyer_grade: 확실 · 보통 · 관망). 고객등록 때 buyers.grade 로 옮겨 적는다 |
| 이해도 | 처음 · 관심 · 공부해봄 |
| 목적 | 실사용 · 투자 · 신축 (여럿) |
| 지역 | 구 (여럿) |
| 예산 | 최소 · 최대 |
| 메모 | 자유글 |

- 모든 칸은 고객이 직접 적는다. 모르면 비운다(null).
- 상담요청이 오면 중개사는 이 프로필을 함께 본다.

### 5-2. 관심 저장

- **건물 저장 · 광고 저장 둘 다**(두 곳 모두 둘 다 있다). 메모 한 줄.
- 광고가 내려가도 건물 저장은 남는다. 저장한 건물에 광고가 새로 오르면 알림.
- 폴더(디스코)는 뒤로.

### 5-3. 조건 남기기

- 검색 조건을 이름 붙여 저장하고 「알림 받기」를 켠다(`app.saved_searches` 에 칸을 더한다).
- 새 광고가 조건에 맞으면 알림을 쌓는다(`app.want_alerts`). 조건 개수 제한은 두지 않는다.
- 중개사 쪽 공개(「찾아주세요」 · 매입 요청)는 뒤로.

## 6. 신고

- 광고 상세의 더보기 → 신고. 로그인 계정만.
- 사유: 거래완료된 매물 · 표시정보가 실제와 다름(무엇이 다른지 필수).
- 상태: 확인중 · 처리 · 반려. 들어오면 광고 review 가 검수중이 된다.

## 7. 크롤링 매물 (팀 계정만)

- 매매 · 임대 호가를 **광고가 아니라 참고 자료**로 둔다. 고객에게는 나가지 않는다.
- 붙는 자리: 사이드 판(§2), 건물 상세 층별 정보 근처, 매물 모달 「임대 내역」 옆.
- 칸: 거래유형(매매 · 임대) · 가격 / 보증금 · 월세 · 관리비 · 층 · 계약면적 · 전용면적 ·
  **게시 사무소명 · 중개사 이름 · 중개등록번호 · 전화** · 처음 본 날 · **마지막 확인일** · 사라진 날.
  출처 사이트 · 원문 링크는 두지 않는다.
- 기존 임대 크롤 자료(주소로 붙인 6.7만 건)가 첫 적재분이다. 게시자 칸은 비어 있다.

### 가져오기

- 중개사가 가입해 중개등록번호가 인증되면, 같은 등록번호로 크롤링된 매물을 「다른 사이트에 올리신 매물 N건」으로 보여 준다.
- 고른 것만 그 팀의 매물이 된다(조용히 바꾸지 않는다).
- 가져오는 값: 주소 · 가격 · 면적 · 층. 사진 · 설명글은 가져오지 않는다.

## 8. 스키마

새 표는 전부 빈 채로 만든다.

| 표 | 칸 |
|---|---|
| `app.accounts` + | `kind text NOT NULL DEFAULT '중개사'` 중개사 · 고객 (기존 계정은 중개사로 채움) |
| `app.customer_profile` | account_id PK · intent(buyer_grade A · B · C) · literacy(처음 · 관심 · 공부해봄) · purposes text[] · regions text[] · budget_min · budget_max bigint · note · updated_at |
| `app.ads` | id · team_id · listing_id · building_pk · deal(매매) · brokerage(일반 · 전속) · price bigint · land_area · total_area numeric · floors_above · floors_below · zoning · approved_on · title · body · contact_account_id · contact_phone · address_open bool · price_open bool · violation bool · state · review · review_note · posted_on · expires_on · closed_on · created_by · created_at · updated_at |
| `app.ad_photos` | ad_id · photo_id · sort |
| `app.ad_boosts` | id · ad_id · amount_won · starts_on · ends_on · created_by · created_at |
| `app.inquiries` | id · ad_id · team_id · account_id(고객) · kind(매수 문의 · 매도 문의 · 시세 문의) · body(200자) · name · phone · consent_at · status(미확인 · 상담중 · 고객등록 · 종료) · buyer_id · listing_id(매도 문의가 매물이 되면) · handled_by · created_at · updated_at |
| `app.saves` | id · account_id · building_pk · ad_id(광고 저장이면) · memo · created_at (유일: account_id + building_pk + ad_id) |
| `app.saved_searches` + | `notify bool` · `closed_at` |
| `app.want_alerts` | saved_search_id · ad_id · matched_at · seen_at |
| `app.ad_reports` | id · ad_id · account_id · reason(거래완료 · 표시정보 다름) · body · status(확인중 · 처리 · 반려) · created_at · handled_at |
| `master.crawl_listing` | id · deal(매매 · 임대) · building_pk · pnu · price · deposit · rent · mgmt bigint · floor text · contract_area · excl_area numeric · office_name · agent_name · reg_no · phone · first_seen · last_seen · gone_on · claimed_team_id · claimed_listing_id |

- 선택지 값은 `ref.enum_groups` · `ref.enums` 사전에 넣는다(칩으로 그리기 위해).
- 지우는 칸: `app.listings.ad_status` · `ad_off`(광고는 `app.ads` 로).
- 팀 계정이 아니면 `master.crawl_listing` · 팀 표를 읽는 API 는 빈 값을 낸다.

## 9. 첫 판에서 하는 것 / 뒤로

| 첫 판 | 뒤로 (칸만) |
|---|---|
| 스키마 전부(빈 표) | 광고 검수 화면 · 소유주 인증 · 실매물확인서 |
| 검색 세 탭 + 사이드 판 + 권한 분기 | 채팅 · 후기 · 응답률 · 임시번호 |
| 크롤링 임대 호가 붙이기(기존 자료) | 노출 순위 규칙 · 가격 |
| 광고 폼 · 문의 폼 · 고객관리 「문의」 · 고객 프로필 · 관심 · 조건 남기기 | 크롤링 매매 수집 · 가져오기 화면 · 임대 광고 |
