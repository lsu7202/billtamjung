## 1. 목적/역할
- **로그인 후 기본 랜딩 화면.** 서울 **전 건물**을 주소·필터로 통합 조회.
- 서울 내 **모든 주소가 조회 대상** — 매물로 등록됐든 안 됐든 모든 건물이 검색된다("매물"=조회 단위).
- 결과를 **3종 우선순위**로 분류해 한눈에: 광고 · 내 매물 · 일반.
  | 분류 | 정의 | 의미 |
  |---|---|---|
  | 광고 | **광고가가 존재**하는 매물(매도자가 내놓음) | 매매 성사 확률 ↑ |
  | 내 매물 | **매물 등록**으로 담당자 지정된 것(사적 레이어, 팀 공유 반영) | 연락처·이력 확보 |
  | 일반 | 위 둘에 안 속하는 나머지 전 건물 | 발굴 대상 |

## 2. 진입 · 이탈
- **진입**: [[S00-로그인]] 성공 → 이 화면(기본 랜딩). GNB '검색'으로 재진입.
- **이탈**:
  - 행 `상세보기`/행 클릭 → [[S02-매물상세]] (해당 건물 PNU/PK로).
  - `필터` → [[S01b-필터]] 모달(뒤로 이 결과가 흐리게 비침).
  - `지도위치` → 지도 뷰로 전환 + 해당 핀 포커스.

## 3. 화면 요소별 동작

### 3.0 ★ 검색 단위 원칙 (대표지번-부속지번)
- [규칙] **결과 단위 = 건물(대표지번).** 한 건물이 여러 필지(대표+부속)에 걸쳐도 결과엔 **대표지번으로 1건**만 나온다.
- [규칙] **주소 인덱스 = 대표+부속 전 필지.** 부속지번도 **정확 주소로 검색은 된다**(검색 불가 없음).
- [규칙] **정확 주소 → 그 필지가 속한 건물(대표지번)로 귀결.**
  - 대표지번 입력 → 그 건물.
  - **부속지번 입력 → 관계표(annex)로 대표지번을 찾아 그 건물을 결과로**(부속→대표는 조용히 귀결, 별도 안내 없음).
- [규칙] **조건 검색(필터)에선 부속지번 필지가 별도 행으로 중복 노출되지 않음** — 건물 단위 dedupe(§3.4).
- [규칙] 필지별 데이터(공시지가·용도지역·법정치 = 필지 단위)는 [[S02-매물상세]] '관련 필지'에서 열람.
- [예외] **나지(건물 없는 필지)** = 필지 자체가 결과 단위(신축부지 검색용).
- [규칙] **왜 이렇게**: 대표-부속은 **여러 필지를 합쳐 건물 1채**를 지어 생긴 관계. 건물 매매는 보통 **통으로**(전 필지 한 번에) → 그래서 검색·**관리(내 매물)의 기본 단위 = 대표지번**(= 전 필지 묶음). 대표를 관리하면 부속 필지도 함께 관리됨. **간혹 필지를 쪼개 거래**하는 경우가 있어 필지 단위 관리·열람도 가능해야 함([[S02-매물상세]] 관련필지). → 매물 관리 단위는 [[S02-매물상세]] 명세에서 상세화.

### 3.1 검색바
| 요소 | 동작 |
|---|---|
| 주소 입력 | [규칙] **지번/도로명** 주소 검색(예: `강남구 역삼동 601-5`). 부분 입력 시 자동완성 후보([정식]). |
| [검색] | [규칙] 입력 주소 필지 → §3.0 원칙으로 **건물(대표지번)** 도출. 단일 결과면 바로 [[S02-매물상세]] 진입 가능, 다건이면 결과 목록. |
| **부속지번 입력 시** | [규칙] **대표 건물로 바로 이동**(별도 배지·안내 없이 자연스럽게). 해당 부속 필지 상세는 [[S02-매물상세]] '관련 필지'에서 접근. |
| [필터] | [규칙] [[S01b-필터]] 모달 오픈. 조건 지정·적용 후 결과 반영. |
| 뷰 토글(매물/지도) | [규칙] 리스트 ↔ 지도 전환. 지도에선 결과바(건수·정렬) 숨김. |
- [규칙] **검색은 구독 무제한·무크레딧.** 크레딧은 보고서에만 소모([[S0M-마이페이지]] §3.2).

### 3.2 적용된 필터 칩
- [규칙] [[S01b-필터]]에서 건 조건을 칩으로 나열, 각 `×`로 **개별 제거**(제거 시 즉시 재조회).
- [규칙] 지역 앵커(시/구/동)도 칩. 여러 지역 누적 가능.
- [예외] 칩 0개 = 전 서울 기본 조회(건수 큼 → §3.4 페이징).

### 3.3 결과바 (건수 · 정렬)
| 요소 | 동작 |
|---|---|
| 전체 N건 | [데이터] 현재 조건에 맞는 총 건수(3열 합). |
| 정렬 | [규칙] **매매가순 / 수익률순**(내림차순). 3열 각각 내부 정렬. |
- [예외] 값 없는 항목(추정가 없음)의 정렬 위치 = 후순위(뒤로). §3.5 참조.

### 3.4 결과 목록 (매물 뷰 — 3열)
- [규칙] **광고 · 내 매물 · 일반** 3열 병렬, 각 열 헤더에 건수. 우선순위 좌→우.
- 행 = `주소 · 매매가 · 수익률`. 호버 시 액션(`상세보기`·`지도위치`) 노출.
- [규칙] 행 클릭/`상세보기` → [[S02-매물상세]].
- [규칙] **건물 단위 1행(부속지번 dedupe)**: 조건 검색 시 한 건물은 대표지번으로 한 번만 노출(§3.0). 나지만 필지 단위 행.
- [규칙] **페이징/무한스크롤**: 일반 열은 대량(수백~수천) → 열별 지연 로딩. (방식 TBD: 무한스크롤 vs 페이지)
- [데이터] **내 매물 열** = 내 사적 레이어 + **팀 공유분**([[S0M-마이페이지]] §3.5 공유범위 따름).

### 3.5 표시 값의 성격 (매매가·수익률)
- [규칙] **매매가**:
  - 광고 = **광고가**(매도자 제시).
  - 내 매물 = 등록 시 입력가(없으면 추정).
  - 일반 = **추정 매각가**(매각 레이어 기반) — 없으면 `—`. **"추정" 고지**(RTMS 지번 마스킹 → 추정치, `data-overview` 매각 참조).
- [규칙] **수익률** = 추정(매매가 대비 추정 순임대수익). 임대 정보 부재 시 `—`.
- [예외] 추정 불가 건물은 값 `—` 표기, 정렬 후순위. 유저가 [[S02-매물상세]]에서 실제값으로 수정 가능.

### 3.6 지도 뷰
- [규칙] 결과 건물을 핀으로 표시. `지도위치` 진입 시 해당 핀 포커스.
- [규칙] 핀 클릭 → 요약 말풍선 → [[S02-매물상세]].
- [정식] 지도 이동/줌 시 영역 내 재조회, 클러스터링.

## 4. 상태 · 규칙
- [MVP] 검색 조건은 세션 유지 — [[S02-매물상세]] 갔다 뒤로 오면 결과·스크롤 복원.
- [규칙] 조건 저장/불러오기 = [[S01b-필터]] 모달에서 수행(저장 목록은 [[S0M-마이페이지]] §3.4).
- [규칙] 3열 분류는 **매물 상태**에 종속: 매물 등록 시 일반→내 매물, 광고가 등록 시 →광고.

## 5. 데이터 연결
- [데이터] 조회 원천 = 서울 통합뷰(건물 마스터 + 필지 + 매각/교통 등, `04-data/schema.md`).
- [데이터] 필터 조건 → 쿼리 파라미터([[S01b-필터]] 직렬화).
- [데이터] 내 매물 판정 = 매물등록 테이블(계정/팀 소유). 광고 판정 = 광고가 존재 여부.
- [데이터] 매매가(추정)·수익률(추정) = 매각·임대 파생([[S03-주변시세]]와 동일 소스).

## 6. 예외
- 검색 결과 0건 → 빈 상태 안내("조건에 맞는 매물이 없습니다") + 조건 완화 유도.
- 주소 오입력/미존재 → "해당 주소를 찾을 수 없습니다".
- 네트워크 실패 → 재시도.
- 대량 결과(전 서울) → 페이징/성능 가드(§3.4).
