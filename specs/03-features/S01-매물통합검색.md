## 3. 화면 요소별 동작

### 3.0 ★ 검색 단위 원칙 (대표지번-부속지번)
- [규칙] **결과 단위 = 건물(대표지번).** 한 건물이 여러 필지(대표+부속)에 걸쳐도 결과엔 **대표지번으로 1건**만 나온다.
- [규칙] **주소 인덱스 = 대표+부속 전 필지.** 부속지번도 **정확 주소로 검색은 된다**(검색 불가 없음).
- [규칙] **정확 주소 → 그 필지가 속한 건물(대표지번)로 귀결.**
  - 대표지번 입력 → 그 건물.
  - **부속지번 입력 → 관계표(annex)로 대표지번을 찾아 그 건물을 결과로**(부속→대표는 조용히 귀결, 별도 안내 없음).
- [규칙] **조건 검색(필터)에선 부속지번 필지가 별도 행으로 중복 노출되지 않음** — 건물 단위 dedupe(§3.4).
- [규칙] 필지별 데이터(공시지가·용도지역·법정치 = 필지 단위)는 [[S02-매물상세]] '관련 필지'에서 열람.
- [예외] **나지(건물 없는 필지)** = 필지 자체가 결과 단위(신축부지 검색용).
- [규칙] **왜 이렇게**: 대표-부속은 **여러 필지를 합쳐 건물 1채**를 지어 생긴 관계. 건물 매매는 보통 **통으로**(전 필지 한 번에) → 그래서 검색·**관리(내 매물)의 기본 단위 = 대표지번**(= 전 필지 묶음). 대표를 관리하면 부속 필지도 함께 관리됨. **간혹 필지를 쪼개 거래**하는 경우가 있어 필지 단위 관리·열람도 가능해야 함([[S02-매물상세]] 관련필지). → 매물 관리 단위는 [[S02-매물상세]] 명세에서 상세화.

### 3.1 검색바
| 요소 | 동작 |
|---|---|
| 주소 입력 | [규칙] **지번/도로명** 주소 검색(예: `강남구 역삼동 601-5`). 입력 시 **자동완성 드롭다운**(아래 §3.1a). |
| [검색] | [규칙] 입력 주소 필지 → §3.0 원칙으로 **건물(대표지번)** 도출. 단일 결과면 바로 [[S02-매물상세]] 진입 가능, 다건이면 결과 목록. |
| **부속지번 입력 시** | [규칙] **대표 건물로 바로 이동**(별도 배지·안내 없이 자연스럽게). 해당 부속 필지 상세는 [[S02-매물상세]] '관련 필지'에서 접근. |
| [필터] | [규칙] [[S01b-필터]] 모달 오픈. 조건 지정·적용 후 결과 반영. |
| 뷰 토글(매물/지도) | [규칙] 리스트 ↔ 지도 전환. 지도에선 결과바(건수·정렬) 숨김. |
- [규칙] **검색은 구독 무제한·무크레딧.** 크레딧은 보고서에만 소모([[S0M-마이페이지]] §3.2).

#### 3.1a ★ 주소 자동완성 (타입어헤드) *(신설 2026-07-21)*
- [규칙] 입력 즉시 아래로 **후보 드롭다운**. 다 안 치고 골라 진입 — 모든 검색·지도 앱 표준 UX.
- [데이터] **후보 소스 = 우리 통합뷰 주소 인덱스**(서울 전역 586,343동 지번주소). 외부 지오코딩 API 미사용 → 비용·의존 없음, 우리 매물·데이터와 100% 일치. *(도로명↔지번 매핑은 별도 보강 [정식])*
- [규칙] **매칭**: 공백 무시 부분일치. **정렬** = 접두일치 우선 → 동률이면 **매물 보유 건 우선**(내 매물 > 광고 > 일반) → 가나다순. 상위 **7건**.
- [규칙] **표시**: `구 동 지번`(모노스페이스) + 입력부 **시그널블루 볼드 하이라이트** + 매매가(보유 시) + 분류 배지(내 매물/광고). 헤더에 후보 건수.
- [규칙] **키보드**: ↑↓ 이동 · Enter 선택 · Esc 닫힘. 바깥 클릭 시 닫힘.
- [규칙] **선택 → 해당 건물**(대표지번 §3.0) 진입 or 지도 포커스. 후보 없으면 "일치하는 주소가 없습니다".
- 공용 컴포넌트(`.ac-*`, `wireframe.css`) — 타 화면 검색창도 동일.

### 3.2 적용된 필터 칩
- [규칙] [[S01b-필터]]에서 건 조건을 칩으로 나열, 각 `×`로 **개별 제거**(제거 시 즉시 재조회).
- [규칙] 지역 앵커(시/구/동)도 칩. 여러 지역 누적 가능.
- [예외] 칩 0개 = 전 서울 기본 조회(건수 큼 → §3.4 페이징).

### 3.2a ★ 즐겨찾기
- [규칙] 검색바에 `★ 즐겨찾기` **빠른 필터 토글** → 켜면 **즐겨찾기한 매물만** 표시.
- [규칙] 결과 **행의 ★**로 즐겨찾기 토글([[S02-매물상세]] 헤더 ★와 동일).
- [데이터] 즐겨찾기 = **개인 북마크**(계정 귀속·개인 전용, 팀 공유 X). 내 매물(등록·담당자)과 별개. 개수는 [[S0M-마이페이지]]에 표시.

### 3.3 결과바 (건수 · 정렬)
| 요소 | 동작 |
|---|---|
| 전체 N건 | [데이터] 현재 조건에 맞는 총 건수(3열 합). |
| 정렬 | [규칙] **매매가순 / 수익률순**(내림차순). 3열 각각 내부 정렬. |
- [예외] 값 없는 항목(추정가 없음)의 정렬 위치 = 후순위(뒤로). §3.5 참조.

### 3.4 결과 목록 (매물 뷰 — 3열)
- [규칙] **광고 · 내 매물 · 일반** 3열 병렬, 각 열 헤더에 건수. 우선순위 좌→우.
- 행 = `주소 · 매매가 · 수익률`. 호버 시 액션(`상세보기`·`지도위치`) 노출.
- [규칙] 행 클릭/`상세보기` → [[S02-매물상세]].
- [규칙] **건물 단위 1행(부속지번 dedupe)**: 조건 검색 시 한 건물은 대표지번으로 한 번만 노출(§3.0). 나지만 필지 단위 행.
- [규칙] **페이징**(확정 2026-07-19 — 무한스크롤 폐기): 일반 열은 대량(수백~수천) → **열별 독립 페이징**. 각 열 하단에 페이지 컨트롤. 3열의 건수가 극단적으로 다르므로(예 12 / 5 / 240) 열마다 페이지를 따로 넘긴다.
- [데이터] **내 매물 열** = 내 사적 레이어 + **팀 공유분**([[S0M-마이페이지]] §3.5 공유범위 따름).

### 3.5 표시 값의 성격 (매매가·수익률)
- [규칙] **매매가**:
  - 광고 = **광고가**(매도자 제시).
  - 내 매물 = 등록 시 입력가(없으면 추정).
  - 일반 = **추정 실거래가**(실거래 레이어 기반) — 없으면 `—`. **"추정" 고지**(RTMS 지번 마스킹 → 추정치, `data-overview` 실거래 참조).
- [규칙] **수익률** = 추정(매매가 대비 추정 순임대수익). 임대 정보 부재 시 `—`.
- [예외] 추정 불가 건물은 값 `—` 표기, 정렬 후순위. 유저가 [[S02-매물상세]]에서 실제값으로 수정 가능.

### 3.6 지도 뷰 (네이버 지도)

#### 선택 매물 요약 카드 (핀/행 클릭 시)
- 구성 = **S02 헤더의 축약**(통일감):
  - **로드뷰 1개**(선택 매물만) · 주소 · 3분류 태그 · ★즐겨찾기 · 매물번호·접수일·담당자
  - **계기판 지표**: 매매가 · 수익률(만실/공실제외) · 평단가(대지) · 층수 · 면적(대지/연면적/건축). **용도는 제외.**
  - **가격 추이 그래프 1개**: 실거래·공시지가·광고가 **시계열 3종을 한 그래프**에 겹쳐 표시(광고가는 점선). 호버 시 세로 가이드선 + 연도별 3종 값 툴팁.
    - [규칙] **계열색은 [[S02-매물상세]] 상세 차트와 공유**(공통 토큰 `--c-real`·`--c-gongsi`·`--c-ad`): 실거래=잉크, 공시지가=시그널블루, 광고가=퍼플. S01(개요·겹침)과 S02(상세·분리)는 레이아웃만 다르고 **색·툴팁 언어는 동일**. 등락 방향은 상승률 숫자색(`--up`/`--down`)으로만 표기.
  - `상세보기 →` [[S02-매물상세]].
- [규칙] **로드뷰는 선택한 1건만 로드**한다. 리스트 전체에 썸네일을 붙이지 않는다 — N건×이미지 = API 오버헤드.
- [데이터] 로드뷰 = 네이버 Panorama 정지 프레임(좌표 기반, 매도자 사진 불요).
- [규칙] **깊은 데이터(가치점수·규제·필지별 값·시계열 상세)는 넣지 않는다** — S02/보고서로. 부동산플래닛식 6탭 밀도를 지양하고 "중요한 것만".

|---|---|
| **일반 / 위성** | 배타 토글 — 네이버 `NORMAL` ↔ `SATELLITE`(`setMapTypeId`) |
| **지적도** | 독립 토글. **이중 구조**([[네이버지도-연동]] §1.1): 네이버 `CadastralLayer`(지적선 배경) + **우리 지적 폴리곤 GeoJSON**(클릭 히트영역, 투명). 필지 클릭 → 그 필지 공시지가·용도지역·규제 팝오버(우리 필지별 데이터) |
| **로드뷰** | 네이버 `Panorama` 패널 — 선택 지점 반경 300m 최근접 파노라마. [[S02-매물상세]] §3.2와 동일 |

- [규칙] 지적도는 일반/위성과 **독립**(둘 다 켤 수 있음). 로드뷰는 오버레이가 아니라 전환 패널.
- **★ 차별점**: 지적선만 보이는 경쟁사와 달리, **필지를 클릭하면 그 필지 데이터**(공시지가·규제)가 뜬다 — 우리가 필지 단위로 보유한 데이터를 지도에서 바로 활용.

#### 3.6b ★ 클러스터 상호작용 *(2026-07-21 — 무동작 → 정의)*
- [규칙] **밀집 시 클러스터**(숫자 버블) 표시.
- [규칙] **클러스터 클릭 → 그 위치 매물 목록 팝오버**(가까운 순, 상위 N건 + `⋯ N건 더 · 확대해서 보기`).
  - 목록 행 클릭 → 그 매물 [[S02-매물상세]].
  - `확대해서 보기` → 지도를 그 클러스터로 줌인(클러스터가 개별 핀으로 분해).
- [규칙] 빈 지도 클릭 시 팝오버·클러스터 목록 닫힘.

#### 3.6c ★★ 영역 그리기 검색 (Draw-to-Search) *(신설 2026-07-21 — 고유 기능, 경쟁사 부재)*
> 법정동 앵커의 한계(행정경계에 갇힘)를 넘어, **지도에 임의 영역을 직접 그려** 그 안의 매물만 찾는다. "테헤란로 이 블록만", "대로 안쪽만" 처럼 행정동으로 못 자르는 범위를 잡는 **우리만의 차별 기능**. 우리가 보유한 **지적 폴리곤**이 있어 가능한 "자석 스냅"이 핵심 무기.

- [규칙] 지도 툴바에 **`영역` 도구**. 활성화 시 지도 팬/줌 일시정지, 커서=크로스헤어. `Esc`/`지우기`로 취소.
- [규칙] **그리기 3모드** (도구 안에서 전환):
  | 모드 | 동작 |
  |---|---|
  | **자유곡선** | 마우스 드래그로 생 올가미. 그린 선 그대로가 경계 |
  | **다각형** | 꼭짓점 클릭 → 더블클릭/시작점 클릭으로 닫음. 꼭짓점 드래그 편집 |
  | **자석 올가미** ★ | 자유곡선처럼 그리되, 경로가 **필지 경계·도로에 자동 스냅**(포토샵 자석 올가미 개념). 대충 그려도 필지 단위로 깔끔하게 딱 맞음. 스냅 on/off 토글 |
- [규칙] **자석 스냅 소스 = 우리 지적 폴리곤 경계 + 도로**([[네이버지도-연동]] §1.1의 GeoJSON 재사용). 스냅 임계 내 최근접 경계 정점/간선으로 흡착. 결과 영역은 **그 안에 들어오는 필지들의 경계 합집합**으로 정리(건물을 반 자르지 않음).
- [규칙] **영역 = 지역 범위 대체**(확정 2026-07-21): 그린 영역이 있으면 그게 검색 범위. **법정동 앵커 칩은 무시**되고 **`✏️ 그린 영역` 칩**이 대신 뜬다. 칩 `×` 제거 → 동 범위로 복귀. 속성 필터(면적·가격 등)는 영역 위에 그대로 적용(AND).
- [규칙] 그리기 완료 → **즉시 그 영역으로 재조회**(별도 확정 버튼 없음). 영역 폴리곤 반투명 표시 + 영역 넓이(㎡/㎢) + 결과 건수.
- [규칙] **결과**: 건물 **대표 좌표(centroid)가 영역 안**(`ST_Within`)인 매물만 3열 목록·핀에 반영. 나지·부속지번도 대표지번 원칙(§3.0) 유지.
- [규칙] **영역 편집**: 꼭짓점 드래그(다각형), 다시 그리기, 지우기. `그린 영역` 칩에서도 지우기.
- [규칙] **영역 저장**: 그린 영역은 검색 조건의 일부(GeoJSON)로 **세션 유지**(뒤로가기 복원) + **조건 저장/불러오기**([[S01b-필터]] §3.7)에 폴리곤 포함.
- [규칙] **[[S01b-필터]] 연동**(2026-07-21): 범위는 검색바·필터 모달 **공유 상태**. S01b 지역 앵커에서 `🗺️ 지도에서 영역 그리기`로도 진입 → 지도 그리기 → 그린 폴리곤이 범위. 법정동 앵커 ↔ 그린 영역은 **배타**(영역이 동 대체). 현재 범위가 그린 영역이면 S01b도 `✏️ 그린 영역`(다시 그리기·지우기)으로 표시. 양쪽 어디서 바꿔도 같은 범위 칩·폴리곤에 반영.
- [데이터] 프론트가 폴리곤을 **GeoJSON**으로 백엔드 전달 → `WHERE ST_Within(building.geom, ST_GeomFromGeoJSON(:poly))`. GIST 인덱스([[../07-architecture/00-system-architecture]] §2). 자기교차 폴리곤은 `ST_MakeValid`, 정점 과다는 단순화.
- [예외] 영역 0건 → 빈 상태("그린 영역 안에 매물이 없습니다 · 영역을 넓혀보세요"). 초소형 영역/선(면적 0) → 무시하고 안내.
- **단계**: 🟢 **베타** = 자유곡선·다각형 그리기 + `ST_Within` 검색 + 영역 대체 + 세션 유지. 🔵 **정식(고급)** = **자석 스냅**(실시간 경계 흡착), 복수 영역(합집합/제외), 영역 저장 이름관리, 원/반경 도구.
  ※ 자석 스냅은 기술 난도(실시간 경계 매칭)로 정식. 단 "그린 영역 안 필지 합집합으로 경계 정리"의 **후처리 스냅**은 베타에서도 가능(그리기 후 1회 스냅).

## 4. 상태 · 규칙
- [MVP] 검색 조건은 세션 유지 — [[S02-매물상세]] 갔다 뒤로 오면 결과·스크롤 복원.
- [규칙] 조건 저장/불러오기 = [[S01b-필터]] 모달에서 수행(저장 목록은 [[S0M-마이페이지]] §3.4).
- [규칙] 3열 분류는 **매물 상태**에 종속: 매물 등록 시 일반→내 매물, 광고가 등록 시 →광고.

## 5. 데이터 연결
- [데이터] 조회 원천 = 서울 통합뷰(건물 마스터 + 필지 + 실거래/교통 등, `04-data/schema.md`).
- [데이터] 필터 조건 → 쿼리 파라미터([[S01b-필터]] 직렬화).
- [데이터] 내 매물 판정 = 매물등록 테이블(계정/팀 소유). 광고 판정 = 광고가 존재 여부.
- [데이터] 매매가(추정)·수익률(추정) = 실거래·임대 파생([[S03-주변시세]]와 동일 소스).

## 6. 예외

## 빈 상태 (empty state) *(신설 2026-07-19)*
- [규칙] **신규 계정 첫 진입** — 내 매물 0건. 광고·일반 열은 데이터가 있으므로 정상 표시된다.
  - 내 매물 열에만: `아직 등록한 매물이 없습니다` + 한 줄 안내 `매물 상세에서 담당자를 지정하면 내 매물이 됩니다`.
- [규칙] **검색 결과 0건** — `조건에 맞는 매물이 없습니다` + `조건 완화` 액션(적용 칩 중 가장 좁은 조건 제거 제안).
- [규칙] **즐겨찾기 필터 ON인데 0건** — `즐겨찾기한 매물이 없습니다`.
- [규칙] 빈 상태 문구는 **한 줄 + 액션 하나**까지. 일러스트·장문 안내 금지(잡다한 안내 글씨 지양).
