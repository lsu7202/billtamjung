# S06 매물 찾기 · 구해요 (2026-09-30)

탐색을 두 화면으로 나눈다. 레일 위: ☰ · 빌탐정 · **매물 찾기** · **구해요**.

| 화면 | 주소 | 목록 | 필터가 걸리는 곳 |
|---|---|---|---|
| 매물 찾기 | `/search` | 매물(광고 · 중개사는 내 매물) | 매물 |
| 구해요 | `/seek` | 전체 \| 구해요 | 모든 건물 |

- 매물 = 우리 유저가 광고로 올린 것. 크롤링 자료는 매물이 아니다.
- **필터는 하나.** 두 화면이 같은 조건(지역 · 영역 · 필터 · 매물유형)을 쓴다. 한쪽에서 바꾸면 다른 쪽도 그대로다.
- 「전체 건물」 레이어는 없앤다. 매물 밖 건물은 구해요의 전체 탭이 맡는다.

## 1. 매물 찾기

패널 머리: 검색 pill · 필터 · 접기. 그 아래 두 줄, 이름 한 칸 + 「빌딩 | 상가주택 | …」 글자 한 줄(대표 09-30). 칩이 아니다. 칸이 줄을 꽉 채우고, 고른 칸만 파랑 글씨 + 연파랑 바탕(칸 전체), 넘치면 줄바꿈 없이 가로 스크롤.

    매물 유형 | 빌딩 · 상가주택 · 공장·창고 · 숙박 · 기타   (여러 개 같이 켬)
    거래 유형 | 매매                                     (지금은 매매 하나)

- 구해요 화면에도 두 줄이 똑같이 선다.
- 목록 머리엔 「매물 N개」와 숨김만. 「전체 · 내 매물 · 광고만」 칩과 조건 남기기 종은 뺐다.
  조건 알림(want_alerts · saved_searches.notify)도 같이 걷었다(0203). 저장한 조건과 저장한 건물 알림은 남는다.

## 1-1. 조건 (대표 09-30)

「필터」라는 말은 화면 어디에도 안 쓴다 — 전부 「조건」.

- 검색 줄의 「조건」을 누르면 **사이드바가 통째로 조건 화면**이 된다(너비 480px). 모달이 아니다.
- 머리: 「조건」 · ☆ 저장한 조건(불러오기 · 이름 · 덮어쓰기 · 삭제 · 지금 조건 저장) · ↺ 초기화 · ✕ 닫기(바꾼 것은 버린다).
- 몸: 지역 → 영역 → 묶음(입지 · 건물 · 토지 …)을 위에서 아래로. 묶음 머리는 굵은 글자와 가는 선만.
  - **지역 = 두 칸 고르기.** 왼쪽 구(세로 목록) · 오른쪽 그 구의 동(세 칸씩). 구를 누르면 동이 뜰 뿐 아무것도 담기지 않는다.
    「전체」를 누르면 구 전체, 동을 누르면 그 동들. 여러 구 · 여러 동을 담는다(서버가 목록을 OR 로 받는다). 동 칸은 개별로 고른 것만 켜진다. 무엇이든 담긴 구는 왼쪽에서 글자만 파랑(개수 · 「전체」 표시 없음).
  - 줄 = 이름 칸 + 값 칸. 선택지 열 개 이하는 칸을 바로 늘어놓고, 그 밖(범위 · 많은 선택지)은 줄을 누르면 그 자리에서 열린다. ▾ 는 쓰지 않는다.
  - 사이드바의 매물 유형은 조건 화면에 다시 세우지 않는다(건수엔 같이 건다).
- **영역 그리기는 「지역」 머리 오른쪽**: 자유곡선 · 다각형 · 원(그린 게 있으면 지우기). 지도에 그린 영역은 조건 화면에 쌓였다가 적용 때 걸리고, 닫으면 버린다.
  탐색 지도 오른쪽 아래 도구모음의 「영역」(자 포함)은 뺐다. 빌탐정 AI 화면 지도는 그대로.
  - **그리기 화면**: 도구를 누르면 사이드바 · 조건 창 · 도구바가 숨고 지도가 살짝 어두워진다. 커서는 자유곡선 = 펜, 다각형 · 원 = 십자.
    자유곡선 = 누른 채 끌다 떼기 · 원 = 중심에서 끌기 · 다각형 = 점을 찍어 잇고, 첫 점 12px 안으로 오면 자석처럼 붙어 누르면 닫힘. Esc = 그리던 것 버리기.
    도형은 여러 개 이어 그린다. 아래 막대 「자유곡선 | 다각형 | 원 | 지우기」 + **「적용」** — 적용을 눌러야 끝나고 조건 창으로 돌아간다.
  - 스페이스를 누른 채 끌면 지도가 움직인다(누르는 동안 그리기는 시작 안 됨).
- **순서**: 지역 → 금액 → 건물 → 토지 → 교통(옛 입지) (→ 매물, 매물관리만).
- **고급모드**: 머리 오른쪽 스위치(끄면 회색, 켜면 파랑). 누구나 켤 수 있다(사람마다 기억). 고급을 켜면 새로 선 줄이 한 번 깜빡인다.
  기본 = 매매가(구해요는 추정가) · 지역 · 대지면적 · 연면적 · 엘리베이터 · 주차 · 사용승인일 · 지상 · 지하 층수 · 입주 업종 · 지목 · 도로접면 · 역과의거리. 그 밖은 고급.
- **법정 대비 건폐율 · 용적률** = 현재 − 법정(넘으면 +, 남으면 −). 옛 「여유분」(법정 − 현재, 0에서 자름)을 뒤집었다. 서버 칸 `bcr_over` · `far_over`.
  모델은 아직 「건폐여유 · 용적여유」(법정 − 현재) — 모델 개편 때 옮긴다.
- **조건 목록은 모델과 같다**(09-30). 추정으로 거는 조건은 없다 — 추정 수익률 · 추정 임대 · 추정 평단가 · 추정 공시비율 · 유동인구 · 실거래가 · 토지이용상황 · 기타용도.
  주용도는 `use`(부분일치), 입주 업종은 `biz_dnf` 로 건다(모델과 같은 칸). 모델에만 있던 전면 도로폭 · 규제(311개, 자주 10 + 그 외)를 더했다.
  - 매물 찾기: 금액 = **매매가**(광고 매매가, 없으면 팀 매매가 — `listing_price`).
  - 구해요: 금액 = **추정가**.
  - 매물관리(모달): 두 갈래 줄은 팀 값만(매매가 · 수익률 · 임대 · 보증금 · 평단가 · 공시비율) + 매물 묶음 · 관리비 · 공실.
- 발: 판 맨 아래 고정 **「적용 (N건)」** 하나(「N건 적용」은 조건 N개로 읽혀서 바꿨다, 10-02). 적용을 눌렀을 때만 걸린다.
- 걸린 조건을 칩으로 나열하던 줄 · 「담은 곳」 줄 · 평/㎡ 전환은 없다(평/㎡ 는 지도 도구바 값).
- 매물관리: 버튼 이름만 「조건」, 창은 모달이고 본체는 같다.

## 2. 가격지표 (지도 오른쪽 위 도구바, 두 화면 공통)

오른쪽 아래 도구모음(영역 · 측정)과 같은 결의 세로 도구바. 위에서부터:

| 칸 | 누르면 |
|---|---|
| 설정 | 오른쪽 끝에서 설정 판이 덮는다(왼쪽 ☰ 판 방식). 판 밖 · Esc 로 닫힘 |
| 실거래 | 켜고 끄기(켜면 파랑) |
| 단위 | 총액 → 토지 단가 → 건물 단가 차례로 |
| 평 · ㎡ | 면적 단위 바꾸기 |

**추정가는 지표에서 뺐다**(대표 09-30). 매물 찾기는 실거래로 견주고, 추정가는 상세 판 「시세」와 구해요에서 본다.

설정 판(칸은 매물 유형 줄과 같은 그리드). 묶음 머리 「실거래」 · 「추정가」를 누르면 켜고 끈다 — 켜면 파랗게 차고, 꺼지면 그 아래 설정 줄 전체가 회색:

| 묶음 | 줄 | 값 | 기본 |
|---|---|---|---|
| 실거래 | 범위 | 전체 · 100m · 300m · 500m | 전체 |
| | 조건 | 필터 적용 · 전체 | 필터 적용 |
| 실거래 | 기간 | 1년 · 3년 · 5년 · 전체 | 3년 |
| | 연도 | 2026 … 2006, 한 해씩 켜고 끔(여러 해). 켜면 기간 대신. 다섯 칸씩 줄바꿈 | |
| 단위 | 가격 | 총액 · 토지 단가 · 건물 단가 | 총액 |
| | 면적 | 평 · ㎡ | 평 |

- **면적 단위는 앱 전체 값**(useUnit)이다. 단가뿐 아니라 목록 · 상세의 면적, 평당(㎡당), 공시지가가 같이 바뀐다.
- 주변만 기준은 고른 건물, 없으면 지도 가운데. 범위가 전체면 줌 15 이상에서 화면 안만.
- 한 건물엔 핀 하나 — 매물 > 실거래.

## 3. 구해요

목록 판 위 탭 **전체 \| 구해요**. 고객과 중개사가 **같은 목록**을 본다.

| 탭 | 줄 | 지도 |
|---|---|---|
| 전체 | 조건에 맞는 모든 건물 · 추정가순 · 관심 · 구해요 N | 흰 점(가격표 없음) |
| 구해요 | 구해요가 열린 건물 · 그 아래 구해요마다 한 줄(예산 · 목적 · 한마디 · 제안 n/5 · 남은 날) | 초록 점 |

- **조건을 걸어야 결과가 나온다.** 조건 = 지역 · 그린 영역 · 필터 중 하나 이상(매물 유형은 늘 켜져 있어 치지 않는다). 없으면 「지역이나 조건을 걸어 주세요」.
- 먼저 건수만 센다. **1,000건이 넘으면 받지 않고** 「N건 · 조건을 더 좁혀 주세요」. 이하면 전부 받는다 — 지도에 빠진 곳이 없다.
- 지도엔 **가격표 없이 점만**(밀집하면 가격표는 읽히지 않는다). 마우스를 올리거나 고르면 그 건물만 가격표. 점은 묶지 않는다.
- 이름 · 연락처는 누구에게도 안 보인다. 예산 · 목적은 남긴 사람의 고객 프로필에서 읽는다.
- 누를 수 있는 것만 다르다.
  - 고객: 건물 상세 → **구해요 남기기**(한마디 200자). 한 고객이 한 건물에 열린 구해요는 하나.
  - 중개사: 구해요 줄 → **제안 보내기**(내 매물 하나 · 한마디 300자). 한 구해요에 팀당 하나.
- 제안이 5개 차면 **마감**(더 못 받는다). 30일 지나면 목록에서 빠진다. 고객이 30일 연장 · 닫기.
- 가격 칸은 어디에도 없다(호가창이 생기지 않게).

### 고객이 제안을 고르면

마이페이지 「구해요」 탭 → 받은 제안 → **고르기**(이름 · 전화 · 동의). 그 팀에 **매수 문의** 한 줄이 생긴다(`inquiries.seek_id`).
고객관리 「문의」 칸에 그대로 뜨고, 여기서부터 연락처가 넘어간다. 고른 제안은 채택, 고객이 **거절**할 수도 있다.

## 4. 관심 정도

카드 · 상세에 `저장 N · 오늘 N명`. 모두에게 보인다.
- 저장 = `app.saves` 를 건물별로 센 수(사람 수).
- 오늘 = 오늘(KST) 상세를 연 계정 수. 고객 · 중개사 모두. 계정마다 하루 한 번 센다.

## 6. API

| 경로 | 누가 | 하는 일 |
|---|---|---|
| `POST /views` {building_pk} | 누구나 | 오늘 봤다 |
| `GET /interest?pks=` | 누구나 | 건물마다 저장 · 오늘 |
| `POST /seeks/search` (검색 요청 몸통) | 누구나 | 조건에 맞는 열린 구해요(익명) · 내 것 · 우리 팀 제안 여부 |
| `POST /seeks` {building_pk, note} | 고객 | 남기기 |
| `GET /seeks/mine` | 고객 | 내 구해요 + 받은 제안 |
| `POST /seeks/{id}/extend` · `DELETE /seeks/{id}` | 고객 | 30일 연장 · 닫기 |
| `POST /seeks/{id}/proposals` {listing_pk, message} | 중개사 | 제안 보내기 |
| `POST /proposals/{id}/pick` {name, phone, consent} | 고객 | 고르기 → 문의 |
| `POST /proposals/{id}/reject` | 고객 | 거절 |

## 7. 첫 판에서 뺀 것
