# 마케팅 전략 — AARRR (v0 초안)

> **상태**: 초안 · 2026-07-06. 크레딧/과금은 `credit-policy.md`.
> 대상 = **솔로 상업용 빌딩 중개인** (한국). 해자 = **검색** + 매물분석보고서.

---

## 0. 시장 특성이 순서를 정한다

- 시장 = **좁고 · 신뢰 기반 · 네트워크로 촘촘함.** → **Referral이 성장 엔진**, 유료광고 아님.
- 해자 = **검색(중독시키는 것).** → **Activation·Retention 먼저.** 3명도 못 붙잡으면 획득은 무의미.
- **우선순위: A(활성)·R(유지) → Referral → Acquisition → Revenue.**

**확정된 전제 (개발자):**
- **획득 채널 = 아는 중개사 네트워크(지인의 지인의 지인)** — warm intro 기반.
- **베타 3인 = 같은 상권으로 클러스터링 가능** → 집단지성·공동중개·폐쇄 리퍼럴망이 소규모에서도 작동.

---

## 1. Acquisition (획득)
니치라 유료광고 ROI 낮음. **warm intro가 메인.**
- **지인 체인 소개**: 아는 중개사 → 그 중개사의 동료 → … 신뢰가 얹혀 전달되는 소개.
- 보조: 상가/빌딩 중개 네이버카페·지역 단톡방·밴드에 **유용한 분석 공유하며 자연 노출**(스팸 X).
- 보조: 건물 페이지 **프로그래매틱 SEO**("○○동 빌딩 공시지가·용도지역·수익률").
- 유료광고는 리텐션 검증 후.

## 2. Activation (활성화) ★ 지금 핵심
아하 = **① 첫 검색에서 아는 건물이 리치 데이터로 다 뜸 ② 첫 분석보고서가 뽑힘.**
- **온보딩**: 관심지역 선택 → 그 지역 데이터 **선충전** → 아는 건물 검색 → "다 있네"(신뢰) → 샘플 보고서 1건.
- ⚠️ **빈 데이터 = 활성화 사망.** → 베타 유저 지역 데이터 선충전이 마케팅보다 먼저.
- **활성화 지표**: 가입 후 첫 유의미 검색 + 매물 저장 + 보고서 1건.

## 3. Retention (유지) ★ 지금 핵심
검색을 **일상 습관**으로.
- 저장 조건 · 매물관리 · **알림**(신규 매물, 공시지가 변동, 매각 발생).
- **주간 다이제스트 메일**: "관심지역 이번 주 변동" → 재방문.
- **데이터 신선도 = 리텐션 토대.** 수정이력 집단지성 = **쓸수록 좋아지는 데이터 네트워크 효과.**
- **지표**: WAU, 검색 빈도, 저장 매물 수, 4주 리텐션.

## 4. Referral (추천) ★ 성장 엔진
동료 추천 > 광고. 크레딧과 연결.
- **크레딧 리퍼럴**: 추천인·피추천인 둘 다 크레딧 (크레딧 faucet 통합).
- **보고서 = 바이럴 표면**: "빌탐정 생성" 브랜딩 → 클라이언트·동료 노출 → 인바운드.
- **비경쟁 네트워크**: 직접 경쟁자 말고 **다른 지역 중개사** 초대 유도.
- **공동중개(co-broking)**: 둘 다 쓰면 매물 공유 쉬움 → 네트워크 당김.
- **지표**: 초대 발송/수락률, 유저당 초대 수(K-factor).

## 5. Revenue (수익)
설계 완료(`credit-policy.md`). 핵심 이벤트 = **체험판(1개월)→유료 전환**(검색 중독 + 보고서 맛). 확장 = 크레딧 top-up, 티어 업.
- **지표**: 체험→유료 전환율, 크레딧 소비량, 티어 업그레이드율.

---

## 6. 관통 통찰 2개

1. **데이터 콜드스타트 = 최대 리스크.** Activation·Retention 둘 다 "그 유저 지역에 데이터가 있느냐"에 달림. → **베타 유저 지역 데이터 선충전이 1순위.**
2. **지리적 클러스터링**(확정): 베타 3인을 **같은 상권**으로 → 매물 공유·수정이력 밀도·폐쇄 리퍼럴망이 소규모에서 작동. **비클러스터면 네트워크 기능 전부 사망.**

+ **보고서는 1인 3역**(활성화 wow · 리퍼럴 표면 · 매출) → 퀄리티 투자 우선순위 최상.

---

## 7. 베타 실행 플랜 (요약)

1. **유저 선정**: 지인 체인으로 **같은 상권 3인** 확보.
2. **데이터 선충전**: 그 상권 건물 데이터를 미리 리치하게.
3. **활성화**: 아는 건물 검색 → 샘플 보고서로 wow.
4. **유지**: 주간 변동 알림 + 검색 습관화.
5. **측정**: 활성화율 · 검색 빈도 · 보고서 소비(크레딧) · 4주 리텐션.
6. Referral/Acquisition 확대는 **리텐션 신호(PMF) 확인 후.**
