# 마케팅 전략 — 고객 여정 5단계

> **역할**: 빌탐정을 어떻게 **알리고 · 붙잡고 · 퍼뜨릴지**. 대상 = 솔로 상업용 빌딩 중개인.
> (틀은 "AARRR" 5단계 = 획득·활성화·유지·추천·수익. 아래는 한글 위주.)
> 상태: v0 · 2026-07-06.

---

## 0. 시장 특성이 순서를 정한다

- 시장 = **좁고 · 신뢰 기반 · 서로 아는 네트워크.** → **입소문(추천)이 성장 엔진**, 유료광고 아님.
- 해자 = **검색** → **"좋다 느낌(활성화)"과 "다시 옴(유지)"이 먼저.** 3명도 못 붙잡으면 아무리 모아도 소용없음.
- **순서: 활성화·유지 → 추천 → 획득 → 수익.**
- 확정: 획득 = **아는 중개사 소개(지인 체인).** 데이터 = **서울 전체(MVP부터)** → 어느 지역이든 첫 화면이 안 비어 활성화 가능.

---

## 1. 획득 — 어떻게 알게 하나
- **아는 중개사 소개(지인의 지인)** 가 메인. 좁은 시장이라 광고 효율 낮음.
- 보조: 중개사 커뮤니티(네이버 카페·단톡·밴드)에 유용한 분석 자연스럽게 공유, 건물 정보 검색 노출.

## 2. 활성화 — "이거 좋다" 순간 ★ (지금 핵심)
- 아하 = ① 첫 검색에 **아는 건물이 풍부한 데이터로 뜸** ② **첫 분석보고서** 뽑음.
- 온보딩: 관심지역 → 아는 건물 검색("어 다 있네") → 샘플 보고서 1건.
- 데이터가 서울 전체라 **지역 안 가리고** 활성화 됨.

## 3. 유지 — 다시 오게 ★ (지금 핵심)
- **검색을 일상 습관으로.** 저장 조건 · 매물관리.
- 데이터가 정확·최신일수록 유지↑. 수정이력(집단지성) = **쓸수록 데이터가 좋아짐**.
- 지표: **주간 사용자 수 · 검색 빈도 · 4주 후 남아있는 비율(잔존율).**

## 4. 추천 — 입소문 엔진 (성장 동력)
- 동료 추천 > 광고.
- **크레딧 추천 보상**(추천한 사람·받은 사람 둘 다 크레딧).
- 보고서에 **"빌탐정 생성" 표시** → 클라이언트·동료가 보고 유입.
- 직접 경쟁자 말고 **다른 지역 중개사** 초대. 공동중개로 서로 끌어당김.

## 5. 수익 — 돈으로
- **체험판 → 유료 전환**(검색 습관 + 보고서 필요가 전환 동력). 확장 = 크레딧 추가 구매 · 상위 티어. 상세 `credit-policy.md`.

---

## 통찰 2가지
1. **데이터 없으면 활성화 사망** → **서울 전체 적재(개발에 포함)로 해결.** 활성화가 특정 지역에 안 묶임.
2. **보고서 = 활성화·추천·매출 1인 3역** → 보고서 퀄리티 투자 최우선.

---

## 용어 풀이 (헷갈릴 때)
| 영어 | 뜻 (한 줄) |
|---|---|
| 획득 (Acquisition) | 우리 서비스를 알게 함 / 유입 |
| 활성화 (Activation) | 처음 써보고 "이거 좋다" 느끼는 순간 |
| 유지 (Retention) | 떠나지 않고 계속 다시 옴 |
| 추천 (Referral) | 입소문 · 남에게 소개 |
| 수익 (Revenue) | 실제 결제 · 매출 |
| PMF | 시장이 진짜 원하는 제품인지 (제품-시장 적합) |
| 잔존율(리텐션) | 일정 기간 뒤 안 떠나고 남은 사용자 비율 |
