# 베타 가이드 영상 · 촬영 스크립트

> **퀘스트를 준다 → 영상이 푼다 → 직접 해본다.**
> 퀘스트 셋. 각 퀘스트는 **세 박자**로 간다.
>
> | 박자 | 하는 일 |
> |---|---|
> | ① 제시 | 이번 퀘스트가 무엇인지 — 화면 멈추고 띠만 |
> | ② 방법 | 이걸 하려면 어디를 봐야 하는지 — 예고 상자로 자리만 짚는다(아직 안 누름) |
> | ③ 실연 | 「자, 그럼 직접 해보겠습니다」 후 실제 조작 |
>
> 목표 길이 **2분**. 슉슉 넘어가지 않는다 — 클릭 하나에 결과를 볼 시간을 준다.
> 화면은 프로덕션 실조작 녹화(1920×1080). 내레이션=타입캐스트 ssfm-v30(Seohyeon).

## 퀘스트 1 · 사대문 안쪽 40~60억 매물 찾기 (0:10 ~ 0:55)

**띠** — 퀘스트 1 · 사대문 안쪽 40~60억 매물 찾기 · `0 / 3`

### ① 제시
| 화면 | 나레이션 |
|---|---|
| 지도 정지. 띠만 보인다 (1.5초 여유) | 첫 번째 퀘스트입니다. 사대문 안쪽에서, 사십억에서 육십억 사이 매물을 찾습니다. |

### ② 방법
| 화면 | 나레이션 |
|---|---|
| 지도 도구에 **예고 상자** (누르지 않음) | 사대문은 행정구역이 아니라서 구나 동으로는 검색되지 않습니다. 지도에 직접 그려야 합니다. |
| 필터 버튼에 **예고 상자** (누르지 않음) | 그린 다음, 필터에서 금액과 용도 조건을 겁니다. |

### ③ 실연
| 화면 | 나레이션 |
|---|---|
| 커서가 자유곡선으로 이동 | 자, 그럼 직접 해보겠습니다. |
| 자유곡선 클릭 → 켜짐 | 지도 도구에서 자유곡선을 고릅니다. |
| **드래그로 사대문을 감싸 그린다** (천천히) | 사대문을 감싸듯 그립니다. 반듯하지 않아도 됩니다. |
| 손을 뗀다 → 영역 안만 남음 (1.2초 머무름) | 놓으면 그 안의 건물만 남습니다. |
| 필터 클릭 → 조건 화면 | 필터를 엽니다. |
| 매매가 › `40억~60억` | 매매가를 사십억에서 육십억으로 넣습니다. |
| 토지이용상황 › `상업용 빌딩` | 토지이용상황에서 상업용 빌딩을 고릅니다. |
| 주용도 › `제2종근린생활시설` | 주용도는 제이종근린생활시설로 합니다. |
| 적용 클릭 → 목록이 바뀐다 (1.5초 머무름) | 적용을 누르면 조건에 맞는 것만 남습니다. |
| **띠가 `1 / 3`으로 차오른다** + 완료음 | |

## 촬영 규칙

**계정** — 촬영 전용 계정으로 찍는다. 지금 개인 계정으로 찍으면 화면에 이런 게 박힌다:
크레딧 −320(고장으로 보인다) · 남의 사무소명이 찍힌 브리핑 표지 · 「내」 뱃지 붙은 개인 영업 데이터.
업무 탭은 소유자명·연락처가 있으므로 아예 찍지 않는다.

**찍기 전 대기** — Pretendard 로딩 완료 · 지도 타일 로딩 완료 · 로딩 스피너 종료.
회색 빈 타일이 한 프레임이라도 찍히면 다시 찍는다.

**조작** — 커서는 화면 밖에서 들어온다. 버튼 위에서 hover가 보이고 0.6초 머문 뒤 눌린다.
드래그는 가속·감속을 준다(등속이면 기계로 보인다). 검색어는 한 글자씩.
**클릭 뒤 결과를 볼 시간을 1.2초 이상 준다** — 이게 없으면 따라갈 수 없다.

**예고 상자** — 누르기 0.6초 전에 대상에 상자가 뜬다. ② 방법 박자에서는 상자만 띄우고 **누르지 않는다**.

**편집** — 클릭 순간 그 지점으로 1.2배 확대. 나레이션이 끝나고 0.3초 뒤 클릭.
리포트 생성 대기는 빨리감기 + 「만드는 중」. 장면 전환은 짧은 크로스디졸브.
**자막을 깐다** — 소리 끄고 보는 사람이 많다.

**소리** — 딸깍(클릭) −18dB · 작은 팝(상자) −24dB · 두 음 상승(퀘스트 완료) −14dB · 배경음 −30dB.
전부 직접 합성한다.

**넣지 않을 것** — 매물 등록, 정보 수정, 업무 탭, 사진, 리포트 각 장의 계산 근거.

**대체안** — 전체화면이 자동 조작 환경에서 막히면 그 컷만 브리핑을 크게 보여주는 것으로 바꾼다.
