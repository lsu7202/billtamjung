# 빌탐정 컬럼정의서 (필드 마스터)

> **역할**: "어떤 필드가 있나"의 **단일 출처** — 필드·타입·단위·허용값·원본·수집방식·검색타입·상태. (물리 저장구조=`schema.md` · 화면매핑=`field-inventory.md` · 원본레이아웃=`mart-layout.md`/`codes-vworld.md` · 식=`formulas.md` · UI값=`enums.md` · 역할지도=`README.md`)
> 허용값의 "관측"= 실데이터 전수 기준(토지=**서울 89.9만 필지** · 건물=서울 58.6만 동). **미관측 = 데이터에 없었단 뜻일 뿐, 값 자체는 유효**.
> 상태: ✅확정 · 🟡방침 확정/미완 · ⬜원본 미확보 · ✍️수기 · ƒ파생. 2026-07-14 기준. (구 `data-dictionary.md` 흡수)

## ★ 저장 단위 원칙 (표시단위 ≠ 저장단위)
- 표의 "단위"는 **화면 표시 포맷**. DB 저장은 정규화된 별도 값.
- 금액: **원(KRW) 정수** 저장(억/만원 혼용 금지) — 화면만 억·만원 포맷. 예: `100.01억` ↔ 저장 `10,001,000,000`
- 비율(%·%p): 숫자값 저장(`50.01`), 기호는 표시만.
- 면적: **㎡** 저장, 화면 평(×0.3025). · 날짜: **`YYYY-MM-DD`** 저장, 화면 `YYYY/MM/DD`.

## ★ 시계열 구조 원칙
- **공시지가 · 매각 · 광고가 · 층별임대**는 `(시점 + 값)`의 시계열 → 번호(매각일1/2/3)로 늘리지 않고 **반복 레코드**로 저장. 표↔그래프 토글 컴포넌트 1개 공유.

## ★ 수정 모드 원칙 (마스터 불변 + 유저 오버레이)
- **유저 수정은 공공 마스터를 절대 안 바꾼다.** 마스터(①, read-only) 위에 **유저 오버레이(②, 계정+팀 공유)**가 덮음. 화면값 = 마스터 + 내 오버레이. 다수결·전체반영 없음. (상세: 메모 `data-edit-architecture` · [[S02-매물상세]] §1.1)
- 모드: **🔒 잠금**(수정 불가) · **✏️ 직접입력**(오버레이) · **🔀 계산 or 입력**(자동계산 기본+직접입력 허용, 배지 없음) · **③ 커뮤니티**(전체 공유) · **⚙️ 시스템**(추정/파생, read-only).

## 검색타입 (S01b 상세검색 필터 형태)
- **range**=범위 · **date-range**=기간 · **bool**=여부 · **series**=시계열 · **enum**=선택 · **text**=부분일치.
- 면적·율·수익·공시지가/상승률·층수·엘베·주차 = `range` · 날짜(사용승인·대수선) = `date-range` · 전화번호·사진·브리핑 = `bool` · 공시지가/매각/광고 시계열 = `series` · 지목·용도지역·상태값 = `enum` · 기타용도 = `text`.
