# 빌탐정 컬럼정의서 (필드 마스터)

> **역할**: "어떤 필드가 있나"의 **단일 출처** — 필드·타입·단위·허용값·원본·수집방식·검색타입·상태. (물리 저장구조=`schema.md` · 화면매핑=`field-inventory.md` · 원본레이아웃=`mart-layout.md`/`codes-vworld.md` · 식=`formulas.md` · UI값=`enums.md` · 역할지도=`README.md`)
> 허용값의 "관측"= 실데이터 전수 기준(토지=**서울 89.9만 필지** · 건물=서울 58.6만 동). **미관측 = 데이터에 없었단 뜻일 뿐, 값 자체는 유효**.
> 상태: ✅확정 · 🟡방침 확정/미완 · ⬜원본 미확보 · ✍️수기 · ƒ파생. 2026-07-14 기준. (구 `data-dictionary.md` 흡수)

## ★ 저장 단위 원칙 (표시단위 ≠ 저장단위)
- 표의 "단위"는 **화면 표시 포맷**. DB 저장은 정규화된 별도 값.
- 금액: **원(KRW) 정수** 저장(억/만원 혼용 금지) — 화면만 억·만원 포맷. 예: `100.01억` ↔ 저장 `10,001,000,000`
- 비율(%·%p): 숫자값 저장(`50.01`), 기호는 표시만.
- 면적: **㎡** 저장, 화면 평(×0.3025). · 날짜: **`YYYY-MM-DD`** 저장, 화면 `YYYY/MM/DD`.

## ★ 시계열 구조 원칙
- **공시지가 · 실거래 · 광고가 · 층별임대**는 `(시점 + 값)`의 시계열 → 번호(실거래일1/2/3)로 늘리지 않고 **반복 레코드**로 저장. 표↔그래프 토글 컴포넌트 1개 공유.

## ★ 결측(null) 표기 원칙
- **null 표현 = "미지정" 하나로 통일** (기존 확인중·빈값·00 전부 → 미지정). 넛지 없음.
- 가치점수 계산 시 결측 항목 = **0점**(게이팅 없음, `formulas.md` F-16). 표시는 "미지정", 점수 기여는 0.

## ★ 수정 모드 원칙 (마스터 불변 + 유저 오버레이)
- **유저 수정은 공공 마스터를 절대 안 바꾼다.** 마스터(①, read-only) 위에 **유저 오버레이(②, 계정+팀 공유)**가 덮음. 화면값 = 마스터 + 내 오버레이. 다수결·전체반영 없음. (상세: 메모 `data-edit-architecture` · [[S02-매물상세]] §1.1)
- **원칙: UI에 노출되는 필드는 전부 수정 가능**(오버레이). **잠금(🔒) 없음** — 오버레이는 개인/팀 전용이라 뭘 고쳐도 마스터·타인 무영향.
- 모드: **✏️ 직접입력**(원본·조사·수기값) · **🔀 계산 or 입력**(자동계산 기본+직접입력 허용, 배지 없음) · **③ 커뮤니티**(전체 공유) · **⚙️ 시스템**(추정/파생, read-only).
- **내부 식별자(PNU·좌표·필지폴리곤·법정동코드·부속지번 관계·주소 지번/도로명)** = UI 비노출 or 매물 식별키 → **수정 논외**(표 제외).

### 인덱스 설계 시사점
- **range가 43개(66%)** → 대부분 **B-tree 단일 인덱스**로 커버. 실사용 빈도 상위(매매가·연면적·대지면적·수익률·역과의거리)부터 우선.
- **multi(enum)**는 카디널리티가 낮아 단독 인덱스 효율이 낮다 → **복합 인덱스의 후행 컬럼**이나 부분 인덱스가 적합.
- **업무 14개는 `listings` 테이블**(팀 스코프) — 공공 건물 테이블과 조인이 필요. `team_id` 선행 복합 인덱스 전제.
- **대표조건 15개**(`S01b-상세검색필터.md`)가 실사용 빈도 상위 가정 → 인덱스 우선순위의 1차 근거.
