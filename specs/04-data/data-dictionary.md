# 데이터 사전 (Data Dictionary)

> 필드의 **단위·정밀도·예시**를 확정하는 단일 출처. (출처/계산식은 `sources.md`/`formulas.md`와 연결)
> `field-inventory.md`(화면 기준 목록)를 데이터 기준으로 재구성·그룹핑한 문서.
> **검색타입** = S01b 상세검색에서 이 필드가 갖는 필터 형태. (range=범위 / date-range=기간 / bool=여부 / series=시계열)

## ★★ 단위 원칙: 표시단위 ≠ 저장단위
- 아래 표의 **단위/정밀도 = 화면 표시단위**. **DB 저장값은 정규화된 별도 값**이다.
- **저장 규칙**
  - 금액: 모두 **원(KRW) 정수**로 저장. (억/만원/원 혼용 금지) — 화면에서만 억·만원으로 포맷.
    - 예: 매매가 화면 `100.01억` ↔ 저장 `10,001,000,000`
  - 비율(%, %p): **숫자값**으로 저장(예 `50.01`), 단위 기호는 표시만.
  - 면적: 저장은 **㎡** 권장, 화면은 평(×0.3025) 표시. (현재 표시단위=평)
  - 날짜: 저장 `YYYY-MM-DD`(ISO), 화면 `YYYY/MM/DD`.
- 따라서 표의 "단위" 컬럼은 **표시 포맷 명세**로 읽을 것. (저장 타입은 별도 스키마에서 확정)

## ★ 구조 원칙: 시계열은 반복 레코드로 묶는다
- **공시지가 / 매각사례 / 네이버광고**는 모두 `(날짜·시점 + 값)`의 시계열.
- `매각일1/2/3`처럼 번호로 늘리지 않고 **반복 레코드 테이블**로 저장한다.
- 동일 구조이므로 **차트 토글(표↔그래프) 컴포넌트 1개를 공유**한다. (앞서 확정)

### G6. 광고 (집단지성 수기) ★변경 · ⏳초안
> ⏳ **초안** — 광고가·층별 임대정보(G5)·주변임대시세 등 **집단지성 의존 기능은 콜드스타트라 아직 보장된 기능이 아님.** 아래 구조는 초안으로 설정해두고 **베타 실사용으로 검증 후 확정**.
> ⚠️ **크롤링 폐기**(네이버 등). 광고가 = **중개인 관측/입력(집단지성)**. **관찰 기여 허용**(B안).
> **시계열 = 가격 변동 시점만** 점을 찍는다. **같은 값 재확인 = 새 점 아님** → 확인 건수·마지막확인일만 갱신(신선도). 값이 바뀌면 새 점(추이 보존).
> 화면 용어는 **"광고가" 통칭** (두 축 구분: ① 동시점에 관측이 갈리면 다수 확인값으로 정리=노이즈 필터 · ② 그 값이 시간에 따라 바뀌면 변동일 점 추가=추이). 이 계산은 **내부 로직** — UI에 '대표/최다' 노출 안 함. 담당자 우선 **없음**(stale 방지).
> **광고 상태**(광고중/없음) = 파생 데이터로 보유하되 **화면 표시 안 함** — 매물 3분류·검색 필터에만 사용.
> 기여자 = **내부 기록**(크레딧 보상·정제·스팸방지)이며 **화면 비공개**(담당자 비공개 정합) — 공개는 변동일+대표 광고가+확인 건수, 본인 기여만 본인이 봄.
> ⚠️ 엣지: 같은 건물 두 중개사가 서로 다른 호가로 광고(B 허용) → 최다/최신으로 커버(미결).
> 위치 = S02 **공용 '광고' 섹션**(업무 탭 아님 — 광고는 시장 공개 사실이라 전체 공유). 입력=모달(광고가+확인일+[내 광고] 체크). 담당자·관찰자 공동 기여.
> ★핵심: **광고 상태를 손으로 토글 안 함** — 광고가 유무로 자동 파생(입력=광고중·삭제=광고없음). 사용자는 "내 광고냐"만 판단.
