# 데이터 사전 (Data Dictionary)

> 필드의 **단위·정밀도·예시**를 확정하는 단일 출처. (출처/계산식은 `sources.md`/`formulas.md`와 연결)
> `field-inventory.md`(화면 기준 목록)를 데이터 기준으로 재구성·그룹핑한 문서.
> **검색타입** = S01b 상세검색에서 이 필드가 갖는 필터 형태. (range=범위 / date-range=기간 / bool=여부 / series=시계열)

## ★★ 단위 원칙: 표시단위 ≠ 저장단위
- 아래 표의 **단위/정밀도 = 화면 표시단위**. **DB 저장값은 정규화된 별도 값**이다.
- **저장 규칙**
  - 금액: 모두 **원(KRW) 정수**로 저장. (억/만원/원 혼용 금지) — 화면에서만 억·만원으로 포맷.
    - 예: 매매가 화면 `100.01억` ↔ 저장 `10,001,000,000`
  - 비율(%, %p): **숫자값**으로 저장(예 `50.01`), 단위 기호는 표시만.
  - 면적: 저장은 **㎡** 권장, 화면은 평(×0.3025) 표시. (현재 표시단위=평)
  - 날짜: 저장 `YYYY-MM-DD`(ISO), 화면 `YYYY/MM/DD`.
- 따라서 표의 "단위" 컬럼은 **표시 포맷 명세**로 읽을 것. (저장 타입은 별도 스키마에서 확정)

## ★ 구조 원칙: 시계열은 반복 레코드로 묶는다
- **공시지가 / 매각사례 / 네이버광고**는 모두 `(날짜·시점 + 값)`의 시계열.
- `매각일1/2/3`처럼 번호로 늘리지 않고 **반복 레코드 테이블**로 저장한다.
- 동일 구조이므로 **차트 토글(표↔그래프) 컴포넌트 1개를 공유**한다. (앞서 확정)

## B. 공시지가  (시계열) ★변경

> **변경**: 현재 / 5년전 / 10년전 3개만이 아니라 **현재~10년 전체 연도를 저장**한다.

| 필드명 | 단위/정밀도 | 예시 | 검색타입 |
|---|---|---|---|
| 공시지가 시계열 `[년도, 공시지가]` | 공시지가=원 단위 | 2026, 10,000,000 | series |
| 총공시지가 *(파생)* | 원 단위 | 공시지가 × 대지면적 | range |
| 공시지가 기준 *(파생)* | 원 단위 | 총공시지가 × 2 | range |
| 공시지가 상승률 (5년) *(파생)* | %, 소수점 2자리 | 50.01 / 50 | range |
| 공시지가 상승률 (10년) *(파생)* | %, 소수점 2자리 | 50.01 / 50 | range |
| 총공시지가와 매매가 비율 *(파생)* | %, 소수점 2자리 | 50.01 / 50 | range |

- **파생 필드** (→ `formulas.md`로 식 이관):
  - `총공시지가 = 공시지가 × 대지면적`
  - `공시지가 기준 = 총공시지가 × 2`  *(×2 배수 의미 추후 확인)*
  - `상승률(5년) = (현재 공시지가 / 5년전 공시지가 − 1) × 100`, 10년도 동일
  - `총공시지가와 매매가 비율 = 총공시지가 / 매매가 × 100`
