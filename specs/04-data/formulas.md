# 계산식 정의 (Formulas)

> 파생 필드의 식·입력·예외를 못 박는 단일 출처. 필드는 `data-overview.md`, 식 ID는 `F-00`.
> **저장 정책**: 시계열에서 산출되는 대표지표(F-01·F-02·F-03)는 **매물 테이블에 비정규화 컬럼으로 캐싱**한다.
> 원천 시계열이 갱신되면 **재계산**한다. S01 필터 = 이 캐시값, S02 헤더 = 동일 값(검색↔상세 일치).

## 시계열 → 대표지표 (검색용 비정규화)

### F-01 매각손익  *(매각사례 시계열 → 스칼라)*
```
정의: 직전 매각 → 최근 매각 손익률
F-01 = (최근 매각액 − 직전 매각액) / 직전 매각액 × 100   (단위 %, 소수점 2자리)
예외: 매각 < 2건 → NULL (S01 필터 제외, S02 표시 '—')
```

### F-02 공시지가 상승률  *(공시지가 시계열 → 스칼라, 5년·10년)*
```
F-02a 상승률(5년)  = (현재 공시지가 − 5년전 공시지가)  / 5년전 공시지가  × 100
F-02b 상승률(10년) = (현재 공시지가 − 10년전 공시지가) / 10년전 공시지가 × 100
단위 %, 소수점 2자리. 해당 연도 데이터 없으면 NULL.
```

### F-03 광고 상승률  *(네이버광고 시계열 → 스칼라)*
```
정의: 직전 광고가 대비 최신 광고가 상승률
F-03 = (최신 광고가 − 직전 광고가) / 직전 광고가 × 100   (단위 %, 소수점 2자리)
예외: 광고 < 2건 → NULL
```

## 공시지가 파생

### F-04 총공시지가
```
F-04 = 공시지가(원/㎡ 또는 원/평 기준 통일) × 대지면적        (단위 원)
```
### F-05 공시지가 기준
```
F-05 = 총공시지가 × 2        (×2 배수 의미는 추후 확인)
```
### F-06 총공시지가/매매가 비율
```
F-06 = 총공시지가 / 매매가 × 100        (단위 %, 소수점 2자리)
```

## 금액 파생

### F-07 평단가(대지) / F-08 평단가(연면적)
```
F-07 = 매매가 / 대지면적(평)
F-08 = 매매가 / 연면적(평)
(저장 원 단위 → 화면 만원 단위)
```

### F-09 건폐율·용적률 여유분
```
F-09a 건폐율 여유분 = 법정 건폐율 − 현재 건폐율        (단위 %p)
F-09b 용적률 여유분 = 법정 용적률 − 현재 용적률        (단위 %p)
```

## 매각 파생

### F-12 매각회수
```
F-12 = 매각사례 시계열 레코드 개수 (건). 자동 계산.
```

## 공실 파생

### F-13 총공실  *(enum: 있음 / 없음 / 확인중)*
```
층별 '공실상태'(공실 / 임대중 / 확인중) 우선순위 집계:
1) 층 중 '공실'이 1건 이상 → 있음
2) 아니고 '확인중'이 1건 이상 → 확인중
3) 전부 '임대중' → 없음
예: (없음·확인중)→확인중, (있음·확인중)→있음
근거: 공실 여부를 모르는 경우가 많아 3값. 공실제외수익률(F-14) 트리거.
```

### F-14 공실제외수익률
```
목적: 일반 수익률은 '현재 공실'인 층의 임대료를 0으로 반영 → 실제 임대잠재력 과소평가.
      공실제외수익률은 공실 영향을 제외(=만실 가정 등)하고 산출.
F-14 = (공실 제외 기준) 순임대수익 / 매매가 × 100   (정확한 반영 방식 확정 필요)
관련: 총공실(F-13)이 '있음'인 매물에서 일반 수익률과 차이가 발생.
```

## 금액정보 산출 (층별 임대정보 → 자동 파생 · 별도 계산기 없음)  *(세부 식 TBD)*
```
입력: 층별 [보증금, 임대료, 관리비, 공실상태], 매매가, 자기자본, 대출 이자
출력: 공실, 총보증금, 총임대료, 총관리비, 순임대수익, 수익률, 공실제외수익률, 자기자본수익률
F-10 수익률        = (연 총임대료 − 연 총관리비) / 매매가 × 100   (공실 반영, 식 확정 필요)
F-11 자기자본수익률 = 순수익 / 자기자본 × 100                     (대출이자 반영, 식 확정 필요)
```
