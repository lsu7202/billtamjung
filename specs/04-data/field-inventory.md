## S00. 로그인 / 계정
> 목업: `_mockups/S00.html` (정식 기준 · MVP=이메일 로그인/회원가입만).

### 로그인 / 회원가입 (탭 전환)
- 로그인: 이메일 · 비밀번호 · 로그인 유지 · 비밀번호 찾기
- 회원가입: 이름 · 중개사무소명(선택) · 이메일 · 비밀번호 · 약관 동의 → 가입 시 **체험판 1개월 자동 시작**
- 소셜 로그인(카카오·네이버) **[정식]**

### 계정 모델 (★ 권한·DB 설계 직결)
- **공용 vs 사적 2레이어** (★핵심):
  - **공용**(전체 공유·집단지성): 건물·토지 데이터, 광고가/광고 상태, 위키, 수정이력, 공시지가, 매각사례.
  - **사적**(내 매물 = **유저/팀별 레이어, B안**): 담당자, 소유자 CRM(연락처·성향), 진행상태. 공용 건물 위에 각 중개사가 얹는 **각자의 사적 레이어** — 같은 건물을 여러 중개사가 각자 내 매물로 가질 수 있음.
- **대표 계정 1 : 직원 계정 N** (최대 N개 직원 계정 연결).
- 대표와 직원은 **매물을 공유**한다. **공유 범위는 대표가 마이페이지에서 설정**.
  - **기본**: 대표 → 직원 매물 조회 **가능** / 직원 → 대표 **불가** (단방향) · **전부 공유**: 양방향
- **담당자·내 매물 가시성**:
  - **팀 내부** = 공유 설정 따라 보임.
  - **팀 외부(다른 중개사)** = **완전 비공개** — 담당자·내 매물 노출 없음(경쟁 민감). 남 눈엔 일반/광고 매물로만 보임. (공동중개 개념 없음)

## S03. 주변임대시세 분석  (= S02 '주변임대시세 계산기') · ⏳초안
> **목표**: 본매물과 비슷한 상황의 매물들의 **평균 임대시세**를 산출.
> **진입**: S02 주변임대시세 섹션의 [주변시세 계산기] 버튼. (※ 매물분석(=가치분석)보고서와 별개, 금액 계산기 M01과도 별개)
> **데이터 원천 = 반경 내 건물들의 층별 임대정보(공용, 유저 축적)**. 빌딩 임대 실거래는 공공에 없음(전월세 신고제=주택만)·크롤링 폐기 → 집단지성이 유일. ⏳ 콜드스타트라 **초안 — 베타 실사용으로 검증 후 확정** (콜드스타트 보완책(상권 통계 기준선 등)도 그때 결정).

**워크플로우**
1. 지도에 **본매물 아이콘** 표시
2. 사용자가 본매물이 포함된 **상권 중심으로 반지름(원)을 직접 그림**
3. 원 내부 매물 대상으로 **백엔드가 임대시세 데이터 조회** (예시 결과: 목동 620-7)
4. 결과 데이터가 **계산기 테이블에 로드**
5. 사용자가 **노이즈를 직접 수정**(데이터 테이블 행 편집/삭제)
6. 계산된 **평균값을 '주변임대시세'에 등록** (S02 표에 반영, 단방향)

- 지도: 본매물 아이콘 + 반경(원) 그리기
- **조회 층 범위 입력: 지하 N층 ~ 지상 N층** (이 범위 층만 조회)
