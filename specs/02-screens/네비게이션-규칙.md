# 네비게이션 규칙 — 리다이렉트를 남발하지 않는다

> 배경(2026-08-13): 거래 섹션·매물상세 개편 과정에서 「~에서 관리 →」「~에서 보기 →」
> 「매물 상세 →」 같은 이동 버튼이 화면마다 붙어 지저분해졌다. 이동은 필요하지만
> **버튼의 수가 늘수록 화면은 안내판이 되고 내용은 뒤로 밀린다.** 규칙으로 못박는다.

## 규칙

1. **개체를 나타내는 행·카드가 곧 링크다.** 매수자 행을 누르면 그 매수자에게 간다 —
   행 안에 「매수에서 관리 →」 같은 라벨을 **또** 넣지 않는다. 필요하면 꼬리에 `→` 하나.
2. **주소는 항상 매물상세 링크다.** 앱 전체 어법. 주소를 링크로 만들었으면
   「매물 상세 →」 버튼을 따로 두지 않는다.
3. **한 화면에 같은 목적지로 가는 길은 하나만.** 두 개 이상 보이면 하나를 지운다.
4. **명시적 리다이렉트 버튼은 화면(패널)당 1개까지.** 그것도 「여기서 못 하는 일의
   정본이 저기 있다」일 때만 — 예: 매물상세의 「거래에서 등록 →」(등록의 정본은 거래).
5. **편집의 정본은 한 곳이다.** 같은 값을 두 화면에서 고치게 하지 않는다(예외: 매도희망가
   — 오버레이 하나를 양쪽에서 고치는 건 저장소가 하나라서 허용). 정본이 아닌 화면은
   **표시만** 하고, 이동은 규칙 1~4를 따른다.
6. **빈 상태의 CTA는 리다이렉트로 세지 않는다.** 「아직 없습니다 — 담기」처럼
   다음 행동이 하나뿐일 때의 안내는 예외.

## 컨트롤 어법 — 네모 입력칸 금지 (2026-08-13)

인라인 화면에 **항상 떠 있는 네모 입력칸(input·select 박스)을 두지 않는다.**
네모칸은 폭을 통째로 잡아먹어 옆에 정보를 세울 수 없고, 몇 개만 쌓여도 화면이
폼이 된다 — 값들이 읽히는 화면이 아니라 채우는 서식이 돼버린다.
매도·매수에서 확립한 어법만 쓴다:

연결된 사람 목록도 같다 — **상자 카드로 세우지 않는다.** 상자는 한 명당 한 줄 폭을 통째로
먹어 다섯 명이면 화면 반이 상자가 된다. 이름(링크) + 상태 소형 칩을 한 줄에 흘린다.

| 편집할 것 | 쓰는 어법 |
|---|---|
| 선택지가 있는 값(상태·담당자·등급…) | **칩**(Chips inline) |
| 금액 | **클릭-편집**(눌러야 입력이 열리고, 벗어나면 닫힘 — EokCell·KV money) |
| 기록·문장 | **pill 한 줄**(CommitLog 입력줄) |
| 신규 등록 폼 | **모달**(NewOwner·NewBuyer) — 모달 안에서만 폼 허용 |
| 검색 | 목록 상단 검색칸(by-q)만 예외 |

이 표에 없는 컨트롤이 필요해 보이면 화면이 아니라 설계를 다시 본다 —
대개 「여기서 편집할 값이 아니다」가 답이다(편집 정본 지도 참조).

## 적용 현황 (2026-08-13)

| 화면 | 정리 |
|---|---|
| 거래 > 매물 | 「매물 상세 →」 삭제(주소=링크) · 담당자 select 박스 → 칩(명함 뒷면) · 매물번호/접수일 입력칸 → 자동 발급 표시(0068) · 매도자/매수자 **카드 상자 → 이름 한 줄**(이름=링크, 상태 소형 칩, 전화 등 상세는 그 사람 화면에서) |
| 매물상세 > 매도자 탭 | 리다이렉트는 「거래에서 관리 →」 하나(규칙 4). 미등록 CTA는 규칙 6 |
| 매물상세 > 매수자 탭 | 행=링크(라벨 없음) · 담기는 Picker |

## 편집 정본 지도

| 값 | 정본 | 표시만 |
|---|---|---|
| 담당자(=등록) | 거래 > 매물 | 매물상세(머리글) |
| 매물번호 · 접수일 | **자동 — 등록 순간 DB 트리거 발급(0068)**, 아무도 편집 안 함 | 거래 > 매물 · 매물상세(머리글) |
| 소유자 인적사항 | 거래 > 매도(명함 뒷면) | 매물상세 매도자 탭 |
| 긴급도 · 매수의향서 | 거래 > 매도(매물 칸) | — |
| 매도희망가 | 오버레이 1곳(양쪽에서 편집 허용 — 규칙 5 예외) | 리포트 |
| 매수희망가 | 거래 > 매수(제안 칸) | 매물상세(파생 최고값) |
| 진행 기록 | 각 장부(매도·매수) | 거래 > 매물(합본, 읽기 전용) |
