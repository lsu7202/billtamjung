# S01b 상세검색(필터 모달) — 설계

> **상태**: 1차 검수 완료 (2026-07-04). 목업 `_mockups/S01b.html` 기준.
> 데이터 근거: `04-data/data-dictionary.md` · 값: `04-data/enums.md`.

---

## 1. 개요

- **S01b = S01에서 [필터] 누르면 뜨는 조건 입력 모달.** 뒤로 S01 결과가 흐리게 비침.
- **결과 목록은 S01에만** 표시된다. 모달 안에는 결과 리스트가 없고 **예상 건수(N건)**만 실시간 노출.
- 조건 지정 후 [적용]하면 모달이 닫히고 S01 결과에 반영.

---

## 2. 레이아웃 (위→아래)

1. **모달 헤더** — 제목 · 예상 N건 pill · 평/㎡ 토글 · [불러오기] [조건저장] · 닫기(×)
2. **지역 앵커** (항상 표시) — 시/도 · 시/군/구 · 법정동 **기본 `<select>` 3단 계층** (§6-1)
3. **적용된 조건 칩바** — 지금 걸린 전체 조건을 칩으로 한눈에, 각 × 로 개별 제거
4. **좌측 인덱스 + 우측 패널** (본체, §3)
5. **하단 바** — [전체 초기화] · 적용 조건 N개 · [취소] · [적용 · 예상 N건]

## 3. 인덱스 + 패널 (핵심 구조)

**카드(아코디언) 방식을 폐기하고 좌측 인덱스 탭 + 우측 패널로 전환** (펼치면 스크롤이 길어지는 문제 해결). 우측 패널은 **내부 스크롤(최대 52vh)**로 높이 고정.

**좌측 인덱스** = `⭐ 자주 찾는 조건` + 7 카테고리(= S02 섹션명과 일치). 각 항목에 적용 개수 뱃지.

| 인덱스 | 우측 패널 내용 |
|---|---|
| ⭐ 자주 찾는 조건 | 대표조건 15개 **값칩 균일 그리드** (라벨/구분 없이 흐름) |
| 입지정보 | 대표조건 칩 + 세부조건 칩 |
| 건물정보 | 〃 |
| 토지정보 | 〃 |
| 금액정보 | 〃 |
| 상세정보 | 〃 |
| 공시지가·매각·광고 | 〃 |
| 업무 | 〃 |

**전 필드가 값칩 + 팝오버로 통일**: 컨트롤 실체는 `#ctl-store`에 **하나만** 존재하고, 칩을 클릭하면 팝오버로 이동해 편집. 카테고리 탭은 `대표조건 칩` + `세부조건 칩` 두 묶음으로 표시.

## 6. 특수 케이스

### 6-1. 지역 = 기본 select 3단 계층 (누적 추가)
- 시/도 → 시/군/구 → 법정동 **기본 `<select>`** (검색형 태그박스는 무거워서 폐기).
- **캐스케이드**: 시/도 선택 시 해당 시/군/구만, 시/군/구 선택 시 해당 법정동만.
- 법정동(또는 "○○ 전체") 선택 시 **조건에 누적 추가** → `지역 강남구 논현동` 칩. 여러 개 누적 = 중복 지역 검색.
- 주소(지번/도로명) 검색 입력은 **세부검색에서 제외**.

### 6-2. 토지이용상황 = 섹터 그룹 다중선택 + 디벨롭 프리셋
**6 배타 섹터로 묶되 개별 선택도 가능**. 중요도 순 나열(라벨 없음).

| 섹터 | 포함 (V-World 3자리 정본 용어, `codes-vworld.md` §2) |
|---|---|
| 상업용 빌딩 | 상업용·업무용·상업기타 |
| 상가주택 | 주상용·주상기타 |
| 주거 | 단독·연립·다세대·**아파트(140)**·주거기타 |
| 공업·산업 | 공업용·공업기타·**태양광발전소부지(440)** |
| 신축부지 | 주거/상업/주상/공업나지·**주차장등(950)** |
| 특수·기타시설 | 전·과수원·전기타·전창고·전축사·답·답기타·답창고·답축사·조림·자연림·토지임야·목장용지·임야기타·광천지·염전·양어장·유원지·골프장·스키장·경마장·공원묘지·**도로등·하천등·공원등·운동장등**·위험시설·유해.혐오시설·지정되지않음·기타 |

> 2026-07-09 정본 정정: 아파트→주거·태양광→공업(코드 계열대로 이동), 공공용지 '~등' 표기, 전·답·임야 세분류 반영. 8xx 특수토지 추가분(광업용지·야영장 등)은 정의서 확정 대기.

- **섹터 체크 = 전체 선택** / **▸ = 개별 펼침** / 일부 선택 = 중간(–) 상태.
- 저장값은 개별 코드 집합(섹터는 입력 편의 래퍼). 칩 요약: `상업용 빌딩 전체 외 2`.
- **⚡디벨롭 프리셋**(섹터 위 빠른선택): 배타 섹터가 아닌 **크로스 태그**. 클릭 시 재개발·용도전환 유망 값 11개(단독·연립·다세대·주거기타·공업용·공업기타·상업용·업무용·상업기타·주상용·주상기타)를 여러 섹터에서 한번에 토글. 성수 공장→카페식 전환 후보. 정확히 그 세트만 선택되면 칩 요약=`디벨롭`.

### 6-3. 기타용도 = 텍스트(부분일치) + 프리셋 칩
- 건축물대장 `etcPurps`(서술형·표준코드 없음) → 자유입력 부분일치 검색.
- 자주 쓰는 검색어 칩: 근린생활시설·사무소·업무시설·단독주택·다가구주택·소매점·판매시설·상가 (클릭 시 입력창 채움).
- **소속: 건물정보** (건축물대장 필드).

## 7. 조건 저장 / 불러오기 (모달)

- **조건저장**: 현재 조건에 이름 붙여 저장(같은 이름 덮어쓰기, 빈 이름·0조건 경고).
- **불러오기**: 저장 목록(이름·조건개수) + [불러오기](상태 복원)/[삭제].
- 전 필드(슬라이더·알약·섹터·텍스트·지역 계층) 직렬화 저장/복원.
- *목업은 메모리 저장(새로고침 시 초기화). 실제는 서버/로컬스토리지 영속화.*

---

## 8. 표시 단위 · 눈금

- 화면 표시단위 ≠ 저장단위 (저장 = 원/숫자/㎡/ISO).
- **공시지가 = 만원/㎡** (원 아님).
- 금액 눈금은 균등분할이 아니라 **실제 매물이 몰리는 값**에 배치. 값은 잠정 → 실제 분포로 재확인 예정.
