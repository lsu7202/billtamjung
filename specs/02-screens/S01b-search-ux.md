# S01b 상세검색 — 검색 UX 아이디어

> 목표: 조건이 많아도 **효율적·직관적**으로 검색. 대표조건은 항상 보이고, 상세조건은 접기.
> 이 문서는 아이디어 정리용 (확정 아님). 채택된 것만 목업/스펙에 반영.

---

## 0. 대표조건 (카드 접힘 시 노출) — 확정 목록

| 대목(카드) | 대표조건 (접힘 시 보임) |
|---|---|
| 지역/주소 | 시군구 · 법정동 · **역과의거리** |
| 면적/규모 | 대지면적 · 연면적 · 건축면적 · 엘리베이터 · 주차장 · 사용승인일 |
| 금액/수익 | 매매가 · 수익률 |
| 광고/매각 | 광고가(네이버광고) · 매각일 &nbsp;(나머지: 매각액·매각손익·매각횟수·광고상승률·광고등록) |
| 속성/상태 | 건물용도 · 용도지역 · 진행상태 · 소유자종류 |
| 공시지가 | (대표 없음 — 헤더만, 펼쳐서 사용) |

→ **대표조건 외 모든 조건은 카드 펼침(▸/▾)으로 숨김/노출.**

---

## 1. 공통 UX 원칙

- **실시간 결과 건수**: 조건 바꿀 때마다 `이 조건으로 N건` 즉시 표시 → 조건이 너무 좁은지 바로 체감.
- **적용된 조건 칩바**: 상단에 현재 조건을 칩으로 모아 보여주고 ×로 개별 제거. (구현됨)
- **조건 세트 저장/불러오기**: 자주 쓰는 조합 저장. (구현됨)
- **초기화**: 카드별/전체. (전체 구현됨)
- **평/㎡ 토글**은 면적 전체에 즉시 반영.

## 2. 조건 "유형별" 입력 패턴 (핵심)

### A. 금액 range (매매가·평단가·보증금·임대료·관리비·광고가)
- min~max 통합 박스 + **프리셋 칩** (구현됨).
- **"이상만" 빠른 모드**: 매매가는 대개 "N억 이하"로 검색 → 한쪽만 입력해도 자연스럽게.
- 슬라이더(양방향 핸들) 옵션 — 대략 범위 감 잡을 때.

### B. 비율 range (수익률·상승률·손익)
- 대개 **"X% 이상"** 검색 → `이상` 기본 프리셋 (예: 수익률 3%↑ / 4%↑ / 5%↑ 칩).

### C. 카테고리 (건물용도·용도지역·주용도·지목·이용상황·도로접면·진행상태·소유자종류·긴급도·등급·입지·명도·멸실·용도변경·경사등급·유동인구)
- ★ **단일 드롭다운 → 다중선택(멀티셀렉트 칩)** 으로 전환이 핵심.
  - 예: 용도지역에서 "일반상업 + 근린상업 + 준주거" 동시 선택.
  - 칩 클릭 토글, 선택된 건 색상 강조.
- 값이 많은 표준코드(용도지역 25·주용도 29·지목 28)는 **검색 가능한 멀티셀렉트**(입력 시 필터링).
- 자체 등급(긴급도/등급/입지)은 **A~E 세그먼트 버튼** 여러 개 선택.

### D. 날짜 (사용승인일·대수선·매각일)
- **"최근 N년 이내" 프리셋** 이 직관적: 사용승인일 → `신축(5년↓)` `10년↓` `20년↓` `20년↑(구옥)`.
- 정밀 검색용 date range도 병행.

### E. 유무/불리언 (전화번호·사진·브리핑·총공실·엘리베이터·주차장·매각이력·광고등록)
- **토글 3단**: 전체 / 있음 / 없음.
- 엘리베이터·주차장은 "있음" 외에 **최소 대수**(예: 주차 5대↑)도.

### F. 거리 (역과의거리) — ★직관 개선 포인트
- 미터 입력 대신 **도보시간/역세권 칩**: `역세권(도보5분↓)` `도보10분↓` `500m↓` `1km↓`.
- 더 나아가 **지도에서 반경 그리기**로 지역+거리 동시 지정 (S03 반경 UI 재사용 가능).

## 3. 필드별 특이 아이디어

| 조건 | 아이디어 |
|---|---|
| 역과의거리 | 도보 N분 칩 + 지도 반경 |
| 사용승인일 | 연식 프리셋(신축/구옥) |
| 매각 | "매각 이력 있음" 토글 + 매각손익 range + 매각회수(N회↑) |
| 광고가 | "네이버광고 있는 매물만" 토글(=광고등록) + 광고가 range |
| 용도지역/주용도/지목 | 검색형 멀티셀렉트(코드 많음) |
| 진행상태 | 멀티 칩(준비중·진행중·가격제시 동시) |
| 총공실 | 있음/없음/확인중 칩 (공실 매물만 보기) |
| 수익률/자기자본수익률 | "X%↑" 프리셋 |
| 유동인구 | 매우높음~ 칩 멀티, "비즈맵 수기" 안내 |
| 경사등급 | 평지/완경사 위주 멀티(급경사 제외 검색 등) |
| 대지/연면적 | 프리셋 + 슬라이더, 평/㎡ 반영 |

## 4. 화면 배치 제안

```
[지역/주소 + 역과의거리]  ← 항상 표시
[적용된 조건 칩바 · 실시간 N건]
┌면적/규모▾┐ ┌금액/수익▾┐ ┌광고/매각▾┐   ← 카드 접힘 = 대표조건만
│대지·연면적│ │매매가·수익률│ │광고가·매각일│
│건축·EV·주차│ │           │ │매각        │
│사용승인일  │ └──────────┘ └──────────┘
└──────────┘
┌속성/상태▾┐ ┌공시지가▸┐                    ← 공시지가는 헤더만(펼침)
│건물용도    │ └────────┘
│용도지역    │
│진행상태    │
│소유자종류  │
└──────────┘
   [카드 펼치면 그 대목의 나머지 조건 전부]
```

## 5. 우선 적용 추천 (효과 큰 순)
1. **카테고리 멀티셀렉트 칩** (단일 드롭다운의 한계 해소) — 가장 큰 직관성 향상
2. **실시간 결과 건수**
3. **역과의거리 = 도보시간 칩 / 지도 반경**
4. **날짜 = 연식 프리셋**
5. **유무 토글 + 최소대수**
