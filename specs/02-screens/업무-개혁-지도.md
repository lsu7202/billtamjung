# 업무 개혁 지도

> 개혁의 큰 그림 정본. 상태: **확정** · **초안 차례**(실물로 그릴 순서) · **미정**.
> 업무 흐름 정본 = 교본 2권(영업편·계약편). 생김새 정본 = 프론트 초안.
> 순서: 지도 → 실물 초안(프론트만, 저장 없음) → 확정 → DB → API → 본 수정.

## 2. 매물 모달

| 탭 | 내용 |
|---|---|
| 소유자 | 기존 그대로: 이름 · 전화(마스킹) · 구분 · 관계 · 나이 · 성별 · 협조 · 응대. 멈춤은 사유만(메모는 메모창으로) |
| 접촉 | 기존 그대로: 통화 · 의사 · 급함 · 시기 · 전환. 멈춤 동일 |
| 정보 | 기존 그대로: 명도 · 용도변경 · 멸실 · 임대내역 · 가격. 멈춤 없음 |
| 계약 | 매도희망가 · 매매가 · 매수희망가 · 거래금액 · **계약금 · 잔금** · 가계약·중도금(**조건부 켜기**, 여부+금액) · **[문서] 버튼** · 매수자 서브탭 · 호가판 |
| **할일** | 영업교본부터 계약교본까지 **전 단계 퀘스트 한 줄기**. 누르면 짧은 설명·이행 방법, 문자 붙는 항목은 ⧉복사. 완료는 성격별(자동/손체크). 돈 항목은 줄이 곧 입력칸. 문서 항목은 문서 창을 여는 문. 가계약·중도금 항목은 조건부 |
| 메모창 | 날짜 · 내용 · 적은 사람. 사람이 적은 것만(필드 변경 자동 기록 제거). 전 탭 공통 |

사람 인적사항(주소 · 주민번호 · 공동명의 · 대리인, 매수자는 +법인번호 · 외국인): 추가 확정, 배치 미정.

## 3. 낱말

- 계약 칸: **합의 전 → 합의중** → 계약예정 → 계약완료 (협의를 합의로 교체)
- 잔금완료 · 신고완료, 레일 구성, 목록 칩 판정: 기존 그대로
- 잔금·신고 레일 칸 클릭 → 할일 탭 해당 단계
- 매매가 = 내건 값 · 거래금액 = 계약된 값

## 4. 할일 엔진

**교본 개정 반영(2026-08-24)** — 다섯 가지가 바뀌었다.
1. **준비 서류 통보 신설**(계약 전 첫 자리) — 합의 다음 날(가계약금이 오갔으면 입금 다음 날).
   기한이 아니라 체크리스트로 관리하고, 합의가 서면 조건으로 발동한다.
2. **임차인 새 계좌 안내는 등기 완료 뒤** — 잔금 직후가 아니다. 소유권이 넘어가기 전에 계좌를
   알리면 임차인이 낸 임대료가 어긋난다.
3. **잔금 D-7의 공과금·정화조는 「우리가 정리해 드린다」는 안내** — 결과 통보가 아니라 대행 선언.
4. **신고필증 대조 삭제** — 신고 내용과 계약서는 같은 것이라 대조가 겹친다. 필수확인 9→8항목.
5. **D-2와 D-1을 D-1로 통합** — 계약·중도금·잔금 셋 다.


- 성격 8: 약속 · 연락 · 받고 주기 · 돈 · 기한 · 문자 · 확인 · 문서. 공통 필드 = 이름 · 매물, 성격이 나머지 필드를 정함
- 발동 = AND 결합: 사건(전제) · 속성(전제) · 시점(때) · 빈값(내용)
- 완료: 값 채우면(돈) · 행동하면(약속·문서) · 결과 기록되면(연락) · 손체크(받기·확인·목적형 문자)
- 전부 파생, 저장 없음. 보는 창 셋: 할일 탭(이 매물 전부) · 대시보드(전 매물 급한 것) · 캘린더 서랍(날짜 없는 것)
- 문자: 템플릿+값 치환, ⧉복사만. 수단형은 버튼, 목적형은 할일
