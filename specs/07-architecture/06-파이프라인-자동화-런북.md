# 데이터 파이프라인 자동화 · 런북

> 크롤 → 활성화 → 빌드 → Postgres 적재 엔드투엔드 자동화(2026-08-02 구축).
> 전체 실행: `scripts/run_pipeline.sh`. 크레덴셜=`scripts/.env.pipeline`(gitignore) + `backend/.env`.

## 파이프라인 구조
```
scripts/crawl_all.py      크롤(실거래·HUB·교통·임대·승강기·V-World[자동로그인])  → data/raw/_dl (스테이징)
scripts/activate.py       스테이징 → 정규 raw (unzip·extract_seoul·SHP 배치)      → data/raw/*
pipeline/build_all.py     빌더 15단계 → 빌탐정.db → export CSV                     → data/exports/_load/*.csv
pipeline/loader.py        CSV → COPY → 검증게이트 → 원자스왑 → version++            → Postgres master.*
```
- **월-스탬프 자동해소**: V-World SHP 파일명의 `_YYYYMM`은 `data/tools/paths.py`가 glob으로 처리 → 갱신 시 코드수정 0회.
- **V-World 자동로그인**: `scripts/vworld/login.py`(비번 base64, `/v4po_usrlogin_a004.do`). `VW_ID/VW_PW`만 있으면 쿠키 수동 불필요.

## 실행
```bash
scripts/run_pipeline.sh                 # 전체(crawl→activate→build→load)
STEP=build scripts/run_pipeline.sh      # 빌드부터(크롤·활성화 스킵)
STEP=load  scripts/run_pipeline.sh      # 적재만
GROUP=monthly scripts/run_pipeline.sh   # 크롤 주기만(실거래)
```

## 검증 테스트 (2 tier)

### Tier 1 — 안전(비파괴): 현재 raw/DB로 재현성 확인
프로덕션 뷰를 건드리지 않고 **별도 테스트 DB**에 재적재해 baseline과 대조.
```bash
# 1) 테스트 DB 생성 + 스키마
createdb -h localhost -p 55432 -U postgres billtamjung_test
DATABASE_URL=postgresql://postgres:PW@localhost:55432/billtamjung_test ./db/apply.sh
# 2) 현재 빌탐정.db → export → 테스트DB 적재
STEP=build EXPORT_DIR=/tmp/exp \
  DATABASE_URL=postgresql://postgres:PW@localhost:55432/billtamjung_test \
  scripts/run_pipeline.sh
# 3) 카운트 대조: billtamjung_test.master.* == baseline(±허용오차)
```
- **build 재빌드도 검증하려면**: raw는 현행 유지, `빌탐정.db`만 백업 후 `build_all.py`로 재생성 → 두 db 카운트/샘플 diff.

### Tier 2 — 풀 from-scratch(파괴적, 사용자 입회 권장)
raw·빌탐정.db·Postgres 전부 비운 뒤 크롤부터 재현. **32GB 재크롤 + 수시간 빌드** → 무인 실행 비권장.
```bash
# 백업
pg_dump "$BT_DATABASE_URL" > /backup/pg_$(date +%F).sql
tar czf /backup/raw_$(date +%F).tgz data/raw          # (32GB, 시간·디스크 주의)
cp data/빌탐정.db /backup/
# 4건 보존물 별도 대피(위 목록) → raw 초기화 → run_pipeline.sh 전체 → baseline 대조
```

## 적재 후 파생 재빌드(순서 고정)
Postgres 적재(loader) 완료 후 파생 테이블 3종을 재실행해야 검색·리포트가 최신 원천을 반영한다:
```bash
PY=backend/.venv/bin/python
$PY scripts/rent_estimate/build_price_index.py          # ① master.sale_price_index — F-17 v3.1 분기 시점보정 지수
$PY scripts/rent_estimate/build_sale_est.py             # ② master.building_sale_est — 적정가 배치(①의 지수를 읽음)
data/.venv/bin/python scripts/vworld/load_redevel_zones.py   # ③ master.redevel_zone/building_redevel — F-21 정비구역 태깅(V-World UD602/603 갱신 시)
```
①→② 순서 필수(②가 ①의 지수를 병합). ③은 독립 — V-World SHP 갱신(반기) 때만.
