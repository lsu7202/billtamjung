> 1차는 **명세 ↔ 목업 대조**였다. 그래서 "한쪽에만 있는 것"(불일치)은 잘 잡았으나, **양쪽 다 없는 것**은 구조적으로 잡을 수 없었다.

## 0. 최대 블로커 — 앱 데이터 레이어가 문서상 존재하지 않는다

`04-data/schema.md`는 **건물·토지 물리 스키마만** 정의한다(`schema.md:5` "1행=건물 1동").

```

```

즉 **부동산 데이터 레이어만 있고 애플리케이션 데이터 레이어가 없다.** 그런데:

  → `F-17 ④ 유사도 가중치 = max(0.3, 1−|Δ|/20)`가 **하한 0.3으로 포화** → 유사도 가중평균이 사실상 단순평균이 되어 **F-17의 핵심 로직이 무력화**
  → **해법 권장**: 결측 항목은 **본매물·comp 양쪽에서 제외**하고 남은 항목으로 가중치 재정규화(비교의 대칭성 확보)
- `S03:51`(자동저장 오버레이) ↔ `:52`(체크상태는 세션 유지) 모순 — 생성기가 영속값을 읽는지 세션을 읽는지 불명
