## 테마 1 · 목업 샘플 데이터 정합성 붕괴 — **최우선** [데이터]

여러 화면·PPT가 **한 건물의 일관된 데이터셋을 안 쓰고** 서로 다른 샘플을 박아넣어, 같은 화면 안에서도 값이 어긋난다. 데모에서 가장 티나는 결함.

| # | 위치 | 모순 | 근거 |
|---|---|---|---|
| 1-1 | S02 헤더 ↔ 건물정보 | 헤더 대지 **71.9평**·연면적 143·건축 37.8·**B1F/3F** vs 본문 대지 **745.6평**·연면적 2,200·건축 445·**지상17/지하7** (≈10배차). 평단가(대지) 1.39억도 71.9평 기준이라 745.6과 불일치 | S02.html 220-224 vs 328-331 |
| 1-2 | S02 공시지가 표 ↔ 그래프 | 표=필지값(144-6, 2026년 **3,325만/㎡**) vs 그래프·상승률=하드코딩 **1,312만/㎡**. 같은 블록에서 다른 값 | S02.html 906·938 vs 863-876 |
| 1-3 | R_example.pptx 가치점수 | 표지 **80.4점 A** vs STEP1 **82.2점 A** (같은 보고서 총점 2개) | slide1 vs slide4 |
| 1-4 | R_example 현재수익률 | slide2 **1.63%**(현재월세 기준) vs slide7 **1.79%**(매도희망가 기준) — 둘 다 "현재수익률"로 읽힘 | slide2 vs slide7 |
| 1-5 | 상권 반경 기본값 | 목업 **400m**(S02:729) vs R_example **500m**(slide3/5/6) | — |

**조치**: **기준 샘플 건물 1채**(예: 삼성동 144-6)의 정합 데이터셋(면적·층수·공시지가·수익률·반경)을 확정하고 S02·R_example·브리핑에 **동일 값 통일**. 필지 전환 그래프 갱신(1-2)은 구현 이슈 → 테마 2로.

## 테마 3 · 스펙 ↔ 목업 방향 충돌 — **결정 필요** [결정]

대부분 **목업이 더 진화**했고 스펙이 옛 상태. → 원칙적으로 "목업을 정답으로, 스펙을 업데이트" 권장. 개별 확인 요망.

| # | 화면 | 충돌 | 권장 |
|---|---|---|---|
| 3-1 | S0M | 목업엔 **"데이터 변경됨/최신" stale 배지 + '변경됨' 행에만 재생성** 게이팅. 스펙은 무조건 재생성, stale 개념 없음 | 목업 채택 → 스펙에 stale 판정 UI 반영(신선도 §아키텍처와 연결) |
| 3-2 | S01b | **주용도 컨트롤**: 스펙 TBD인데 목업은 우선순위 2단(주용도주15/부21) 구현 | 목업 채택 → 스펙 TBD 확정 |
| 3-3 | S01b | 옵션 많은 다중선택: 스펙 "가로 스크롤 알약" vs 목업 "세로 wrap" | 결정 — 세로 wrap이 잘림 없음(목업 권장) |
| 3-4 | S01b | **담당자 필터**: 스펙=팀멤버 연동 드롭다운(참조값) vs 목업=고정 이름 3개 | 스펙 채택 → 목업을 팀 연동 플레이스홀더로 |
| 3-5 | R | **내 산출물 저장**: 스펙 §2=명시 버튼 vs §2a·목업=완료 시 자동보관 | 자동보관 채택 → §2 문구 수정 |
