## 0. 한눈에 — 🔵 정식 이관 항목 (베타 이후 로드맵)

베타에서 빠지고 정식에서 들어오는 것만 추림. **나머지는 전부 베타.**

| 영역 | 정식 기능 |
|---|---|
| **인증** | 전화번호 SMS 인증(1번호=1계정 어뷰징 방어), 소셜 로그인(카카오·네이버·번호 자동연동), 딥링크 복귀 |
| **결제/구독** | 크레딧 충전, 구독 플랜 카드·업다운그레이드·가격, 결제수단·청구, 실제 크레딧 차단(베타는 그림자 계량) |
| **팀 협업** | 팀원 초대·수락, 공유범위 정책, 담당자 재배정, 퇴사 승계, 팀원 제외/탈퇴, 팀명 변경, 대표 위임·팀 삭제(TBD) |
| **집단지성 고급** | 광고가 입력(집단지성), 수정이력 값 분포(익명), 위키 댓글·신고, 비밀메모, 전화번호 열람 마스킹 |
| **알림·설정** | 알림 채널·항목 설정, 연결된 소셜 계정 관리, 이메일/전화 변경, 계정 삭제 |
| **지도 고도화** | 지도 API 요금·쿼터+정적지도 폴백, 좌표 정확도 보정, 클러스터 임계·스타일 튜닝, 로드뷰 초기 회전 최적화, **영역 그리기 자석 스냅(실시간)**·복수 영역·영역 저장 |
| **검색 확장** | 도로명↔지번 매핑 보강, 규제 7종 필터(전서울 규제 확장 후) |
| **파이프라인** | ~~정식~~ **베타로 이동(2026-07-21)** — Cloud Scheduler + Job 자동 적재를 베타부터 완성([[07-architecture/01-상세설계]] §2) |

> 핵심: **베타 = 로그인(이메일)→검색→필터→상세 조회·수정→주변시세 curation→보고서 생성**까지의 1인 사용 완결 루프. **정식 = 협업(팀)·수익화(결제)·어뷰징 방어(전화/소셜)·집단지성 고도화.**
