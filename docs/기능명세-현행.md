# 빌탐정 기능 명세 (현행) · 명세 대조 · 점검 결과

> 코드 기준 현재 제공 기능의 상세 문서. 명세서(`specs/`)와 대조해 갭·보완점을 정리하고, 실동작 점검 결과를 기록한다.
> 최종 갱신: 2026-08 (세션 자율 작업분 반영)

## 1. 백엔드 도메인별 기능 (FastAPI, `backend/app/domains/`)

### auth · social — 인증
- `POST /auth/signup·login·refresh·logout` · `GET /auth/me` — JWT(access+refresh). 로그인 유지=refresh.
- `GET /social/{provider}/start·callback` — 소셜 로그인 OAuth 시작/콜백.

### buildings — 건물 상세 (S02 핵심)
- `GET /buildings/{pk}` — 마스터 + 팀 오버레이 병합(`app.building_view`). 좌표·필지경계(GeoJSON)·유동인구 추정등급·**적정가(배치)**·**마스터 예상수익률(roi)**·지역 지가상승률(land_adjust) 포함.
- `GET /buildings/{pk}/floor-outline` — 층별개요(층별임대 프리필용, 마스터 추정 rent_est).
- `GET /buildings/{pk}/parcels` — 대표+부속 필지.

### search — 통합검색 (S01/S01b)
- `GET /search/suggest` — 주소 자동완성(접두검색) + **좌표(lng/lat)** 반환 → 지도 중심이동.
- `GET /search/regions` — 시군구·법정동 캐스케이드(인메모리 캐시).
- `POST /search/snap` — 자석 올가미(그린 영역↔필지 union 스냅).
- `GET /search/parcel-at` · `/parcel/{pk}` — 클릭지점 필지 / 건물 필지경계.
- `POST /search` — 2열(내매물/일반) 페이징 결과. **classified CTE**: 매매가=팀 sale_price ?? **적정가**, 수익률=rent(팀 floor_rents ?? 마스터 rent_est) ÷ 매매가, `price_is_est` 플래그.
- `POST /search/pins` — 지도 핀(경량, 3000 상한) + sale_est(적정가).
- `_filter_sql` — **23개 서버 필터**(아래 §4 대조).

### market — 주변시세
- `POST /market/nearby` — 상권 반경 comp(실거래·임대), IQR 이상치 제외.

### floor_rents · series — 임대/시세 데이터
- `GET·PUT·DELETE /floor-rents` — 층별 임대(보증금·월세·공실) CRUD, contract_area 단위 정합.
- `GET·PUT·DELETE /series` — 시세 시계열(공시지가·실거래) 편집. **공시지가 1990~2026 전 구간**(이번 백필).

### listings — 업무 (담당·업무정보)
- `GET /listings/members` — 팀원 목록(담당자 드롭다운).
- `GET /listings/{pk}` — 매물 업무정보.
- `PUT /listings/claim` — 담당자 배정(→ 내매물 분류).
- `PATCH /listings/biz` — 업무정보 편집(수기 매매가 등).
- `GET /listings` — 내 업무 목록.

### overlays — 데이터 수정(팀 공유 오버레이)
- `PUT·DELETE /overlays` · `DELETE /overlays/all/{target}` — 마스터 불변 + 유저 오버레이(팀 공유). 3-모드 편집.
- `GET /overlays/distribution/{target}` — 값 분포.

### extras — 부가기능
- `GET /enums` · `/fields` — enum·필드 메타.
- `PUT·GET /favorites` — 즐겨찾기(★).
- `POST·GET·DELETE /saved-searches` — 검색조건 저장/불러오기.
- **위키**: `POST·GET /buildings/{pk}/wiki` · `DELETE /wiki/{id}` · `PUT /wiki/{id}/vote` — 매물 위키글 + 투표.
- **메모**: `PUT·GET·DELETE /buildings/{pk}/memos` — 팀메모/비밀메모(`app.memo_kind`=team,secret).

### photos — 사진
- `GET·POST·DELETE /photos` · `GET /photos/{id}`(blob, 인증헤더) — S02 유저 업로드 사진.

### reports — 분석보고서 (S02b)
- `GET /reports/comps/{pk}` — S02b 초기(comp 목록·미리보기·지도핀).
- `POST /reports/preview` — comp 편집 반영 실시간 미리보기.
- `POST /reports` — **분석보고서 생성**(비동기잡, 크레딧 30). ※ 브리핑 폐지 — analysis만.
- `GET /reports/{id}/download` — PPTX 다운로드.
- `GET /reports/{id}` · `GET /reports` — 조회/목록.

### credits — 크레딧
- `GET /credits` · `/credits/entries` — 잔액·사용내역.

## 2. 프론트 화면 (React, `frontend/src/features/`)

- **S00 로그인/회원가입** (`auth/`) — 로그인 유지·약관 게이팅.
- **S01 통합검색** (`search/SearchPage`) — 지도 우선. 핀 태그 **적정가/실거래 토글**, 클러스터, 회색점(비상업). **사이드카드**(적정가·수익률·층수·면적·실거래추이 = 즉시값). **자동완성 주소=지도 중심이동+선택**, **지명(강남역)=지오코딩 중심이동**. 2열 리스트(내/일반, 매매가·수익률·'적정' 표기).
- **S01b 필터 모달** (`search/FilterModal`) — 지역 캐스케이드 + 60필드 UI(서버 23필드 실동작 §4).
- **S02 상세** (`building/BuildingPage`) — 헤더 계기판(면적 평/㎡ 토글), **지도·로드뷰 통합탭**(FOV 부채꼴·초기시야 본매물 보정·로드뷰 확대), 층별임대, **업무·메모·위키 탭**(`Sidebar`), 리포트뷰(`ReportView`), 데이터 편집(오버레이).
- **S02b 분석보고서 생성** (`building/ReportModal`) — comp F-16 편집·실시간 미리보기·크레딧 명세.
- **S0M 마이페이지** (`mypage/MyPage`) — 크레딧·내 산출물(재생성)·저장검색.
- **리포트** — 웹 덱(`ReportPage` 10슬라이드) · 애니메이션(`ReportStory`) · PPTX(`generate_report`). 단일소스 `reportModel`.

## 4. 명세 대조 · 갭 · 보완점

### 필터 (S01b) — 전 필터 작동 ★(이번에 전면 구현)
S01b UI의 모든 필터가 실제 검색에 반영되도록 backend `classified` CTE(raw→classified 2단)·`_filter_sql`(마스터/계산값 분리)·프론트 `toFilters`를 전면 확장.

**작동 필터(전부):**
- 마스터: 용도지역·지목·토지이용상황·지형형상·도로접면·지세·**주용도**(main_use_name 직접매칭)·기타용도·대지/연면적·건축면적·**토지면적·용적률산정연면적**·엘리베이터·주차장·규모지상/지하·건폐율·용적률·역과의거리·사용승인일·**대수선경과**·최신공시지가·실거래가·실거래일
- 계산값(classified): **매매가·수익률(만실/공실제외)·평단가(대지/연면적)·공시총액·총공시/매매·공시상승률5/10년·실거래손익·실거래횟수·유동인구(proxy)·법정건폐/용적·건폐/용적 여유분**
- 집계(floor_rents): **총보증금·총임대료·총관리비·총공실**
- 업무(listings 오버레이): **진행상태·긴급도·등급·입지·소유자타입·관계·협조도·친절도·건물용도·명도·용도변경·멸실·담당자·소유자명·매물번호·매수의향서·전화번호(유무)·접수일·사진(유무)**

**참고(정확도 주석):**
- 법정건폐/용적·여유분 = **서울시 도시계획조례 표준치**(자치구 세부 조례 미세차 가능).
- 유동인구 = 접근성 proxy(도로접면+역거리), value_score와 동일.
- 실거래손익 = 최근 2건 등락률. 담당자·업무 값 = ref.enums(code=label 한글) 직접 매칭.
- 업무 신규 컬럼(명도·용도변경·멸실·노후도·건물용도)은 0022 마이그레이션 + BIZ_FIELDS 추가로 S02 편집·필터 동시 지원.

### 기타 갭
- `app.report_kind` enum에 `briefing` 값 잔존(미사용) — 정리하려면 마이그레이션(선택).
- `specs/03-features/브리핑자료.pptx` = 폐지된 기능 정본 → 문서상 deprecated 표기 권장.
- (메모 기록) 라이브 comp union 미적용 divergence·F-20 임계 보정 등은 별도 트랙.
