## 실제로 잰 값

본매물에서 구역까지 거리를 PostGIS 로 재 봤다.

```
효제2구역                      73m
효제1구역                      97m
효제3구역                     329m
세운재정비촉진지구 세운4구역     342m
```

팀원 자료의 지도와 같은 그림이 나온다. 필지 규제도 국토부 원장에서 그대로 온다.

```
도시관리계획 입안중 · 도시지역 · 지구단위계획구역 · 토지거래계약에관한허가구역 ·
가축사육제한구역 · 과밀억제권역 · 대공방어협조구역 · 상대보호구역 · 서울도심 · 중점경관관리구역
```

「도시관리계획 입안중」과 「토지거래계약에관한허가구역」은 그 자체로 중개인이 알아야 할 사실이다.

## 날짜 구멍은 메웠다 (2026-09-04 저녁)

원본 SHP 을 열어 보니 우리가 안 읽고 버린 칸이 둘 있었다.

- `NTFDATE` 고시일자. 원본이 **32%**만 채웠다
- `MNUM` 관리번호. 여기 고시 정보가 박혀 있다

```
61100001111020260145UDT1000001000
       ^^^^^ ^^^^ ^^^^
       시군구 연도  번호     →  종로구 · 서울특별시 고시 2026-145호
```

839건 전부 이 자리가 숫자다. NTFDATE 가 있는 266건과 연도를 대조하니 98%·91% 일치했다.
로더를 고쳐 다시 실었다.

```
고시연도 있음  817 / 839  (97%)
고시일자 있음  273
```

**효제1·2·3구역은 서울특별시 고시 2026-145호, 세운4구역은 2016-103호(2016-04-07)다.**
팀원 자료의 「2026년 3월 지정」과 연도가 맞는다.

날짜가 생기니 거르기가 된다. 종로5가 93-1 반경 600m 안 구역이 14개인데,
최근 3년으로 좁히면 9개가 된다.

## 이름 구멍도 메웠다 (2026-09-04 저녁)

839개 중 317개(38%)가 이름이 비어 있었다. 원본 REMARK·ALIAS 가 비었으니 원천에 없는 것이고,
같은 고시번호에서 이름을 빌릴 수 있는 것은 3건뿐이었다. **고시번호를 이름 대신 쓴다.**

```
이름 없음  →  「서울특별시 고시 제2025-629호 정비구역」
```

`redevel_zone.label` 을 생성열로 두어 이름이 있으면 이름, 없으면 고시번호를 낸다.
지어내지 않고 화면에 「(이름없음)」이 안 서는 유일한 길이다.

```
이름도 고시번호도 없어 여전히 못 부르는 구역   6건 (839개 중)
태깅된 건물 중 이름이 서는 것              127,968 / 129,153 (99%)
```

**이 김에 버그 하나가 같이 잡혔다.** `build_building_score.py` 는 `rd.name` 이 비면 정비구역
안에 있는 건물인데도 매력도 점수의 정비 축을 통째로 못 받았다. 이제 `label` 을 본다.

`building_redevel` 이 `kind·name` 뿐이라 고시 날짜가 구역 표에만 있고 건물엔 안 왔다.
`zone_id·label·gosi_year·gosi_no·ntf_date` 를 같이 내리게 고쳤다.

## 남은 결함 둘

**① 이름이 설명문인 것 72개.** 「정비예정구역, 건축물의 건축 등 행위제한」처럼 이름 자리에
설명이 들어 있다. 원천이 그렇다. 글자가 깨진 것도 3개.

**② 너무 많이 걸린다.** 반경 1.5km 안에 정비구역이 서른 개 넘게 잡힌다. 그대로 보여주면 소음이다.
팀원은 일곱 개만 골랐다. 그 고르는 일을 사람이 했다. 지구단위계획까지 실었으니 오히려 늘었다.

## 지구단위계획 이름도 메웠다 (2026-09-04 밤)

「지구단위계획구역 포함」까지만 알고 **어느 계획인지 몰랐다.** 공공데이터포털에서 새로 받을
줄 알았는데, **8월에 이미 받아 둔 파일이 있었다** — V-World C_UQ161(`data/raw/C_UQ161`).
전국 13,144건 중 서울 948건을 싣는다.

고시일은 고시일련번호에 박혀 있다.

```
11410NTC202012110003
     ^^^ ^^^^^^^^
         고시일자       →  2020-12-11
```

```
지구단위계획구역  948건 · 이름 948 (100%) · 고시일자 919 (97%)
태깅 건물         148,715동
```

본매물 종로5가 93-1 로 대 보면 팀원 자료의 2·4번이 그대로 나온다.

```
종로4·5가 지구단위계획구역          2023-08-25   구역 안
율곡로 지구단위계획구역             2024-07-12    55m
주교 지구단위계획구역               2005-03-17   198m
동대문역사문화공원주변 지구단위계획   2024-04-23   202m
```

**율곡로는 날짜가 어긋난다.** 팀원은 2025-05 고시라 적었고 우리 원천은 2024-07-12 다.
원천이 아직 안 따라왔는지 다른 고시인지는 확인해야 한다. 고쳐 적지 않고 원천 값을 그대로 둔다.

`scripts/vworld/load_district_plans.py` · 파이프라인 derive 단계에 넣었다.

## 원천 확인 결과 (2026-09-04 저녁)

**서울시 고시공고 API 는 죽었다.** OA-2482(고시공고)와 OA-20283(도시계획 결정고시) 둘 다
「종료된 서비스」다. 다른 서울 API(공공와이파이·상권)는 같은 키로 멀쩡히 돈다.

**본청 고시공고 게시판은 검색이 되지만 지명으로는 안 걸린다.**
「지구단위계획」으로 치면 도시계획 고시가 나오는데, 「종로5가」·「효제동」·「효제1구역」은 0건이다.
고시 제목에 동 이름이 안 들어가고, 자치구 고시는 본청에 없다.

**자치구 고시공고 API 는 송파구(`SpNotice`)만 살아 있다.** 다른 구는 500을 낸다.
`SpNotice` 는 `SEQ · SNAME · BUSEO · TITLE · CONTENT · REG_DATE` 를 주고 **본문이 통째로 온다.**

**웹 검색으로는 팀원이 꼽은 것을 다 찾을 수 있다.** 실제로 해 봤다.
종로5가역 출입구 개선은 서울시 디자인 사업으로 2026년 10월 완공 목표(팀원 자료는 12월),
창경궁로 보행친화거리는 종로4가~퇴계로4가 0.9km 도로공간재편으로 5월 말 완료다.

## 그래서 할 일

1. ~~정비구역에 날짜를 붙인다~~ **끝냄.** MNUM·NTFDATE 를 읽어 고시연도 97%·고시일자 273건.
2. ~~이름 없는 317개~~ **끝냄.** `label` 생성열이 고시번호를 대신 낸다. 못 부르는 것 6건만 남았다.
3. ~~지구단위계획 계획명~~ **끝냄.** 받을 필요도 없었다 — V-World C_UQ161 을 8월에 이미 받아 뒀다.
   서울 948건 전부 이름이 있고 919건(97%)에 고시일자가 있다. 팀원 자료 2·4번이 여기서 나왔다.
4. **거리 대신 지도.** 서른 개를 목록으로 세우면 못 읽는다. 위치를 아는 것은 지도에 찍고, 목록은 날짜순으로 짧게 둔다.
5. **못 하는 셋은 손으로.** 역 출입구, 보행친화거리, 문화재는 자동으로 못 받는다. 팀이 적는 칸을 둔다.

## 화면안 (2026-09-04 밤)

실제 DB 값으로 건물 상세 「주변 동향」 화면안을 그렸다 —
<https://claude.ai/code/artifact/105630e0-871a-4357-b25f-7a6e40a933ab>

- **거리 열이 없다.** 위치는 지도가 말하고, 목록은 「구역 안」일 때만 그렇다고 적는다
- 지도에 갈래별 아이콘(정비구역 = 쌓이는 층 · 지구단위계획 = 구획 격자), 최근 1년 지정은 파문
- 목록은 날짜순. 고시일자가 있으면 `2024.07.12`, 관리번호에서 연도만 읽었으면 `2026년`
- 줄을 누르면 원장 칸이 그대로 펼쳐진다(고시번호·고시일·원천). 요약하지 않는다

**남은 판단은 둘이다.** ① 반경 700m 에 31개가 걸린다 — 시기 칩으로 줄이는 게 맞는 줄임인지.
② 자동으로 못 받는 셋(역 출입구·보행친화거리·문화재)을 이 목록에 섞을지 따로 둘지.

## 남는 질문

팀원 자료는 호재를 고르고, 각각의 「본매물 효과」를 문장으로 썼다. 그건 사람의 판단이다.
우리가 자동으로 만들 수 있는 것은 **무엇이 있는지까지**이고, 그것이 이 건물에 무슨 뜻인지는 여전히 중개인이 쓴다.
자동화의 목표는 팀원 자료를 대신하는 것이 아니라, **팀원이 일곱 개를 찾느라 쓴 시간을 없애는 것**이다.
