# 주변 소식 — 자료 계획

> 이름 확정(2026-09-06): 「주변 동향」 → **「주변 소식」**. 서울 전체를 자리 없이 보는 **「소식」 탭**과 한 벌이다.

> 화면은 이미 섰다(입지 탭 `lc-ev`). 이 문서는 **그 화면에 무엇을 실을 것인가**를 정한다.
> 파이프라인은 한 번 돌리면 오래 걸리므로, **필요한 자료를 전부 확보한 뒤 한 번에** 돌린다.
> 작성 2026-09-05.

## 갈래는 다섯이다 (2026-09-06 확정)

화면 왼쪽 목록의 머리글이다. **「기타」는 없앴다** — 「그 밖」 1,012건을 열어 보니 도형 있는 358건은
이미 들어와 있었고, 안 들어온 654건은 전부 도형이 없었다. 그중 의미 있는 143건이 규제라
「규제」 갈래로 바꿨다. 「생긴다」와 「못 한다」는 정반대 소식이라 한 머리글 아래 못 둔다.

| 갈래 | 무엇 | 지금 |
|---|---|---|
| 정비·개발 | 정비구역·재정비촉진·지구단위계획 | ✅ 1,787 |
| 기반시설 | 도시계획시설 + 나라장터 공사 발주(보조) | ✅ 5,940 |
| 건축 인허가 | 신축·증축 허가(최근 5년) | ✅ 14,946 |
| 규제 | 개발행위허가제한 — 「지금 못 짓는다」 | ✅ 127 |
| 정책 발표 | 서울시 보도자료 — 본문 없음, 사실과 링크만 | ✅ 580(자리 앎) / 2,039(전체) |

### 두 화면 · 한 자료

| 화면 | 자르는 법 | 무엇이 서나 |
|---|---|---|
| **소식** 탭 (`/news`) | 안 자른다 | 서울 전체. 자리를 몰라도 선다. 고시·공고 4.4만까지 |
| **주변 소식** (건물 상세 → 입지) | 반경 | 자리를 아는 것만. 갈래별 반경(건축 인허가 250m, 나머지 700m) |

자리는 **거르는 조건이 아니라 값**이다(`located`). 그래야 「없는 것」과 「모르는 것」이 갈린다 —
고시 5,456건 중 3,243건, 나라장터 4,698건 중 4,456건이 자리를 모른다. 버리면 AI 도 못 쓴다.

## 1. 정비·개발 — 됐다. 구멍만 남았다

| | 원천 | 상태 |
|---|---|---|
| 도형 | V-World `UD602`(정비구역) · `UD603`(재정비촉진) · `C_UQ161`(지구단위계획) | ✅ 839 + 948 |
| 본문 | 서울도시공간포털 결정고시 | ✅ 1,625/1,787 (90.9%) |
| 고시문 PDF | 같은 포털 | 주소만 1,562. **내용은 안 뽑음** |

### 남은 것 셋

**① PDF 본문 뽑기 — 1,562개.**
5개를 열어 보니 **전부 글자 PDF다(스캔 아님).** `pypdf` 로 바로 뽑힌다. 쪽당 1,000자 남짓.
17,074개를 다 받을 필요 없다 — 동향에 걸린 1,562개면 3GB 남짓, 30~50분.

요지(`content`)에 없고 PDF에만 있는 것: **면적 · 건폐율 · 용적률 · 층수 · 세대수.**
중개인이 볼 값은 대개 이쪽이다.

덤: PDF 첫 줄이 발행 기관을 말한다(「서울특별시 **용산구** 고시 제2025-86호」).
지금 고시번호가 겹쳐 헷갈리는 것(2026-130 이 두 건)을 이걸로 가른다.

**② 못 붙은 162줄.**
효제1·2·3구역이 그렇다 — 고시번호(제2026-145호)는 우리가 갖고 있는데 **포털에 그 번호가 없다**
(130·131·132·133·134·136 은 있다). PDF에 「서울시보 제4112호」라고 찍혀 있으니
**서울시보를 직접 파면** 메워질 수 있다. 확인 안 함.

**③ 이름이 겹치는 줄.**
1,787줄 중 66개 이름이 여러 줄에 걸쳐 있다 — 「지구단위계획구역」 75줄 · 「도시환경정비사업」 25줄 ·
「주택재개발」 18줄. 원천의 이름 칸에 **이름이 아니라 사업 종류**가 들어 있기 때문이다.
고시번호로 찾은 고시 제목으로 갈면 고쳐진다(같은 방법으로 291줄을 이미 고쳤다).

문제는 **자리다.** 고시엔 도형이 없다.

**확인할 것:** 공고 상세 페이지(`bidNtceDtlUrl`)에 현장 소재지가 있는가. 있으면 5% 가 크게 오른다.

## 3. 건축 인허가 — 원천이 이미 우리 안에 있다

건축HUB 마트 **55장 중 「인허가」 계열이 17장**인데, 우리가 받는 것은 「대장」 계열의 표제부 하나뿐이다.

```
[인허가]   17장  기본개요 · 동별개요 · 층별개요 · 대수선 · 공작물 · 철거멸실 · 가설건축물 …
[대장]     10장  기본개요 · 총괄표제부 · 표제부 · 층별개요 …   ← 지금 받는 것
```

필요한 것은 셋이다.

| 마트 | 무엇이 나오나 |
|---|---|
| 인허가/기본개요 | 허가일 · 착공일 · 사용승인일 · 대지위치 → **「옆 땅에 신축이 들어온다」** |
| 인허가/철거멸실 | 철거 신고 → **「저 건물이 없어진다」** |
| 인허가/대수선 | 대수선 허가 |

대지위치(PNU)가 붙어 오므로 **자리 문제가 없다.** 갈래 셋 중 가장 쉽다.

## 4-1. 발표는 났는데 고시도 발주도 없는 구간 — **보도자료로 판다**

팀원이 덱에 넣은 **종로5가역 7·8번 출입구 개선**을 끝까지 쫓았다(「78번」이 아니라 **7·8번**이었다).

```
종로5가역 7·8번 출입구 일대 디자인경관 개선사업 · 약 130㎡ · 서울시 · 2026년 착수 예정
같은 프로젝트: 창동역 일대 · 강북구 4·19로 · 낙산 성곽길
```

**고시 43,986건에도 없고 나라장터 3년치에도 없다.** 도시관리계획 결정이 아니라 디자인정책 사업이라
고시가 안 나고, 아직 발주 전이라 나라장터에도 없다. 같은 프로젝트의 다른 곳이 「올해 설계, 내년 준공」이니
공사 발주는 2026 하반기~2027이다. **정책 발표부터 발주까지 1~2년의 빈 구간**이 있고,
하필 중개인이 알고 싶어 하는 시점이 거기다.

### 서울시 보도자료 — 길은 확실하다

그 건은 **보도자료에 있었다**(`nttNo=456622` · 2026-04-21 · 디자인정책관 도시경관담당관).

```
목록  https://www.seoul.go.kr/news/news_report.do?curPage=N&bbsNo=158
      10건/쪽 · 6,356쪽 ≈ 63,560건 · **서버에서 그려진다**(번호·제목·담당부서·등록일)
상세  https://www.seoul.go.kr/news/news_report.do?bbsNo=158&nttNo=456622
증분  1쪽만 받아 아는 nttNo 가 나오면 멈춘다 → 하루 한 요청
백필  3년치 = 목록 약 1,400쪽 (2022-10 이 1,500쪽 언저리)
```

### 수확은 얼마나 되나 — 실측(2026-08-07 ~ 09-04, 295건)

```
한 달 295건 → 연 3,500건
  개발·시설 관련 제목        49건 (17%)  → 연 600건
  그중 **우리 DB에 실재하는 자리**가 잡힌 것  11건 (22%) → 연 130건
```

건진 것 표본: 전농동 152-65 신통기획 · 사당동 305-35 신통기획 · 상도동 214 신속통합기획 ·
광진 모아타운(구의동 587-58) · 길음 역세권 장기전세 · 대치동 코엑스 리모델링.
**신속통합기획·모아타운이 고시 나기 전에 여기서 먼저 잡힌다.**

### 라이선스 — **사실만 뽑는다(2026-09-05 대표 확정)**

보도자료는 본문 끝에 이렇게 붙어 있다.

```
본 저작물은 "공공누리" 제4유형: 출처표시 + 상업적 이용금지 + 변경금지
```

빌탐정은 유료 서비스라 상업적 이용이다. **본문을 저장하거나 화면에 싣지 않는다.**
저작권은 표현을 보호하지 **사실을 보호하지 않는다** — 사실만 뽑아 우리 칸에 채우고 원문 링크를 건다.

| 하는 것 | 안 하는 것 |
|---|---|
| 위치(역·도로·지번) · 규모(면적·세대·층수) · 발표일 · 담당부서 · 원문 URL | 본문 문장을 DB에 저장 |
| 뽑은 사실로 **우리가 이름을 짓는다**(「종로5가역 일대 · 디자인경관」) | 기사 제목·부제를 그대로 싣기 |
| 파싱할 때만 본문을 메모리에서 읽고 **버린다** | `body` 칸에 넣기 — **비워 둔다** |

고시와 같은 줄에 세우지 않는다. 고시는 결정이고 이건 **발표**다. 갈래를 따로 둔다.

### 함정 셋

① **제목만으로는 안 된다.** 「9월부터 전 한강공원**으로**」가 도로명으로 잡힌다. 본문을 받아
   **우리 `subway_stations`·`road_segment` 에 실재하는 이름인지 대조**해야 오탐이 걸러진다.
② **HWP 변환이라 글자 사이에 공백이 있다**(「종로 5 가역 7·8 번」). 붙여서 비교해야 하는데,
   그러면 앞말과도 붙는다(「첨부파일사당동 305-35」). 경계 처리가 필요하다.
③ **「예정」이라 확정이 아니다.** 화면에서 고시·발주와 같은 줄에 세우면 안 된다.

### 자치구 보도자료는 따로다

서울시 보도자료에는 구 단위 사업이 잘 안 나온다. 자치구는 25곳이고 **게시판 플랫폼이 제각각이다**
(종로구는 `portal/bbs/selectBoardList.do`, 강남구는 다른 길). 25개를 각각 붙여야 한다.
**지금은 안 한다** — 서울시 것부터 하고 수확을 보고 정한다.

## 4-2. 서울시보 — 고시 구멍 162줄의 원천

효제1·2·3구역이 못 붙은 이유는 포털에 제2026-145호가 없어서다. 그 고시는 **서울시보**에 있다.

```
목록  https://www.seoul.go.kr/func/seoulsibo/list.do
파일  https://www.seoul.go.kr/func/seoulsibo/fileDownload.do?fileName=seoulsibo_20260713110659_53672.pdf
```

**한 호가 50~95MB다**(그 주의 고시 전부가 한 PDF에 들어 있다). 3년치 156호면 8GB 남짓.
전부 받을 일이 아니라, **못 붙은 162줄의 고시일 언저리 호만 골라 받아** 그 번호를 찾는다.
