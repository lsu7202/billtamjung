**갈래는 용어로.** 「더 지을 수 있게 된다」는 설명이지 이름이 아니다.

**결합률 실측(09-05)** — 「PDF 99%」는 그쪽 고시 100건 중 PDF 붙은 게 99건이라는 뜻이었다.
**우리 데이터 결합률이 아니다.** 따로 쟀다.

| 우리 것 | 고시가 붙나 | 방법 |
|---|---|---|
| 지구단위계획 948 | **100%** (60건 표본 전부) · 본문 100% · PDF 98% | `ntfc_sn` = `noticeCode` **1:1** |
| 정비구역 839 | **48%** (40건 표본 중 19) | 이름 검색 |

정비구역은 `MNUM` 이 다른 체계라 코드로 못 붙는다. 못 찾은 것은 대부분 **표기 차이**다 —
「청량리8구역」 vs 고시의 「청량리 제8구역」 · 「…정비구역」 vs 「…정비사업」 ·
「상봉7재정비촉진구역」 vs 「상봉 제7구역」. 띄어쓰기·「제」·「구역/사업」을 맞추면 오른다.
다만 「개봉5주택재건축-자세한사항은 주택과 문의」처럼 이름 자리에 안내문이 든 것은 못 고친다.
**100% 는 못 간다.** 화면은 본문이 있는 것만 본문을 보이고, 없으면 그 칸을 안 만든다.

**화면에 무엇이 더 서나**
- `title` — 「도시관리계획(율곡로 지구단위계획) **결정(경미한 변경)**」. 경미한 변경인지 신규 결정인지가 여기 있다
- `content` — 본문. AI 가 읽을 실체
- `pdf` — 고시문 원문 링크. E-1 의 `source_url` 이 드디어 채워진다
- `site` · `charger` · `phone` — 「노원구청 도시관리과 하동우 02-2116-3868」

**받는 법의 함정**(스크립트 주석에 적었다)
`/ntfc/getNtfcList.json` POST+JSON(`/api/ntfc/…` 는 404) · Referer 필요 ·
PDF 경로는 `UpisArchive`(대문자 U·A). `upisArchive` 는 404

**다음:** 440쪽 전량 수집 → `master.notice(notice_code, title, content, notice_no, notice_date, pdf_url, …)` →
`district_plan.ntfc_sn` 조인. 정비구역은 이름 매칭(붙는 것만).

### E-1. AI 에이전트가 읽는 표 — **화면보다 이게 먼저다**

화면은 이 표를 그리는 한 가지 방법일 뿐이고 **같은 표를 에이전트가 그대로 읽는다.**
그래서 화면에 있는 값만 표에 있고, 표에 없는 값은 화면에도 없다.

```
building_pk  1024123619
kind         정비·개발            ← 갈래는 코드. 문장이면 모델이 뜻을 다시 해석한다
name         홍실아파트 주택재건축 정비사업   ← 원장 그대로. 우리가 지은 제목이 아니다
on_date      2025-01-09          ← 없으면 null. 「2025년」을 2025-01-01 로 채우지 않는다
on_year      2025                ← 연도만 아는 경우를 담는 칸이 따로 있다
gosi_no      null                ← 모르는 것은 null. 빈 문자열·0·「미상」이 아니다
relation     반경 안              ← 구역 안 | 반경 안
distance_m   412
source       V-World C_UQ161     ← 어디서 왔는지가 값의 일부다
source_url   null
```

셋을 지키면 에이전트가 지어내지 않는다.
① **갈래는 코드로** ② **모르는 것은 null** ③ **출처를 값 옆에.**
날짜를 `on_date`(정확)와 `on_year`(연도만) 두 칸으로 가른 것도 같은 이유다 —
한 칸에 뭉개면 모델이 `2025-01-01` 을 실제 고시일로 읽는다.

**할 일 순서**
1. 표 `master.building_event`(위 스키마) — `redevel_zone`·`district_plan` 에서 채운다
2. 화면(정비·개발만). **지금 할 수 있다**
3. 기반시설 — 도시계획시설 `UQ161·UQ162·UQ164` · 도시개발구역 `UD901` (V-World)
4. 건축 인허가 — 건축HUB. 항목 K 와 같은 원천
5. 못 받는 셋(역 출입구·보행친화거리·문화재)은 나라장터 발주로만. 그 전엔 팀이 적는 칸

7. **지도 검색 엔터 이동** — 자동완성이 180ms 늦어 헛돌던 것. 친 글자로 그 자리에서 묻는다.
8. **「도산대로 · 오피스 요율로 역산」 스판 삭제**
9. **안내 스판 전부 삭제** — 「매매가를 넣으면 섭니다」 외 여섯.
