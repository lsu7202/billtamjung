## 2026-09-04 에 끝낸 것

1. **건물정보 승강기는 대장 기준** — 코드 완료, 값은 C 에서 갈린다.
   빌더 `_elev`(대장 전용)·`_elev_ext`(공단) 분리 · 0156 `elevator_ext` · API `_ref` · 화면 참조 곁말.
   건폐율·용적률도 대장이 비면 계산값을 옆에 참조로.
2. **평·㎡ 토글에 공시지가가 따라온다.** GongsiCard·GongsiTable 이 unit 을 받는다. 기본 평.
3. **층별 임대정보**
   - 용도 제거, **상호명** 신설(0155 `tenant_name`)
   - 순서 1층 → 위 → 옥탑 → 지하 (FloorRows `frank` · floor_rents ORDER BY · RentPanel `floorRank`)
   - 「＋ 호실」이 한 호실짜리 층에 안 뜨던 것 고침
   - **호실 번호를 지어내지 않는다.** 대장은 호실을 안 주므로 대장 줄에는 호실이 없고,
     한 호실뿐인 층도 호실을 안 보여준다. 팀이 ＋호실로 나눌 때만 101·102 로 선다.
   - **`sfloor` 버그**: 「옥탑1층」이 「1층」과 같은 층으로 읽혀 1층이 「102호」로 떴다. 옥탑을 따로 센다.
   - 여러 호실 층의 접기 제거. 항상 펴져 있다.
   - 입력 카드: 상호명·면적·상태 한 줄, 호실은 그 아래.
4. **「10년 전 대비 +5%」**
5. **「법정 대비 건폐 · 용적」** = 현재 − 법정. 넘으면 + 이고 빨강. **소수점 1자리.** `%p` 전부 제거.
6. **주변시세 막대 호버** — 막대 전체에 「이 건물 … · 주변 시세 …」, 눈금은 잡는 영역을 넓혔다.
7. **지도 검색 엔터 이동** — 자동완성이 180ms 늦어 헛돌던 것. 친 글자로 그 자리에서 묻는다.
8. **「도산대로 · 오피스 요율로 역산」 스판 삭제**
9. **안내 스판 전부 삭제** — 「매매가를 넣으면 섭니다」 외 여섯.
