# 보고서 작성 규격 (네이처셀 결)

적극적인 매수자에게 보여 줄 **매물 한 채의 투자 보고서**다. 읽는 사람은 판단을 하려는 사람이다 — 짧고, 근거가 있고, 표와 그림이 글을 받친다.

## 지면
- A4 세로. 장마다 `<section class="slide">`. 보통 3~6장. 첫 장은 표지 겸 요약.
- 장 머리는 `<h2>` 번호 + 짧은 명사구(「1. 매물 개요」). 소제목은 `<h3>`(「1) 입지」).

## 구성(물음에 맞게 빼고 더한다 · 차례를 강제하지 않는다)
1. **요약** — 결론 한 줄(굵게) + 근거 셋(▲ 불릿).
2. **매물 개요** — 대장 값 표(대지 · 연면적 · 층수 · 용도 · 사용승인 · 용도지역), 지적도 `<bt-map addr="…">`, 사진 `<bt-photo addr="…">`.
3. **가격 근거** — 매매가와 실거래 · 공시지가 · 주변 실거래 비교. 평단가로 맞춰 본다.
4. **임대 · 수익** — 현 임대(있으면) · 수익률. 실제 값과 추정 값을 섞지 않는다(추정은 「추정」이라 쓴다).
5. **입지 · 동향** — 역 거리 · 상권 · 주변 동향(정비 · 개발).
6. **위험과 확인할 것** — 명도 · 용도변경 · 법정 대비 초과 등.

## 문장
- **명사 · 체언 종결.** `~임` `~음` `~함` `~중` `~로 판단됨` `~가능성이 높음`. `~이다` `~한다` 를 쓰지 않는다.
- **단정과 추정을 나눈다.** 사실은 `~임`, 해석은 `~로 판단` `~가능성이 높음`.
- 접속은 한자어로: 다만 · 반면 · 따라서 · 한편 · 결국.
- 문단은 2~4문장 · 한 문단 한 논점. 근거가 셋 이상이면 문단 뒤에 ▲ 불릿(`<ul class="tri">`).
- **굵게는 문장당 한 곳**, 핵심 명사구에만.
- 수치에는 단위와 시점을 붙인다(「16.99%」 「2026년 2분기」).

## 쓰지 말 것
| 금지 | 왜 |
|---|---|
| 대시(—)를 연결어로 | 쉼표와 마침표로 나눈다 |
| 예고 문장(「세 가지로 나누어 봄」) | 목차가 이미 말한다 |
| 이음말(「즉」 「정리하면」 「주목할 점은」) | 문단이 제 순서면 필요 없다 |
| 표에 있는 값을 본문에서 되읊기 | 글은 표에서 안 읽히는 것(왜 · 그래서)만 |
| 과장(「압도적」 「혁신적」) · 수익 약속 | 판단하는 사람에게 신뢰를 잃는다 |
| `%p` | 「11.2 포인트」 또는 값 자체로 |
| 모르는 수치를 지어내기 | 우리 자료에서 받은 값만. 없으면 표에 `–` |

## 표
- 번호와 이름: `<p class="cap">표 1 | 이름</p>` 를 표 위에. 아래에 `<p class="src">자료: 국토교통부 실거래가 · 빌탐정 집계</p>`.
- 열은 최대 5개. 첫 열 = 항목 이름. 숫자 칸은 `class="num"`(오른쪽 · 자릿수 맞춤). 없는 값은 `–`.
- 강조는 색 하나(`class="hi"`).

## 그림(차트)
- `<svg>` 로 직접 그린다. 번호와 이름 `그림 N | 이름` · 자료 줄.
- 두 축이면 남색 막대(`var(--navy)`) + 주황 선(`var(--orange)`). 값 라벨을 마크 위에. 격자선은 가로만 연회색.
- 강조점 한 곳만 빨강(`var(--red)`). 원형 파이는 쓰지 않는다.
- **주장과 축이 같은 방향인지 본다.** 그림이 글을 배신하면 안 된다.
- 글자는 14~15px, 선은 2.4~2.6px(인쇄에서 줄어든다).

## 틀(클래스)
- `.slide` 한 장 · `h2` 장 머리 · `h3` 소제목 · `p` 본문 · `ul.tri` ▲ 불릿 · `p.cap` 표 · 그림 이름 · `p.src` 자료 줄
- `div.row` 가로 나눔(지도 · 사진 나란히) · `div.kv` 표지의 큰 값 묶음 · `table` 표
- 색 토큰: `--navy` 남색(주인공) · `--navy-2` 흐린 남색 · `--sky` 연파랑(표 머리 바탕) · `--orange` 주황 · `--red` 빨강 · `--muted` 회색
